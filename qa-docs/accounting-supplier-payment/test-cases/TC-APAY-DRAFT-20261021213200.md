# Summary AP: Debit Note USD sebagai source masuk baris Debit Note dalam USD pada AP USD (cross-menu)

Card: [ETM-16712](https://erpintegration.atlassian.net/browse/ETM-16712) (Test Case, cross-menu) · card asal: [ETM-16643](https://erpintegration.atlassian.net/browse/ETM-16643) · TC terkait lama: ETM-16680 sampai ETM-16684 (TC-APAY-SUM-001 sampai 005)

## Retest cepat

1. Buat AP: Create; Supplier = PT. Supplier Multicurrency, Transaction Currency = USD, Exchange Rate = 16.000; lanjut sampai halaman Edit.
2. Outstanding Purchase Invoice → PI-6968A3ED → Use → to be Paid Amount (USD) = 1.500,00 → simpan.
3. Di Account Payment Source klik Select Debit Note → centang DN-69689DE9 → Use → Amount = 1.000,00 → simpan.

## Data uji dari awal sampai akhir

Prasyarat umum:
- Akun uji QA yang punya akses menu Account Payment (Finance and Accounting → Account Payment). Login di https://staging.olshoperp.com/login.
- Company aktif harus **Lumi Charms.id**: klik avatar profil di pojok kanan atas → Switch Company → Lumi Charms.id → Proceed. Cara cek: daftar Account Payment memuat dokumen tanggal 21-10-2026 (mis. PY-5UTDC0FK). Kalau membuka halaman edit dokumen muncul 'You do not have access to this page', berarti company belum benar (data tes ini milik company Lumi Charms.id).
- Perbaikan ETM-16643 sudah ada di Staging. Cek di bagian paling bawah halaman: tulisan 'Last FE build' tanggal 21-10-2026 15:09 atau lebih baru, dan 'Last API build' 21-10-2026 16:19 atau lebih baru.
- Aturan isian: kolom 'to be Paid Amount (kode mata uang)' di form Use selalu dalam mata uang header AP (Transaction Currency), bukan mata uang invoice. Kolom 'to be Paid Amount' dan 'to be Paid Amount (IDR)' di sisi kanan hanya tampilan.
- DN-69689DE9 belum dipakai AP lain: di daftar Select Debit Note, Used Status 'Prepared: USD 0, Processed: USD 0' dan Remaining Balance USD 1.000,00.

## Langkah dan hasil yang harus terlihat

1. Login, pastikan company Lumi Charms.id.
2. Buat AP: Create; Supplier = PT. Supplier Multicurrency, Transaction Currency = USD, Exchange Rate = 16.000; lanjut sampai halaman Edit.
3. Outstanding Purchase Invoice → PI-6968A3ED → Use → to be Paid Amount (USD) = 1.500,00 → simpan.
   - Cek Summary: Utang USD 1.500,00; Total USD 1.500,00 orange.
4. Di Account Payment Source klik Select Debit Note → centang DN-69689DE9 → Use → Amount = 1.000,00 → simpan.
   - Cek Summary: Debit Note USD -1.000,00; Cash / Bank USD 0,00; Total USD 500,00 orange.
   - Di tabel Payment Source, kolom Rate untuk DN tampil 14.700 dan ada nilai Exchange Gain. Nilai itu tidak ikut dihitung di Summary.
5. Select Cash/Bank → centang 'BCA USD 2 - New 31 Dec 25' → Use → Amount = 500,00 → simpan.
   - Cek Summary: Cash / Bank USD -500,00; Total USD 0,00 warna normal.

## Hasil yang diharapkan

- Utang USD 1.500,00; Cash / Bank USD -500,00; Debit Note USD -1.000,00; Adj Debit USD 0,00; Adj Credit USD 0,00; Total USD 0,00 normal.
- Baris Debit Note bernilai tepat USD 1.000,00: bukan USD 918,75 (hasil 1.000 × 14.700 : 16.000) dan bukan hitungan lain dari kurs DN.
- Cash/Bank dan Debit Note tampil di baris yang berbeda.

## Catatan QA

- DN yang 'terbit dari AP' hanya terjadi lewat Import Account Payment, dan Import hanya untuk IDR. Jadi skenario DN terbit dalam USD tidak bisa dibuat. DN terbit versi IDR sudah dicakup ETM-16684.
- Setelah selesai hapus AP uji supaya DN-69689DE9 kembali bebas.
- Dokumen ini DRAFT (belum dijalankan). Hasil run dicatat di card ETM-16712.

## Pembersihan data (akhir tes)

- Hapus dokumen AP uji yang kamu buat (daftar Account Payment → pilih dokumen → Delete) supaya PI, Debit Note, dan saldo bank yang tertahan (reserved) dilepas dan bisa dipakai penguji lain. Dokumen yang sudah Approved tidak dihapus.
- Jangan menghapus dokumen uji milik orang lain (mis. PY-5UTD8RYM adalah bukti card ETM-16702).
- Simpan screenshot hasil (khususnya kotak Summary) sebagai bukti sebelum dokumen dihapus.
