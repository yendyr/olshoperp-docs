# Proteksi Merging Stock ID & Preservasi Colli Destination pada Modal Inline Update

## Deskripsi
Memverifikasi integritas data Stock ID dan Colli v2: Edit Qty melalui modal inline update tidak boleh menggabungkan 2 Stock ID yang berbeda asal-usul colli-nya menjadi 1 baris SKU tunggal karena akan menghancurkan data `Colli Destination`.

## Langkah Pengujian
1. Buka dokumen TFI di Transfer Internal Colli v2.
2. Masukkan 2 Stock ID dari SKU yang sama: Stock 534818 (dengan Colli Dest) dan Stock 534922 (Loose).
3. Klik edit Qty via **Modal Inline Update Product Transfer** lalu simpan.
4. Periksa jumlah baris detail dan status Colli Destination.

## Hasil Eksekusi & Catatan QA
- **2026-09-10 (ETM-15675):** FAILED — 2 Stock ID tergabung secara otomatis menjadi 1 baris dan Colli Destination hilang/ter-reset menjadi `NULL`.
- **2026-09-14 (ETM-15905):** PASSED — Edit Qty melalui inline edit maupun modal update sudah tidak menggabungkan 2 Stock ID yang berbeda Colli Origin-nya. Baris tetap terpisah konsisten.
