# Pembersihan Colli Code saat Hapus Header Dokumen TFI Unapproved

## Deskripsi
Memverifikasi lifecycle Colli v2 (sesuai requirement §7.3): Colli Code baru yang belum pernah di-approve pada transaksi apa pun harus otomatis terhapus dari datalist Multi-SKU Colli saat dokumen TFI dihapus.

## Langkah Pengujian
1. Buka menu **Transfer Internal Colli v2** (`/supplychain/new-mutation-transfer-internal`).
2. Buat dokumen TFI baru, isi item dan generate **New Colli Code** (contoh: `COL-6AA22CF4`).
3. Buka menu **Multi-SKU Colli** (`/supplychain/multisku-colli`) dan konfirmasi `COL-6AA22CF4` muncul.
4. Kembali ke menu Transfer Internal, hapus dokumen TFI dari datalist (tanpa approve).
5. Cari kembali `COL-6AA22CF4` di menu Multi-SKU Colli.

## Hasil Eksekusi & Catatan QA
- **2026-09-10 (ETM-15675):** FAILED — Colli code `COL-6AA22CF4` tetap exist di menu Multi-SKU Colli setelah header dokumen TFI dihapus tanpa pernah di-approve.
- **2026-09-14 (ETM-15905):** PASSED — Colli code unapproved otomatis dibersihkan / terhapus dari datalist Multi-SKU Colli saat dokumen TFI dihapus dari datalist.
