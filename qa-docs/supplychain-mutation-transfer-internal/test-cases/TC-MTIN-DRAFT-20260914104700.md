# Validasi Larangan Self-Assignment Colli Destination pada Partial Transfer (V-TFI-11)

## Deskripsi
Menguji klausul `V-TFI-11` di mana pada transfer parsial (memindahkan sebagian isi colli), barang yang dipindahkan keluar dilarang dimasukkan kembali ke colli origin yang sama (*self-assignment*). Sistem wajib memfilter atau menolak pemilihan tersebut secara informatif.

## Catatan QA & Konfirmasi Developer
- Konfirmasi Dev: *"kalo partial emang ga bisa sama res, baru bisa sama kalo full colli transfer. misal box COL-X1 isi 10 items mau ditransfer 3 items dengan colli code yang sama, nanti sisa 7 items pakai colli code apa?"*
- Status Temuan: **FAILED** (Memerlukan penyelarasan validasi UI di modal inline dan filter dropdown Select SKU).
