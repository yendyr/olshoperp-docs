# TC-PI-16260-05: [Inbound Import] - Import 10 baris campuran menggunakan Existing Colli Code ('COL-6AC5B3A7' & 'COL-6AC5B3A8')

## Konteks Pengujian (Card ETM-16260)
Memverifikasi kemampuan import detail barang pada menu Purchase Inbound (`/supplychain/new-purchase-inbound`) dalam mengenali dan memetakan beberapa Existing Colli Code secara bersamaan dalam satu kali file upload.

## Hasil Pengujian (Actual Result):
* **Dokumen Inbound:** `IN-5UO4Q05E` (Status: Open)
* **Existing Colli Codes:** `COL-6AC5B3A7` dan `COL-6AC5B3A8`
* **Hasil Aktual:**
  1. Seluruh 10 baris data berhasil diimport secara presisi.
  2. Baris yang mencantumkan kode `COL-6AC5B3A7` berhasil masuk dan terikat ke existing Colli **`COL-6AC5B3A7`**.
  3. Baris yang mencantumkan kode `COL-6AC5B3A8` berhasil masuk dan terikat ke existing Colli **`COL-6AC5B3A8`**.
  4. Baris tanpa kode colli tetap berstatus tanpa colli (**`-`**).

## Kesimpulan:
**PASSED 🟢**  
Sistem berhasil mengikat baris-baris item yang diimport ke masing-masing Colli Code existing yang sesuai tanpa terjadi duplikasi pembentukan kode colli.
