# TC-PI-16260-04: [Inbound Import] - Import 10 baris campuran tanpa colli dan dengan pengelompokan nomor colli ('1' & '8')

## Konteks Pengujian (Card ETM-16260)
Memverifikasi fungsionalitas pemetaan pengelompokan colli berbasis identifier angka pada menu Purchase Inbound (`/supplychain/new-purchase-inbound`). Sesuai requirement:
* Nilai angka berbeda pada kolom Colli (seperti `'1'` dan `'8'`) diartikan sebagai Colli yang berbeda sehingga sistem mengenerate Colli Code baru yang terpisah.
* Baris dengan identifier angka yang sama akan digabungkan ke dalam 1 Colli Code baru yang sama.
* Kolom colli kosong diartikan sebagai item tanpa colli (`-`).

## Hasil Pengujian (Actual Result):
* **Dokumen Inbound:** `IN-5UO4Q05E` (Status: Open)
* **Karakteristik Data:** 10 baris dengan isi kolom Colli bervariasi (kosong, `'1'`, dan `'8'`).
* **Hasil Aktual:**
  1. Seluruh 10 baris berhasil terimport dengan sempurna.
  2. Baris dengan kolom Colli kosong otomatis berstatus tanpa colli (**`-`**).
  3. Baris dengan nilai Colli `'1'` otomatis ter-generate dan digabungkan ke dalam Colli Code baru: **`COL-6AC5B3A7`**.
  4. Baris dengan nilai Colli `'8'` otomatis ter-generate dan digabungkan ke dalam Colli Code baru: **`COL-6AC5B3A8`**.

## Kesimpulan:
**PASSED 🟢**  
Sistem berhasil mengelompokkan dan mengenerate Colli Code baru secara dinamis berdasarkan angka identifier colli yang berbeda pada file import.
