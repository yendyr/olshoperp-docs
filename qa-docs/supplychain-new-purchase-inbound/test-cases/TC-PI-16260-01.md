# TC-PI-16260-01: [Inbound Import] - Import 150 baris tanpa Colli (kolom colli kosong)

## Konteks Pengujian (Card ETM-16260)
Memverifikasi batas kapasitas import detail barang pada menu Purchase Inbound (`/supplychain/new-purchase-inbound`) untuk dokumen dengan volume di atas 100 baris (150 baris) tanpa menggunakan pengelompokan Colli.

## Hasil Pengujian (Actual Result):
* **Dokumen Inbound:** `IN-5UO4GGLR` (Status: Open)
* **File Test Data:** https://docs.google.com/spreadsheets/d/10Hs1XH7vk-K5lwM6bz5Of8fINZCjFDUx/edit?usp=drive_link&ouid=110327478024682538510&rtpof=true&sd=true
* **Hasil Aktual:**
  1. **Success Import:** Seluruh 150 baris item berhasil diimport ke dalam dokumen inbound tanpa kendala timeout atau pembatasan 100 baris.
  2. **Colli Code Otomatis:** Seluruh baris di UI menampilkan nilai Colli Code **`-`** (karena pada file Excel kolom Colli sengaja dikosongkan sesuai requirement: *kolom colli kosong = tanpa colli*).
* **Evidence Attachment:** https://drive.google.com/file/d/18f2GL7I2fErwl8C-NLshWBXWpilE2Qwg/view?usp=drive_link

## Kesimpulan:
**PASSED 🟢**  
Sistem berhasil mengimport 150 baris data tanpa colli pada dokumen `IN-5UO4GGLR` dengan penandaan colli `-` yang akurat.
