# TC-ASO-DRAFT-20260907110300: Advanced Filter All Sales Order — Kombinasi >2 Parameter Filter (Trx Date, Booking Number, Platform Status)

## Objective
Memastikan fitur Advanced Filter pada menu All Sales Order mampu mengeksekusi penyaringan data secara presisi saat user mengombinasikan lebih dari 2 parameter filter sekaligus (khususnya kombinasi Trx Date, Booking Number `is empty`, dan Platform Status `is empty`) tanpa mengabaikan/merusak salah satu kondisi filter.

## Preconditions
1. User login ke OlshopERP Staging (`tim_dev@mail.com`).
2. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
3. Terdapat data transaksi Sales Order spesifik dalam rentang tanggal `13-08-2026` s/d `06-09-2026`:
   - **Data Booking Number Exist**: `SO-5UBOS910` (Booking Number: `BK-2026081501`, Platform Status: empty).
   - **Data Booking Number Empty**: `SO-5UBOYO59` (Booking Number: `-` / empty, Platform Status: empty).

## Test Steps
1. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
2. Klik tombol **Advanced Filter** di atas datalist.
3. Masukkan parameter filter ke-1:
   - Field: `Trx Date`
   - Operator: `Between`
   - Value: `13-08-2026` s/d `06-09-2026`
4. Masukkan parameter filter ke-2:
   - Field: `Booking Number`
   - Operator: `Is Empty`
5. *(Verifikasi 2 Filter)*: Klik **Apply Filter**. Pastikan `SO-5UBOYO59` (Booking Number empty) tampil, dan `SO-5UBOS910` (Booking Number exist) terfilter / tidak tampil.
6. Masukkan parameter filter ke-3:
   - Field: `Platform Status`
   - Operator: `Is Empty`
7. Klik **Apply Filter** / **Cari**.
8. Periksa keberadaan transaksi `SO-5UBOYO59` dan `SO-5UBOS910` di tabel datalist All Sales Order.

## Expected Results
1. Sistem menyaring data dengan menerapkan logika `AND` untuk ketiga kondisi filter sekaligus.
2. Datalist hanya menampilkan transaksi dalam rentang tanggal 13-08-2026 s/d 06-09-2026 yang memiliki `Booking Number` kosong (**Is Empty**) DAN `Platform Status` kosong (**Is Empty**), yaitu transaksi seperti `SO-5UBOYO59`.
3. Transaksi dengan `Booking Number` terisi (exist) seperti `SO-5UBOS910` (Booking Number: `BK-2026081501`) TIDAK BOLEH tampil di datalist.
