# TC-ASO-ADVF-002

## Deskripsi Uji
Memverifikasi fungsionalitas **Advanced Filter** pada menu All Sales Order untuk mendeteksi transaksi e-commerce yang dibatalkan oleh pembeli namun terlanjur diproses kirim oleh gudang tanpa dokumen retur (`Platform Status contains CANCEL`, `Outbound Code is not empty`, `Sales Return Code is empty`). Pengujian ini krusial bagi Finance untuk mencegah kerugian ongkir dan kehilangan aset fisik barang.
