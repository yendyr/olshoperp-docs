# TC-ASO-DRAFT-20260907141804: Advanced Filter All Sales Order — Filter Kepatuhan Pajak (Order General > 1 Juta Tanpa VAT)

## Objective
Memastikan fitur Advanced Filter pada menu All Sales Order mampu memfilter secara presisi kombinasi 4 parameter (Trx Date `Between`, Type `Equals GENERAL`, Product Amount `Greater Than 1000000`, dan VAT Amount `Equals 0`) untuk audit kepatuhan PPN.

## Preconditions
1. User login ke OlshopERP Staging (`tim_dev@mail.com`).
2. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
3. Terdapat transaksi General dan Platform di bulan Agustus 2026 dengan berbagai kisaran Product Amount dan VAT.

## Test Steps
1. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
2. Klik tombol **Advanced Filter** di atas datalist.
3. Masukkan parameter filter ke-1:
   - Field: `Trx Date`
   - Operator: `Between`
   - Value: `01-08-2026` s/d `31-08-2026`
4. Masukkan parameter filter ke-2:
   - Field: `Type`
   - Operator: `Equals`
   - Value: `GENERAL`
5. Masukkan parameter filter ke-3:
   - Field: `Product Amount`
   - Operator: `Greater Than`
   - Value: `1000000`
6. Masukkan parameter filter ke-4:
   - Field: `VAT Amount`
   - Operator: `Equals`
   - Value: `0`
7. Klik **Apply Filter** / **Cari**.
8. Periksa kolom `Type`, `Product Amount`, dan `VAT Amount` pada seluruh baris transaksi yang ditampilkan.

## Expected Results
1. Sistem menyaring data dengan menerapkan logika `AND` untuk keempat kondisi filter sekaligus.
2. Datalist HANYA menampilkan transaksi `GENERAL` di bulan Agustus 2026 dengan `Product Amount > 1.000.000` dan `VAT Amount = 0`.
3. Transaksi `PLATFORM` atau yang memiliki VAT terisi terfilter dengan benar.
