# TC-ASO-ADVF-005

## Deskripsi Uji
Memverifikasi fungsionalitas **Advanced Filter** pada menu All Sales Order untuk memproteksi margin keuntungan perusahaan (*Profitability Guard*), memastikan tim Finance dapat menahan penagihan atau persetujuan invoice atas pesanan yang dijual di bawah modal (Benchmark COGS) hingga mendapat otorisasi diskon resmi dari manajemen.
