# TC-ASO-DRAFT-20260907141803: Advanced Filter All Sales Order — Filter Error Flag 'Below Benchmark COGS' Tanpa Invoice

## Objective
Memastikan fitur Advanced Filter pada menu All Sales Order mampu memfilter secara presisi kombinasi 4 parameter (Trx Date `Between`, Store `Equals`, Failed Process `Contains Below Benchmark COGS`, dan Sales Invoice Code `Is Empty`) untuk audit margin fraud harga jual di bawah HPP acuan.

## Preconditions
1. User login ke OlshopERP Staging (`tim_dev@mail.com`).
2. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
3. Terdapat transaksi toko spesifik (`Store-A`) di bulan Agustus 2026 dengan beberapa indikasi error flag (`cogs-error`).

## Test Steps
1. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
2. Klik tombol **Advanced Filter** di atas datalist.
3. Masukkan parameter filter ke-1:
   - Field: `Trx Date`
   - Operator: `Between`
   - Value: `01-08-2026` s/d `31-08-2026`
4. Masukkan parameter filter ke-2:
   - Field: `Store`
   - Operator: `Equals`
   - Value: `Store-A`
5. Masukkan parameter filter ke-3:
   - Field: `Failed Process`
   - Operator: `Contains`
   - Value: `Below Benchmark COGS`
6. Masukkan parameter filter ke-4:
   - Field: `Sales Invoice Code`
   - Operator: `Is Empty`
7. Klik **Apply Filter** / **Cari**.
8. Periksa kolom `Store`, `Failed Process / Error Flag`, dan `Sales Invoice Code` pada seluruh baris transaksi yang ditampilkan.

## Expected Results
1. Sistem menyaring data dengan menerapkan logika `AND` untuk keempat kondisi filter sekaligus.
2. Datalist HANYA menampilkan transaksi `Store-A` di bulan Agustus 2026 yang terdeteksi `Below Benchmark COGS` dan belum memiliki `Sales Invoice Code`.
3. Transaksi tanpa flag `cogs-error` atau yang sudah terbit Sales Invoice terfilter dengan benar.
