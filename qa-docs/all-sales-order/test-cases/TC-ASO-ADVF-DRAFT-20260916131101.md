# TC-ASO-ADVF-001

## Deskripsi Uji
Memverifikasi fungsionalitas **Advanced Filter** pada menu All Sales Order untuk kebutuhan tim Finance dalam mengaudit pesanan siap tagih (*Uninvoiced Delivered Orders*). Skenario ini menggabungkan 4 parameter sekaligus (`Trx Date`, `Outbound Code is not empty`, `Sales Invoice Code is empty`, dan `Trx Status = PROCESSED`) guna mencegah *unbilled revenue* atau keterlambatan penagihan piutang.
