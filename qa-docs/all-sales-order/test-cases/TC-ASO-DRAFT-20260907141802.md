# TC-ASO-DRAFT-20260907141802: Advanced Filter All Sales Order — Audit Pesanan COD Nominal Besar Berstatus Processed

## Objective
Memastikan fitur Advanced Filter pada menu All Sales Order mampu memfilter secara presisi kombinasi 4 parameter (Trx Date `Between`, Is COD `Equals Yes`, Net Sales `Greater Than 500000`, dan Trx Status `Equals PROCESSED`) untuk pengawasan piutang COD bernominal besar.

## Preconditions
1. User login ke OlshopERP Staging (`tim_dev@mail.com`).
2. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
3. Terdapat transaksi COD dan Non-COD di bulan Agustus 2026 dengan rentang nominal di atas dan di bawah Rp 500.000.

## Test Steps
1. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
2. Klik tombol **Advanced Filter** di atas datalist.
3. Masukkan parameter filter ke-1:
   - Field: `Trx Date`
   - Operator: `Between`
   - Value: `01-08-2026` s/d `31-08-2026`
4. Masukkan parameter filter ke-2:
   - Field: `Is COD`
   - Operator: `Equals`
   - Value: `Yes` (1)
5. Masukkan parameter filter ke-3:
   - Field: `Net Sales`
   - Operator: `Greater Than`
   - Value: `500000`
6. Masukkan parameter filter ke-4:
   - Field: `Trx Status`
   - Operator: `Equals`
   - Value: `PROCESSED`
7. Klik **Apply Filter** / **Cari**.
8. Periksa kolom `Is COD`, `Net Sales`, dan `Trx Status` pada seluruh baris transaksi yang ditampilkan.

## Expected Results
1. Sistem menyaring data dengan menerapkan logika `AND` untuk keempat kondisi filter sekaligus.
2. Datalist HANYA menampilkan pesanan COD di bulan Agustus 2026 yang nilai Net Sales-nya `> 500.000` dan berstatus `PROCESSED`.
3. Pesanan Non-COD atau nominal `<= 500.000` terfilter dengan benar.
