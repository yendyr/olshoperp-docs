# TC-ASO-DRAFT-20260907141801: Advanced Filter All Sales Order — Kombinasi Filter Pesanan Batal Bernomor Outbound (Risiko Rugi Kirim)

## Objective
Memastikan fitur Advanced Filter pada menu All Sales Order mampu memfilter secara akurat kombinasi 4 parameter (Trx Date `Between`, Platform Status `Contains CANCEL`, Outbound Code `Is Not Empty`, dan Sales Return Code `Is Empty`) untuk kepentingan audit rekonsiliasi pesanan batal yang terlanjur terbit resi/outbound.

## Preconditions
1. User login ke OlshopERP Staging (`tim_dev@mail.com`).
2. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
3. Terdapat variasi transaksi penjualan di bulan Juli 2026 yang sebagian dibatalkan platform dan memiliki `Outbound Code`.

## Test Steps
1. Buka menu **Business Development → All Sales Order** (`/businessdevelopment/all-sales-order`).
2. Klik tombol **Advanced Filter** di atas datalist.
3. Masukkan parameter filter ke-1:
   - Field: `Trx Date`
   - Operator: `Between`
   - Value: `01-07-2026` s/d `31-07-2026`
4. Masukkan parameter filter ke-2:
   - Field: `Platform Status`
   - Operator: `Contains`
   - Value: `CANCEL`
5. Masukkan parameter filter ke-3:
   - Field: `Outbound Code`
   - Operator: `Is Not Empty`
6. Masukkan parameter filter ke-4:
   - Field: `Sales Return Code`
   - Operator: `Is Empty`
7. Klik **Apply Filter** / **Cari**.
8. Periksa kolom `Platform Status`, `Outbound Code`, dan `Sales Return Code` pada seluruh baris transaksi yang ditampilkan.

## Expected Results
1. Sistem menyaring data dengan menerapkan logika `AND` untuk keempat kondisi filter sekaligus.
2. Datalist HANYA menampilkan transaksi periode Juli 2026 yang dibatalkan platform (`CANCEL`), memiliki `Outbound Code` terisi, dan belum memiliki `Sales Return Code`.
3. Tidak ada transaksi ber-status non-cancel atau tanpa Outbound Code yang lolos filter.
