# TC-SOI-DRAFT-20260916111506: Verifikasi Konsistensi Nilai Kolom AR pada Fitur Export All Excel untuk Seluruh Skenario Relasi

## Objective
Memverifikasi bahwa file spreadsheet hasil fitur **Export All** menghasilkan data kolom AR yang identik 100% dengan nilai alokasi detail pada tampilan datalist web untuk semua skenario relasi (1:1, 1:N, N:1, N:M, dan Unpaid).

## Preconditions
1. User login ke OlshopERP Staging (`staging.olshoperp.com`) dengan scope company `FAT`.
2. Data transaksi dari skenario TC-01 s/d TC-05 telah tersedia di database staging.

## Test Steps
1. Buka menu **Accounting → Sales Order Invoicing** (`/accounting/sales-order-invoicing`).
2. Tentukan filter pencarian atau tanggal yang mencakup transaksi uji (TC-01 s/d TC-05).
3. Klik tombol **Export All**.
4. Buka slider / tab Export File dan tunggu hingga status export menjadi *Ready to Download*.
5. Unduh dan buka file Excel (`.xlsx`).
6. Periksa baris data transaksi uji pada file Excel, lalu cocokkan nilai kolom AR dengan tampilan di datalist web.

## Expected Results
1. File Excel berhasil diunduh tanpa corrupt.
2. Kolom AR pada file Excel mencerminkan nilai alokasi detail per invoice:
   - Skenario 1 AR - 1 SI: tercatat nilai alokasi riil.
   - Skenario 1 AR - Multiple SI: masing-masing baris SO mencatat nilai alokasi SI bersangkutan (bukan total header AR).
   - Skenario 1 SI - Multiple AR: tercatat sesuai alokasi transaksi pembayaran terkait.
   - Skenario Unpaid: tercatat nilai 0 atau kosong.
3. Nilai angka terformat rapi sebagai format numerik/mata uang yang valid.
