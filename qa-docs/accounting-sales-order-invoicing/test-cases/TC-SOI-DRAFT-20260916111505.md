# TC-SOI-DRAFT-20260916111505: Verifikasi Penanganan Nilai Kolom AR untuk Sales Invoice yang Belum Memiliki Pembayaran AR

## Objective
Memastikan bahwa perubahan query join ke detail AR tidak merusak tampilan data Sales Order / Sales Invoice yang belum memiliki transaksi pembayaran (unpaid), dan tidak memicu error query SQL NULL.

## Preconditions
1. User login ke OlshopERP Staging (`staging.olshoperp.com`) dengan scope company `FAT`.
2. Terdapat Sales Order `SO-501` yang telah terbit `SI-501` (Net Sales: Rp 120.000).
3. Belum ada transaksi Customer Payment (AR) apa pun yang dibuat untuk invoice tersebut.

## Test Steps
1. Buka menu **Accounting → Sales Order Invoicing** (`/accounting/sales-order-invoicing`).
2. Masukkan nomor `SO-501` atau `SI-501` pada kolom pencarian.
3. Amati tampilan pada kolom **AR Number** dan **AR Amount**.

## Expected Results
1. Baris data `SO-501` tampil normal pada datalist.
2. Kolom **AR Number** menampilkan tanda strip (`-`) atau kosong.
3. Kolom **AR Amount** bernilai **Rp 0** atau tanda strip (`-`).
4. Halaman datalist tidak mengalami error 500 Internal Server Error saat merender data tanpa relasi AR.
