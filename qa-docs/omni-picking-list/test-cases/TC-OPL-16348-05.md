# TC-OPL-16348-05: [Picking List] - Full pick tetap langsung complete, Lost untuk SKU satuan non-pcs tersimpan benar, dan Manual Picking List tidak berubah

## Summary
Perilaku lama tetap jalan setelah revamp Picking List: pick penuh tanpa sisa, Lost pada produk dengan satuan selain pcs, dan Manual Picking List yang di luar scope.

---

## Environment
* **Menu/Fitur:** SCM, Processing, Picking List; Supply Chain, Manual Picking List
* **Environment:** Staging
* **Role:** user dengan akses Picking List dan Manual Picking List

---

## Precondition Data
* Picking List 1 status Open, semua SKU satuan pcs
* Picking List 2 status Open, SKU C dengan satuan Box (1 Box = 12 pcs), To Pick 3 Box
* 1 Manual Picking List status Open

---

## Test Data
* Picking List 1: pick penuh semua SKU
* Picking List 2: pick 1 Box, Lost 1 Box (New PL 1 Box)

---

## Steps to Reproduce
1. Picking List 1: pick penuh semua SKU lalu selesaikan
2. Picking List 2: pick 1 Box SKU C, ke Review Unpicked, isi Lost 1, Complete Picking, Confirm & Complete
3. Cek Completion Summary dan dokumen Stock Deduction serta New Picking List yang terbentuk
4. Buka Manual Picking List, jalankan pick sampai complete

---

## Expected Result
* Picking List 1 langsung ke layar selesai tanpa Review Unpicked
* Picking List 2: Lost tercatat 1 Box (12 pcs), New Picking List berisi 1 Box (12 pcs), tidak ada selisih satuan
* Manual Picking List berjalan seperti sebelumnya (tampilan dan alur tidak ikut berubah)
