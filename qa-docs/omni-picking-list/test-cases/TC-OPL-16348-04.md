# TC-OPL-16348-04: [Picking List] - Incomplete SO Picklist dan Completion Summary hanya menampilkan data company user dan butuh akses Picking List

## Summary
Visibilitas data per company dan role: angka pill dan isi slideover Incomplete SO Picklist serta Completion Summary tidak boleh memuat data company lain, dan user tanpa akses Picking List tidak bisa membukanya.

---

## Environment
* **Menu/Fitur:** SCM, Processing, Picking List (pill Incomplete SO Picklist, Completion Summary)
* **Environment:** Staging
* **Role:** User A (company A, akses Picking List), User B (company B, akses Picking List), User C (tanpa akses Picking List)

---

## Precondition Data
* Company A punya 2 SO yang belum fully picked
* Company B punya 3 SO yang belum fully picked
* 1 Picking List company A yang sudah Complete

---

## Test Data
* Gunakan data di atas

---

## Steps to Reproduce
1. Login User A, buka datalist Picking List, lihat angka pill Incomplete SO Picklist, buka slideover
2. Login User B, ulangi langkah 1
3. User B coba buka Completion Summary Picking List company A lewat URL
4. Login User C, coba buka Picking List dan Completion Summary

---

## Expected Result
* User A melihat angka 2 dan hanya SO company A di slideover
* User B melihat angka 3 dan hanya SO company B
* User B tidak bisa melihat Completion Summary milik company A
* User C mendapat pesan tidak punya akses, data tidak tampil
