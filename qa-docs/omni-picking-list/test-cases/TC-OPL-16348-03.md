# TC-OPL-16348-03: [Picking List] - Order 0 picked masuk New PL, unpick menggabungkan baris lagi, dan SO di beberapa Picking List di Incomplete SO Picklist

## Summary
Varian batas pada Picking List: unpick setelah pick sebagian, satu order sama sekali tidak di-pick, Lost diisi penuh, dan SO yang tersebar di lebih dari satu Picking List.

---

## Environment
* **Menu/Fitur:** SCM, Processing, Picking List (halaman process, Review Unpicked, Completion Summary, pill Incomplete SO Picklist)
* **Environment:** Staging
* **Role:** user dengan akses Picking List

---

## Precondition Data
* Picking List 1 status Open berisi SO-1 (SKU A To Pick 4) dan SO-2 (SKU B To Pick 2)
* Ada SO-3 yang item-nya terbagi ke 2 Picking List berbeda dan belum fully picked

---

## Test Data
* SKU A: pick 2, unpick lagi, lalu pick 4
* SKU B (SO-2): tidak di-pick sama sekali, Lost 0
* Skenario tambahan: SKU A Unpicked 2 dengan Lost 2 (New PL jadi 0)

---

## Steps to Reproduce
1. Buka Picking List 1, pick SKU A qty 2, lalu klik ikon unpick pada baris picked
2. Pick SKU A qty 4
3. Biarkan SKU B tidak di-pick, lanjut ke Review Unpicked, Lost 0, Complete Picking, Confirm & Complete
4. Buka View Completion Summary, buka blok Orders
5. Di Picking List lain ulangi dengan Lost sama dengan Unpicked
6. Di datalist Picking List klik pill Incomplete SO Picklist, cari SO-3, buka detail status/PL-nya, expand SKU

---

## Expected Result
* Unpick menggabungkan baris picked kembali ke baris unpicked dengan qty semula (tidak ada baris ganda)
* SO-2 di blok Orders tampil dengan catatan excluded / seluruhnya pindah ke New PL beserta kode New PL-nya
* Lost penuh membuat New PL 0, modal hanya menampilkan Picked dan Lost
* Angka di pill Incomplete SO Picklist sama dengan jumlah order di slideover
* SO-3 tampil sekali dengan progress picked/total, status menyebut 2 Picking List dan bisa dibuka di modal; order yang belum dimulai berstatus Not started; pencarian tanpa hasil menampilkan empty state
