# TC-OPL-16144-01: Verifikasi Trigger dan Eksekusi Export All Pages pada Datatable Picking List

## Konteks Pengujian (Card ETM-16144)
Memverifikasi fungsionalitas baru pada datatable Picking List (`/omni/picking-list`) yang memungkinkan user mengekspor seluruh halaman data (*Export All Pages*) secara asynchronous ke dalam format file spreadsheet Excel.

## Langkah Pengujian
1. Login ke Staging OlshopERP dan pilih company uji.
2. Navigasi ke menu **Supply Chain › Processing › Picking List**.
3. Di bagian toolbar atas datatable, klik icon/tombol **Export**.
4. Pilih opsi dropdown **Export All Pages**.
5. Perhatikan slider/modal export file yang muncul di layar.
6. Tunggu proses background export hingga status berubah menjadi selesai.
7. Klik tombol unduh file Excel.

## Expected Result
* Modal slider export muncul dan menampilkan indikator loading/progress.
* Request API `/omnichannel/picking-list/export-excel` merespons sukses (*"Export All Data are currently in process..."*).
* Polling progress `/omnichannel/picking-list/export-progress` berjalan hingga selesai tanpa error 500.
* File Excel berhasil diunduh dan memuat seluruh data Picking List.
