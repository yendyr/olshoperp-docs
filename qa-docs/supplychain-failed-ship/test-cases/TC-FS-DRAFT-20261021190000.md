# Export All Failed Ship ditolak saat export berjalan dan bila lebih dari 25.000 baris

Card: [ETM-16697](https://erpintegration.atlassian.net/browse/ETM-16697) (Test Case, negative) · card asal: [ETM-16660](https://erpintegration.atlassian.net/browse/ETM-16660)

## Retest cepat
1. Staging, Dev Staging (13), Failed Ship, Export, With Details; kirim lagi 4,5 detik kemudian: An export process is currently running...
2. Tunggu selesai (15 sampai 21 detik) lalu export lagi: diterima.
3. Lebih dari 25.000 baris: lihat FailedShipController::exportAllExcel (hitung dulu, tolak sebelum membuat record).
