# TC-FS-16071-01: Datalist Failed Ship Hanya Memuat Sales Order yang Sudah Memiliki Referensi Dokumen Failed Ship

## Konteks Pengujian (Card ETM-16071)

Menguji hasil optimasi query pada `FailedShipController@index`. Sebelum optimasi, query menyaring seluruh populasi order dengan `is_eligible_to_failed_ship = 1` sehingga ratusan ribu order yang sekadar capable ikut dievaluasi. Setelah optimasi, query secara eksklusif hanya menargetkan data order yang telah memiliki referensi dokumen Failed Ship aktif.
