# Download Template

## Apa ini

Sub-menu **Download Template** di bawah Import: unduh contoh file per platform agar kolom sesuai yang dibaca sistem.

## Kapan dipakai

- Pertama kali upload untuk platform tertentu.
- Shopee: pastikan export **Penghasilan** (bukan format Income lama).
- General: template `OC:` / `OD:` dari master Other Cost / Discount.

## Cara pakai

1. Pilih **Store** dulu.
2. Buka **Import** → **Download Template** → CSV atau Excel (contoh).
3. Isi / sesuaikan dengan export Seller Centre, lalu **simpan sebagai CSV** untuk upload.
4. Shopee: header di **baris ke-3**; hanya baris `Lihat berdasarkan` = **Order**.

## Catatan

- TikTok: template statis di menu bisa belum tersedia — pakai export resmi Seller.
- Upload selalu **`.csv`**.
