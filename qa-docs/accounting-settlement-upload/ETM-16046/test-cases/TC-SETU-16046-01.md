# Outbound sukses untuk SKU bekas parent (child soft-deleted)

Implements: `SC-SETU-16046-01` · Origin: [ETM-16046](https://erpintegration.atlassian.net/browse/ETM-16046) · Jira TC: [ETM-16052](https://erpintegration.atlassian.net/browse/ETM-16052) · Request ID: `none`

## Step-by-Step UI Crawling

1. Buka Instant Settlement (`/accounting/settlement-upload`).
2. Siapkan/pilih batch berisi SKU bekas parent (tanpa anak aktif).
3. Proses hingga outbound.
4. Assert outbound sukses; tidak error parent semata karena child soft-deleted.

## Catatan QA

- Gap-only: validasi parent = anak aktif saja (bukan `withTrashed`).
- Contoh AC: TROLAS4-black / batch ST-* di merdian bila masih ada.
- Jangan isi `last_execution` sampai run nyata.
