# Purchase Inbound (Legacy UI) — Panduan Pengguna

**Menu:** Supply Chain → Purchase Inbound · **Route:** `/supplychain/mutation-inbound`

## Penting

Ini **UI lama**. Aturan bisnis GRN + **Colli v2** yang kanonik ada di:

→ **[BETA - New Purchase Inbound](../supplychain-new-purchase-inbound/user-guide.md)**

Kedua UI memakai API yang sama. Colli v2 (Existing/New + Colli Type) **identik**.

## Ringkas

1. Buat inbound dari PO / supplier.
2. Isi detail produk (+ colli bila dipakai).
3. Approve → stok masuk gudang tujuan.

Untuk SOP lengkap, Colli, dan validasi: ikuti panduan **BETA**.
