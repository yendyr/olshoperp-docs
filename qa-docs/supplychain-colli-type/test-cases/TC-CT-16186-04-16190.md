# TC-CT-16186-04-16190: [Colli Type] - Setelah switch company hanya default milik company aktif yang tampil

## Konteks Pengujian (Card ETM-16186 / Ref ETM-16190)
Memverifikasi scope query tenant di backend/frontend agar setelah user beralih/switch antar company, list Colli Type hanya menampilkan data milik tenant aktif dan tidak mengalami kebocoran data (*leakage*) dari tenant lain atau fallback ke SYSTEM.

## Bukti Pengujian (Evidence)
- Company Dev-Staging: https://drive.google.com/file/d/1ibZuezXlFz3OCxHH9cKrX1l7J3CtcGwC/view?usp=drive_link
- Company FINANCE: https://drive.google.com/file/d/1FYKaGeAwhQrF68sj4wqFVHjIgezBUfbZ/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  1. Saat aktif di company **Dev-Staging**, datalist menampilkan record milik Dev-Staging (`BOX`, `PLT`, dan record custom `CT-QA-003`).
  2. Saat di-switch ke company **FINANCE**, datalist hanya menampilkan record milik FINANCE (`BOX` dan `PLT`) dan **tidak menampilkan record custom `CT-QA-003` milik Dev-Staging**.
  3. Scope query tenant terbukti mengisolasi data per company dengan benar.
