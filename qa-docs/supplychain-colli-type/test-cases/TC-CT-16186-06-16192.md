# TC-CT-16186-06-16192: [Colli Type] - BOX & PLT company aktif tersedia di pemilih transaksi terkait

## Konteks Pengujian (Card ETM-16186 / Ref ETM-16192)
Uji integrasi lintas menu (cross-menu) antara master data Colli Type dan transaksi operasional Supply Chain (seperti pembuatan Colli pada modul *BETA - New Transfer Internal* dan *Purchase Inbound*). Memastikan dropdown Colli Type berhasil membaca dan menampilkan data master default serta custom milik company aktif.

## Bukti Pengujian (Evidence)
- Dropdown Add Colli pada Menu Transaksi (BETA - New Transfer Internal): https://drive.google.com/file/d/1kSp49j_x7lvfpDHbtLjjp3rRjR7ZR_Ir/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  Pada form modal *Add Colli* di menu transaksi (*BETA - New Transfer Internal*), opsi dropdown **Colli Type** menampilkan master data default `BOX` dan `PLT` serta Colli Type kustom aktif milik company yang bersangkutan dengan benar.
