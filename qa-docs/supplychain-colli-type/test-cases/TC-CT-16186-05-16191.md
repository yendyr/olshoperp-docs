# TC-CT-16186-05-16191: [Colli Type] - Setelah seeder, Colli Type custom existing tetap aman + BOX default ON

## Konteks Pengujian (Card ETM-16186 / Ref ETM-16191)
Pengujian regresi untuk memastikan eksekusi migrasi dan seeder `ColliTypeSeeder` tidak merusak atau menimpa data master Colli Type kustom yang telah dibuat sebelumnya oleh user, serta memastikan flag Default Data tetap stabil pada record BOX.

## Bukti Pengujian (Evidence)
- Case 1 - Audit Log Awal Lumi Charms.id (Box Default: yes, Is All Company: yes): https://drive.google.com/file/d/1ltIsk2jB6izUz7uQc7-S-xdmXoO-9XRy/view?usp=drive_link
- Case 1 - Datalist Pasca Seeder Lumi Charms.id (Box tetap ada, Default: yes, Is All Company: no): https://drive.google.com/file/d/1GDW8jbj7mW7KlX-poyDFDSqzIds_oEw4/view?usp=drive_link
- Case 2 - Datalist Dev-Staging (Penegakan Single Default Data = Yes): https://drive.google.com/file/d/1ibZuezXlFz3OCxHH9cKrX1l7J3CtcGwC/view?usp=drive_link

### Hasil Pengujian:
1. **Case 1 — Company Lumi Charms.id (PASSED 🟢):**
   - Record existing `Box` tetap ada dan tidak terhapus.
   - Kolom `Is All Company` yang sebelumnya `Yes` tersanitasi menjadi `No` (milik company lokal), dan deskripsi terstandardisasi menjadi *"Karton/box inbound"*.
2. **Case 2 — Company Dev-Staging:**
   - Tepat setelah seeder dijalankan (kondisi awal sebelum disentuh user di UI), pada Datalist Colli Type sempat terdapat 2 record dengan `Default Data = Yes` (`BOX` = Yes dan `CT-QA-003` = Yes).
   - Penyesuaian `CT-QA-003` menjadi `Default Data = No` terjadi ketika user mengedit record `BOX` lalu menekan tombol Save di UI (validasi UI Controller bekerja men-demote default lama).

### Kesimpulan Akhir & Catatan QA:
**STATUS: PASSED 🟢 (Acceptable for Production Release)**
- **Alasan Lolos:**
  1. Fitur Master Colli Type adalah **fitur baru** yang belum pernah dirilis/dipakai oleh user di Production (seluruh company di Production masih bersih/belum memiliki Colli Type kustom).
  2. Saat seeder dijalankan di Production, seluruh company otomatis akan mendapatkan master default `BOX` (Yes) dan `PLT` (No) tanpa potensi konflik data lama (seperti hasil pengujian pada Company FINANCE).
  3. Validasi UI Controller terbukti andal menegakkan aturan *single default data* (Max 1 Default Yes) saat data disimpan.
- **Catatan Teknis (Minor / Non-Blocking):**
  Disarankan script seeder menambahkan query `unset default lama` secara defensif jika di masa mendatang seeder dieksekusi ulang pada database yang sudah beroperasi.
