# TC-CT-16186-03-16189: [Colli Type] - Company baru/backfill otomatis dapat BOX & PLT milik company

## Konteks Pengujian (Card ETM-16186 / Ref ETM-16189)
Memverifikasi event hook `Company::created` di backend maupun script seeder agar setiap company baru otomatis ter-generate master Colli Type bawaan (BOX & PLT) tanpa intervensi manual.

## Bukti Pengujian (Evidence)
- Company Baru `ACOMP` (Aeri Company): https://drive.google.com/file/d/1ct_iCdxy0WcPcmcyGXmIb-Z0akbbmJEr/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  Saat company baru dibuat (`ACOMP - Aeri Company`), menu Colli Type langsung memuat 2 record default secara otomatis tanpa perlu create manual:
  - `BOX` (Box): Default Data: **Yes**, Active: **Yes**, Show for all company: **No**
  - `PLT` (Pallet): Default Data: **No**, Active: **Yes**, Show for all company: **No**
