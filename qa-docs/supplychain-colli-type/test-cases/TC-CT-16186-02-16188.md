# TC-CT-16186-02-16188: [Colli Type] - Edit default BOX di Company A tidak mengubah Company B

## Konteks Pengujian (Card ETM-16186 / Ref ETM-16188)
Memverifikasi isolasi kepemilikan Colli Type antar tenant (multi-company). Perubahan data master default di Company A tidak boleh berdampak atau menimpa record di Company B.

## Bukti Pengujian (Evidence)
- Company Dev-Staging (Edit Code BOX -> BOX10): https://drive.google.com/file/d/1zMdUW87WP729aExkUQy40iNEgNbzTJJd/view?usp=drive_link
- Company FINANCE (Code tetap BOX tidak terdampak): https://drive.google.com/file/d/1QaqDBNbcj1qw_-pIRbRbMamTUCXDVYxa/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  1. Pada company **Dev-Staging**: Code record berhasil diubah dari `BOX` menjadi `BOX10` dan tersimpan normal.
  2. Pada company **FINANCE**: Record default Colli Type tetap utuh dengan Code `BOX` (Default Data: Yes, Active: Yes) dan tidak terpengaruh oleh perubahan pada company Dev-Staging. Terbukti bahwa masing-masing company memiliki record data independen.
