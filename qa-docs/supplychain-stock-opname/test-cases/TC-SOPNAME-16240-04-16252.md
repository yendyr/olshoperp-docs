# TC-SOPNAME-16240-04-16252: [Stock Opname] - Print SKU, SID, dan print massal COLLI ID tetap berjalan setelah batas 100 halaman

## Konteks Pengujian (Card ETM-16240 / Sub-task ETM-16252)
Uji regresi pada dokumen Stock Opname (`/supplychain/stock-opname`) untuk memverifikasi bahwa:
1. Fitur cetak massal (*bulk print*) COLLI ID pada baris surplus besar (Adjustment Qty > 100) menerapkan batas maksimal **100 halaman per baris produk** secara independen.
2. Opsi cetak label lainnya (**SKU** dan **SID**) tetap berfungsi normal tanpa terpengaruh oleh pembatasan Colli ID.
3. Footer printout menampilkan **Total Sticker** sesuai jumlah lembar tercetak (300) dan **Total Qty** tetap mencerminkan akumulasi kuantitas penyesuaian asli (1.500 pieces).

## Hasil Pengujian (Actual Result):
* **Dokumen Uji:** `SP-5U98B1Q5` (Status: Approved)
* **Detail Baris Uji (Surplus > 100):**
  * `SKUTFE-Pink`: Availability = 446, Transaction Stock = 0, Expected Stock = 500, Adjustment Qty = **500 pieces**
  * `SKUTFE-Putih`: Availability = 475, Transaction Stock = 0, Expected Stock = 500, Adjustment Qty = **500 pieces**
  * `SKUTFE-Mix`: Availability = 490, Transaction Stock = 0, Expected Stock = 500, Adjustment Qty = **500 pieces**
* **Aksi Pengujian:**
  1. Uji cetak opsi *Print SKU* dan *Print SID* pada baris produk.
  2. Centang seluruh baris (Select All: 3 baris SKU) lalu klik tombol *Print* $\rightarrow$ *Colli ID* di toolbar atas tabel.
  3. Verifikasi jumlah halaman hasil cetak, rincian nomor halaman per SKU, serta angka summary / footer (*Total Sticker* & *Total Qty*).
* **Hasil Aktual:**  
  1. **Print SKU & SID:** Kedua opsi cetak berfungsi normal dan menghasilkan label yang sesuai.
  2. **Bulk Print Colli ID (Capping Boundary Test):** Meskipun masing-masing baris memiliki Adjustment Qty 500 pieces, sistem secara konsisten membatasi hasil cetak maksimal **100 halaman per baris**. Total lembar yang digenerate adalah tepat **300 halaman** (terverifikasi via pencarian SKU satu per satu: masing-masing SKU tercetak 100 lembar nomor `1/100` s/d `100/100`).
  3. **Verifikasi Footer & Summary:**
     * **Total Sticker:** Menampilkan nilai **300** (sesuai total 300 halaman/stiker yang dicetak).
     * **Total Qty:** Menampilkan nilai **1.500 pieces** (akumulasi riil 500 + 500 + 500 pieces; capping halaman tidak memotong/mengubah angka total kuantitas asli).
* **Evidence Attachment:** https://drive.google.com/file/d/1IwYE5lukms2s9OREQ-d6tbTNaaTEtSe9/view?usp=drive_link

## Kesimpulan:
**PASSED 🟢**  
Batas maksimal (*capping boundary*) 100 lembar per baris produk pada fitur *Bulk Print Colli ID* telah teruji valid pada baris dengan surplus 500 pieces (total 300 halaman). Footer **Total Sticker** (300) dan **Total Qty** (1.500) tercatat akurat, serta opsi cetak SKU/SID tetap berjalan normal sesuai Acceptance Criteria.
