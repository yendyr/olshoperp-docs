# TC-SOPNAME-16240-02-16250: [Stock Opname] - Print COLLI ID tidak mencetak label untuk baris dengan Adjustment Qty kurang atau nol

## Konteks Pengujian (Card ETM-16240 / Sub-task ETM-16250)
Memverifikasi bahwa fungsi cetak label COLLI ID pada detail dokumen Stock Opname (`/supplychain/stock-opname`) hanya mencetak label stiker untuk baris barang yang mengalami penyesuaian selisih lebih (Adjustment Qty > 0), serta mengabaikan baris dengan selisih nol (Adjustment Qty = 0) dan selisih kurang (Adjustment Qty < 0).

## Hasil Pengujian (Actual Result):

### 1. Pengujian Seleksi Cetak Colli ID (Dokumen: `SP-5UNGU5FC`) $\rightarrow$ **PASSED 🟢**
* **Tabel Detail Dokumen:**
  * `COMP-R2` (Avail: 571, Trx: 571, Exp: 571, Adj: 0)
  * `COMP-R1` (Avail: 670, Trx: 670, Exp: 680, Adj: +10)
  * `SKU-B` (Avail: 10, Trx: 15, Exp: 10, Adj: -5)
* **Single Row Print:** Aksi cetak Colli ID hanya tersedia/muncul pada baris `COMP-R1` (Adjustment Qty +10). Baris `COMP-R2` (0) dan `SKU-B` (-5) tidak memunculkan opsi cetak.
* **Bulk Print (Select All Rows):** Saat seluruh baris dicentang dan memilih Print Colli ID di toolbar atas tabel, sistem hanya mencetak label untuk `COMP-R1` sebanyak 10 lembar (masing-masing lembar memuat kuantitas 10 pcs).

### 2. Pengujian Konversi Satuan (Unit Conversion: `COMP-KABEL-biru`)
* **Kondisi Awal (Pieces):** Expected Stock = 100 pieces $\rightarrow$ Adjustment Qty = 100 $\rightarrow$ Hasil cetak Colli ID = 100 halaman (isi colli 100 pcs/page).
* **Kondisi Setelah Ubah Unit ke Box (1 box = 10 pieces):**
  * Angka pada Expected Stock dan Adjustment Qty otomatis terkonversi menjadi **10**.
  * **Side Finding / Catatan:**
    1. Kolom *Unit* pada tabel detail tetap menampilkan teks `'pieces'` (belum berubah menjadi `'box'`).
    2. Hasil cetak Colli ID menghasilkan 10 halaman, namun keterangan isi colli di lembar cetak mencatat **100 pieces** per halaman.

## Kesimpulan:
**PASSED 🟢 (Main Scope ETM-16250)**  
Sistem berhasil mengisolasi aksi cetak Colli ID hanya untuk baris dengan Adjustment Qty positif (+), serta mengabaikan baris selisih nol (0) dan minus (-). Catatan konversi teks unit dapat dijadikan improvement/subtask penyesuaian template printout.
