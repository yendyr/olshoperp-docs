# Checking Process — Panduan Pengguna

**Menu:** Omni → Checking Process · **Route:** `/omni/checking-process`

## Apa itu

Approve transfer tahap **checking** (setelah picking) ke virtual WH checking. Scan QR / kode TF / SO.

**Bukan** [Checking List](../omni-checking-list/user-guide.md) — itu QC (check item, replace defective, scrap).

## Langkah singkat

1. Pastikan picking sudah approved.
2. Scan / approve di Checking Process.
3. Lanjut Packing Process / Packing List.
