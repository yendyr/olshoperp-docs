# [TC-03] Warehouse existing tidak berubah (hanya create baru)

**Kartu:** [ETM-8618](https://erpintegration.atlassian.net/browse/ETM-8618) — Dampak Perubahan  
**Tag automation:** `@TC-ETM-8618-03`

Perubahan Prefix Type per level hanya memengaruhi **pembuatan warehouse baru**. Data existing tidak ikut berubah.

## Precondition

- Login: `playwright@gmail.com` / `12345678`
- Company: lumicharmsid (153)
- Ada warehouse existing yang sudah punya child (boleh hasil TC-01)

## Step

1. Di datalist, pilih 1 warehouse existing yang sudah punya child
2. Catat Code parent + jumlah/kode child
3. Buka **Edit** warehouse tersebut
4. Cek apakah section **Child Warehouse Generator** tampil di form edit
5. Save All tanpa mengubah hierarki child (jika gagal karena Drop Off, ganti warehouse tanpa Drop Off)
6. Kembali ke datalist/tree; bandingkan dengan catatan sebelum edit

## Expected

- Section generator **tidak** dipakai untuk regenerate di form edit (generator hidden / tidak mengubah tree)
- Parent + child existing sama seperti sebelum edit
- Tidak ada child baru hanya karena buka/simpan edit
