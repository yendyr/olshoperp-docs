# [TC-04] Validasi Prefix unique & alphabet tetap berlaku

**Kartu:** [ETM-8618](https://erpintegration.atlassian.net/browse/ETM-8618)  
**Docs:** `qa-docs/supplychain-warehouse-structure/requirement.md` — **V-07**  
**Tag automation:** `@TC-ETM-8618-04`

Prefix Type per level **tidak** mengendurkan aturan teks Prefix (unique + alphabet only).

## Precondition

- Login: `playwright@gmail.com` / `12345678`
- Company: lumicharmsid (153)

## Step

1. Warehouse Structure → Create, Code `WHPXVAL-{stamp}`, Drop Off **OFF**
2. Buka Child Warehouse Generator
3. **Skenario A — Prefix duplikat:** 2 baris, Level berbeda, Prefix sama `QADUP`, Amount `2`, Prefix Type boleh berbeda (Numeric vs Alphabet) → Save & Next
4. Pastikan save ditolak sebelum lanjut skenario B
5. **Skenario B — Prefix non-alphabet:** buat ulang create (atau reset form) Code `WHPXVALB-{stamp}`; Prefix baris 1 `QA12` (ada angka), Prefix baris 2 `QABZ`, Prefix Type boleh berbeda → Save & Next

## Expected

- Skenario A: save ditolak, pesan mengandung `Prefix must be unique`
- Skenario B: save ditolak, pesan mengandung `Prefix must be alphabet`
- Warehouse baru **tidak** tersimpan dari skenario invalid
- Yang ditolak adalah aturan Prefix teks (V-07), **bukan** karena Prefix Type berbeda antar level
