# [TC-01] Prefix Type berbeda per level (Numeric + Alphabet + Numeric)

**Kartu:** [ETM-8618](https://erpintegration.atlassian.net/browse/ETM-8618) — Requirement After  
**Tag automation:** `@TC-ETM-8618-01`

User bisa memilih Prefix Type **berbeda** di tiap baris Child Warehouse Generator saat create warehouse baru.

## Precondition

- Login: `playwright@gmail.com` / `12345678`
- Company: lumicharmsid (153)
- Fiscal / akses menu Warehouse Structure OK
- Type parent punya ≥3 level child (contoh Building → Aisle / Rack / Shelf)

## Step

1. Buka **Warehouse Structure** → **Create**
2. Isi header: Code `WHPX-{stamp}` (tanpa spasi), Name, Type parent Building (atau setara), Parent kosong, Drop Off **OFF**, Active ON, Show for all company ON
3. Buka section **Child Warehouse Generator**
4. Verifikasi field **Prefix Type** ada di **setiap** baris generator (bukan hanya baris 1)
5. Baris 1: Level child pertama (Aisle / setara Lantai), Prefix `LT`, Amount `2`, Prefix Type **Numeric**
6. Tambah baris. Baris 2: Rack, Prefix `RK`, Amount `2`, Prefix Type **Alphabet**
7. Tambah baris. Baris 3: Shelf, Prefix `SH`, Amount `2`, Prefix Type **Numeric**
8. **Save & Next**, tunggu generator selesai
9. Verifikasi child ter-generate dengan prefix LT / RK / SH

## Expected

- Warehouse parent tersimpan
- Mix Prefix Type antar level **diterima** (tidak ditolak karena beda Numeric/Alphabet)
- Child terbuat mengikuti Prefix Type masing-masing baris
- Jika Prefix Type hanya bisa dipilih di baris pertama → **FAIL** vs Requirement After kartu
