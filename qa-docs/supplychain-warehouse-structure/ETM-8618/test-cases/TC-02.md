# [TC-02] Prefix Type seragam semua level tetap bisa dipakai

**Kartu:** [ETM-8618](https://erpintegration.atlassian.net/browse/ETM-8618)  
**Tag automation:** `@TC-ETM-8618-02`

Requirement After mengizinkan kombinasi; **tidak mewajibkan** campur. Semua Numeric tetap sah.

## Precondition

- Login: `playwright@gmail.com` / `12345678`
- Company: lumicharmsid (153)
- Code unik (jangan reuse Code/Prefix TC-01)

## Step

1. Warehouse Structure → Create
2. Isi header Code `WHPXUNI-{stamp}`, Drop Off **OFF**, Type parent dengan ≥2 level child
3. Buka Child Warehouse Generator
4. Baris 1: Prefix `AA`, Amount `2`, Prefix Type **Numeric**
5. Baris 2: Prefix `BB`, Amount `2`, Prefix Type **Numeric**
6. Save & Next, tunggu generator selesai

## Expected

- Save berhasil
- Kedua level child memakai urutan Numeric
- Tidak ada error karena Prefix Type sama antar baris
