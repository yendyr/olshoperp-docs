# Other Cost — Panduan Pengguna

**Menu:** FA / Omni → Other Cost · **Route:** `/omni/other-cost`

Master biaya tambahan (shipping, packing, dll.) dengan COA Expense dan cakupan store.

1. Create → isi Code, Name, pilih **Other Cost COA**, Applied Store / All Stores.
2. Aktifkan status agar bisa dipakai di transaksi.
3. Jangan pakai akun yang sudah terikat Cash/Bank aktif.
