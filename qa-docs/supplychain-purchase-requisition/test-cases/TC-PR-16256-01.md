# TC-PR-16256-01: [Purchase Requisition] - Edit unit ke Alt Unit '1KOLI5600PCS' (setting System Product) status PR tetap Open

## Konteks Pengujian (Card ETM-16256)
Memverifikasi perbaikan bug regresi status pada modul Purchase Requisition (`/supplychain/purchase-requisition`) menggunakan Alternative Unit pertama (**1KOLI5600PCS**) yang disetting langsung dari **System Product** dengan rasio konversi 5.600 Pieces.

Pada kasus bug awal di card ETM-16256, saat produk awal ditambahkan dengan kuantitas default 1 Pieces lalu unit diubah ke Koli konversi 5.600, sistem menghitung $1 / 5.600 = 0.0001785...$ yang di UI/pembulatan integer terbaca sebagai 0. Kondisi `processed_to_po_quantity` (0) == `quantity_in_base_unit` (0) menyebabkan sistem salah menganggap PR sudah terpenuhi 100%, sehingga status dokumen secara gaib langsung melompat menjadi **Complete** saat save tanpa pernah ada aksi Approve.

## Hasil Pengujian (Actual Result):
* **Dokumen PR:** `PR-6AC49A22`
* **Dokumen PO Terkait:** `PO-6AC49BCE` (With PR)
* **Master Produk Uji:**
  * SKU: `SKU-PurchaseRequisition`
  * Unit: `1KOLI5600PCS` (Setting System Product, Qty Conv: 5.600)
  * Kuantitas: `5` Koli
* **Aksi Pengujian & Verifikasi Reproduce Bug:**
  1. Buat dokumen PR baru, tambahkan baris `SKU-PurchaseRequisition` (default: 1 Pieces).
  2. Ubah satuan unit menjadi `1KOLI5600PCS` (nilai terbagi 1/5.600 $\rightarrow$ di UI tampil '0') lalu ubah kuantitas menjadi `5`, dan simpan.
  3. Periksa status header PR di datalist dan form detail.
  4. Lakukan approval PR melalui menu aksi pada datalist.
  5. Buka menu **Purchase Order**, buat PO baru (tipe *With PR*), buka pop-up modal **Available PR**, lalu cari dokumen `PR-6AC49A22`.
* **Hasil Aktual:**  
  1. **Status Dokumen saat Edit Unit (Anti Phantom Complete):** Pergantian unit ke `1KOLI5600PCS` (meskipun sempat terbagi 1/5600 $\rightarrow$ 0) dan input qty pada detail PR mempertahankan status dokumen tetap **Open** (tidak ada lompatan status otomatis ke *Approved* maupun *Complete* tanpa approval).
  2. **Approval PR:** Klik tombol *Approve* berhasil mengubah status dokumen menjadi **Approved**.
  3. **Integrasi ke PO:** Dokumen `PR-6AC49A22` ditemukan saat pencarian di modal *Available PR* pada Purchase Order dengan kuantitas yang sesuai (**5 1 Koli 5600 pieces**).
* **Evidence Attachment:** https://drive.google.com/file/d/1Pdp3P1GWkTdnp_VOcr-lgA6BvKSMqiwn/view?usp=drive_link

## Kesimpulan:
**PASSED 🟢**  
Bug lompat status otomatis ke Complete akibat konversi $1/5600 \rightarrow 0$ terbukti telah berhasil diperbaiki. Status dokumen PR tetap Open selama pengeditan, approval manual berjalan normal, dan data PR ditarik utuh ke Purchase Order.
