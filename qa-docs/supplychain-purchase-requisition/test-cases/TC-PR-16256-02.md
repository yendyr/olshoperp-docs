# TC-PR-16256-02: [Purchase Requisition] - Edit unit ke Alt Unit '1Koli5600Pieces' (setting Master Unit rate) status PR tetap Open

## Konteks Pengujian (Card ETM-16256)
Memverifikasi perbaikan bug regresi status pada modul Purchase Requisition (`/supplychain/purchase-requisition`) menggunakan Alternative Unit kedua (**1Koli5600Pieces**) yang dikonfigurasi melalui **Master Unit** dengan rate konversi `0.00017857142` ($1/5.600$).

## Hasil Pengujian (Actual Result):
* **Dokumen PR:** `PR-6AC4A03E`
* **Dokumen PO Terkait:** `PO-6AC4A0D3` (With PR)
* **Master Produk Uji:**
  * SKU: `SKU-PurchaseRequisition`
  * Unit: `1Koli5600Pieces` (Setting Master Unit Rate: `0.00017857142`)
  * Kuantitas: `5` Koli
* **Aksi Pengujian:**
  1. Buat dokumen PR baru, tambahkan baris `SKU-PurchaseRequisition`, ubah satuan unit menjadi `1Koli5600Pieces` dan kuantitas = `5`, lalu simpan.
  2. Periksa status header PR di datalist / form.
  3. Lakukan approval PR melalui menu aksi pada datalist.
  4. Buka menu **Purchase Order**, buat PO baru (tipe *With PR*), buka pop-up modal **Available PR**, lalu cari dokumen `PR-6AC4A03E`.
* **Hasil Aktual:**  
  1. **Status Dokumen saat Edit Unit:** Pergantian unit ke `1Koli5600Pieces` dan input qty pada detail PR mempertahankan status dokumen tetap **Open** (tidak melompat menjadi *Complete*).
  2. **Approval PR:** Klik tombol *Approve* berhasil mengubah status dokumen menjadi **Approved**.
  3. **Integrasi ke PO:** Dokumen `PR-6AC4A03E` ditemukan saat pencarian di modal *Available PR* pada Purchase Order dengan kuantitas yang sesuai (**5 1 Koli 5600 pieces default**).
* **Evidence Attachment:** https://drive.google.com/file/d/1WroM3xcwQDTdOH-gWxNN7og3L0w9jGaQ/view?usp=drive_link

## Kesimpulan:
**PASSED 🟢**  
Perubahan unit ke Alternative Unit ber-rate desimal `1Koli5600Pieces` pada detail PR tidak lagi memicu salah deteksi status Complete, proses approval berjalan mulus, dan kuantitas PR ditarik secara akurat ke Purchase Order.
