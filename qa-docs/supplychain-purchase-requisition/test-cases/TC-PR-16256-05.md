# TC-PR-16256-05: [PR to PO Integration] - Tarik PR parsial dengan konversi Alternative Unit di PO dan verifikasi sisa Outstanding PR

## Konteks Pengujian (Card ETM-16256)
Memverifikasi ketepatan tracking kuantitas outstanding dan pergeseran siklus status dokumen Purchase Requisition (`/supplychain/purchase-requisition`) saat kuantitas permintaan ditarik secara bertahap (parsial) ke dalam beberapa dokumen Purchase Order (`/supplychain/purchase-order`).

## Hasil Pengujian (Actual Result):
* **Dokumen PR:** `PR-6AC4AD9B` (Total Kuantitas Permintaan: **11.200 Pieces** / ekuivalen 2 Koli)
* **Dokumen PO 1:** `PO-6AC4ADD3` (With PR, Status: Approved)
* **Dokumen PO 2:** `PO-6AC4AF51` (With PR, Status: Approved)
* **Hasil Pengujian Aktual:**
  1. **Tahap Penarikan PO 1 (Parsial):**
     * Dokumen `PO-6AC4ADD3` dibuat dengan menarik kuantitas sebagian sebesar **5.600 Pieces** (1 Koli).
     * Setelah PO 1 diapprove, status dokumen PR `PR-6AC4AD9B` tercatat **`Processed`** (tidak melompat ke *Complete*).
  2. **Tahap Penarikan PO 2 (Sisa Outstanding):**
     * Saat membuat dokumen `PO-6AC4AF51` dan mencari dokumen PR di modal *Available PR*, dokumen `PR-6AC4AD9B` **masih ditemukan** dengan rincian akurat:
       * **Processed Qty:** `5.600 Pieces`
       * **Outstanding Qty (bisa diinput di PO):** `5.600 Pieces`
  3. **Validasi Batas Kuantitas (Boundary Guard):**
     * Percobaan input kuantitas melebihi sisa outstanding (> 5.600 Pieces) **berhasil ditolak oleh sistem**.
  4. **Status Akhir PR Pasca-Approve PO 2:**
     * Setelah `PO-6AC4AF51` diapprove (seluruh kuantitas 11.200 Pieces terpenuhi penuh), status dokumen PR `PR-6AC4AD9B` berubah menjadi **`Completed`**.
* **Evidence Attachment:** https://drive.google.com/file/d/1_yJNfLJ_LhNAow1_A2GhyNRBb8ifuVEQ/view?usp=drive_link

## Kesimpulan:
**PASSED 🟢**  
Alur penarikan parsial dokumen PR ke beberapa Purchase Order berjalan presisi: status bertransisi dari *Approved* $\rightarrow$ *Processed* $\rightarrow$ *Complete*, pelacakan sisa kuantitas outstanding akurat, dan validasi pencegahan over-allocation kuantitas di PO aktif dengan sempurna.
