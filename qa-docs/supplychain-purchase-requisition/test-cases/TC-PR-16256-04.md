# TC-PR-16256-04: [PR to PO Integration] - Tarik PR satuan Pieces ke PO lalu ubah ke Alternative Unit 1KOLI5600PCS secara penuh

## Konteks Pengujian (Card ETM-16256)
Memverifikasi integrasi cross-module antara Purchase Requisition (`/supplychain/purchase-requisition`) dan Purchase Order (`/supplychain/purchase-order`): dokumen PR dibuat dengan satuan Base Unit (`5.600 Pieces`), saat ditarik ke PO satuannya diubah menjadi Alternative Unit (`1KOLI5600PCS` = 1 Koli). Pengujian memastikan sistem mengenali pemenuhan 100% kuantitas base unit sehingga status PR terupdate menjadi **Complete** dan tidak muncul lagi di modal *Available PR*.

## Hasil Pengujian (Actual Result):
* **Dokumen PR:** `PR-6AC4AADE` (Status awal: Approved $\rightarrow$ Status akhir: Complete)
* **Dokumen PO:** `PO-6AC4AB01` (With PR, Status: Approved)
* **Detail Transaksi:**
  * SKU: `SKU-PurchaseRequisition`
  * PR Initial Qty: `5.600 Pieces`
  * PO Converted Qty: `1 1KOLI5600PCS`
  * Unit Price PO: `1.000` (mengikuti satuan aktif pada baris detail PO)
  * Net Purchase: `1.000`
* **Hasil Aktual:**  
  1. **Konversi Satuan di PO:** Saat baris PR ditarik ke PO dan unit diubah ke `1KOLI5600PCS` dengan Qty = `1`, nilai transaksi tersimpan secara presisi.
  2. **Status Dokumen PR Pasca-Approve PO:** Setelah PO `PO-6AC4AB01` diapprove, status dokumen PR `PR-6AC4AADE` secara otomatis berubah menjadi **Complete**.
  3. **Pengecualian dari Available PR:** Saat mencoba membuat dokumen Purchase Order baru lainnya, kode PR `PR-6AC4AADE` **sudah tidak ditemukan / tidak muncul lagi** di modal *Available PR* (karena kuantitasnya sudah 100% terpenuhi).

## Kesimpulan:
**PASSED 🟢**  
Siklus integrasi alokasi penuh PR ke PO dengan konversi satuan Alternative Unit berjalan sempurna. Status PR terupdate menjadi Complete dan proteksi anti-duplicate penarikan PR pada modal Available PR terverifikasi valid.
