# Tampilan stok produk tanpa stok / stok 0 / stok normal di PR (pasca optimasi ETM-16286)

Card: [ETM-16557](https://erpintegration.atlassian.net/browse/ETM-16557) (Test Case, negative) · card asal: [ETM-16286](https://erpintegration.atlassian.net/browse/ETM-16286)

## Retest cepat
1. Staging, company **Lumi Charms.id (153)** → **SCM → Purchase Requisition** → buka PR Draft (mis. PR-6AD6DE05).
2. **Choose Product**: cari SKU-COLLI-002 (harus 0), SKU-TAX-010 (0), SKUSINGLE-088 (120).
3. Tambahkan ketiganya (kotak **Select Product** atau tombol **Use**) lalu cek kolom **Availability** di detail PR: `-`, `0`, `120`.
4. Muat ulang: nilai sama; console tanpa error JavaScript.

## Catatan QA

### Data uji (company 153) dan hasil 20-10-2026
| Jenis | SKU | Database | Pop-up | Detail PR |
|---|---|---|---|---|
| Tanpa stok | SKU-COLLI-002 (Pieces) | 0 baris stok | 0 | - |
| Tanpa stok | SKU-COLLI-002-RegressionTest (Box) | 0 baris stok | 0 | - |
| Stok 0 setelah keluar barang | SKU-TAX-010 | qty 100, terpakai 100, available 0 | 0 | 0 |
| Stok normal | SKUSINGLE-088 | available 120 | 120 | 120 |

Hanya dilihat di pop-up: SKU-ALT-UNT-005 dan SKU-VAR-bulat (varian tanpa stok) 0; SKU-PRT-001 dan SKU-Retur-Unbilled (stok 0) 0; SKUSINGLE-188 80; SKUSINGLE-023 550 (sama dengan database).

### Observasi
- Aturan tampil sama dengan kode lama: tanpa baris stok → kosong (pop-up 0, detail '-'); ada baris stok → jumlah available dikonversi ke unit baris. Produk tanpa stok tampil 0 di pop-up tetapi '-' di detail PR; card mengizinkan keduanya.
- Console mencatat HTTP 422 "Duplicate request detected, please wait 3 seconds" pada request `stock-convert` setiap klik "Use" (dikirim dua kali: satu ditolak, satu sukses) dan 1 kali pada Save All. Layar tidak menampilkan error dan nilai benar. Endpoint ini tidak diubah ETM-16286; tidak dibuatkan card.
- Mengetik SKU-COLLI-002 di kotak Select Product memilih SKU-COLLI-002-RegressionTest (cocok sebagian); pilih opsi yang persis sama dengan SKU uji.
- PR uji PR-6AD6DE05 awalnya berstatus Open; diubah ke Draft sesuai card. Dibiarkan sebagai data uji (4 baris produk).
- Tidak diuji: produk bundle, unit utama ≠ unit dasar (ETM-16556 s/d ETM-16560), Tyas, Merdian.
