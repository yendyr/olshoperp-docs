# Processing Date (readonly)

## Apa ini

Field **Processing Date** di toolbar Skip Processing **tidak bisa diubah di sini**. Nilai mengikuti setting di Unassign Wave / Skip Wave Process (satu company).

## Kapan dipakai

- Memastikan tanggal dokumen / stok yang dipakai saat Skip.
- Kalau tanggal salah → ubah di menu sumber, bukan di Skip Processing.

## Cara pakai

1. Lihat **Processing Date** di toolbar (readonly).
2. Jika perlu ubah: buka **Unassign Wave** atau **Skip Wave Process**, set tanggal, simpan.
3. Kembali ke Skip Processing — nilai ikut update (company yang sama).
4. Kalau di sumber kosong → Skip memakai **waktu sekarang**.

## Catatan

- Shared per company dengan Unassign Wave & Skip Wave.
- Jangan mengira mengubah date di Skip Processing — field tidak editable.
