# Skip Progress & ikon tahap

## Apa ini

Indikator visual di datalist: **Skip Progress** (persen) plus ikon **Pick / Check / Pack / Collect**. Warna menunjukkan tahap belum mulai, sedang jalan, atau selesai.

## Kapan dipakai

- Memantau batch yang baru di-Skip.
- Mengetahui tahap mana yang masih jalan / macet.

## Cara pakai

1. Setelah klik Skip Processing, lihat kolom **Skip Progress**.
2. Baca warna ikon: abu-abu = belum · kuning/oranye = sedang · hijau = selesai.
3. 100% + icon hijau → order menuju / sudah **Shipped**.

## Catatan

- Progress realtime; refresh tidak selalu perlu jika UI sudah update.
- Detail gagal → [Log Data & Retry](#sf-lingo:SF-SP-03).
