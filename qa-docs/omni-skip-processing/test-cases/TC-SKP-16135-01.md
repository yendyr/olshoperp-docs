# TC-SKP-16135-01: Verifikasi Status dan Tampilan Icon Picked pada Kolom Process Status Pasca Picking Complete

## Konteks Pengujian (Card ETM-16135)
Memverifikasi perbaikan bug regresi icon status gudang pada menu Skip Processing (`/omni/skip-processing`). Memastikan bahwa pada order yang telah menyelesaikan proses picking (PL Approved), icon Pick menampilkan indikator hijau dengan tooltip 'Picked'.

## Bukti Pengujian (Evidence)
- Dokumen Uji: `SO-5UL6YELQ` (Company: Lumi Charms.id)
- Tampilan Icon Process Status: https://drive.google.com/file/d/1R8QemMxnVVvv3euWrPMXJuhRqpj1q0iH/view?usp=drive_link
- Dokumen PL Approved `PL-NECS1AZA` (29-09-2026 09:11:02): https://drive.google.com/file/d/1LA4oGVsNndqO31VQfB6M9UNAZfKTQgWO/view?usp=drive_link
- Dokumen CL Approved `CL-5ULUJPIC` (29-09-2026 09:11:12): https://drive.google.com/file/d/1nKEXLPgH_AL9XX0JmRZ59PwllF5jNOaP/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** Sales Order `SO-5UL6YELQ` menampilkan icon Pick berwarna hijau dengan tooltip *picked* dan icon Check berwarna hijau dengan tooltip *checked*. Icon Pick tidak mengalami regresi kembali ke abu-abu.
