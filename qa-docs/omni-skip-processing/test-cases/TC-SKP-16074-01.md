# TC-SKP-16074-01: Verifikasi Resolusi Shipper ID dan Rute Gudang 3PL Kurir Internal pada Skip Processing SO General

## Konteks Pengujian (Card ETM-16074)

Memverifikasi perbaikan bug mismatch shipper ID pada fungsi `resolveShippingService()` saat eksekusi Skip Processing untuk pesanan internal (Sales Order General). Sistem kini berhasil mengarahkan mutasi stok pengiriman ke Gudang 3PL Kurir Internal Dev Staging, sehingga rantai fulfillment dari DO hingga Outbound berjalan sukses.
