# TC-SKP-16135-03: Verifikasi Presistensi Icon Picked pada Tahap Lanjutan Warehouse Process (Checking, Packing, Shipped)

## Konteks Pengujian (Card ETM-16135)
Memverifikasi ketahanan status (*status persistence*) icon Pick pada menu Skip Processing (`/omni/skip-processing`). Memastikan bahwa saat pesanan bergerak maju ke downstream fulfillment (Checking selesai hingga Approved), status icon Pick tetap konsisten tercatat sebagai 'Picked' (hijau) tanpa mengalami regresi.

## Bukti Pengujian (Evidence)
- Dokumen Uji: `SO-5ULXAGOK` | Checking List: `CL-5UMIUWIZ`
- Bukti Icon Pick & Check Approved (Keduanya Hijau): https://drive.google.com/file/d/1MTy-Kwb599wLsukIBv5nWH7O9W__TFti/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  1. Icon Check berwarna abu-abu sebelum proses, berubah menjadi oranye (*checking progress*) saat *Choose Area*, dan berubah menjadi hijau (*Checked*) saat dokumen `CL-5UMIUWIZ` disetujui (*Approved*).
  2. Icon Pick terbukti tetap konsisten berwarna hijau (*Picked*) dan tidak mengalami regresi kembali ke abu-abu (*Ready to Pick*).
