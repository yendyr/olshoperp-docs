# TC-SKP-16135-02: Verifikasi Status dan Tampilan Icon Pick pada Tahap Sebelum Picking Selesai (Ready to Pick / In Progress)

## Konteks Pengujian (Card ETM-16135)
Memverifikasi transisi status icon Pick pada menu Skip Processing (`/omni/skip-processing`). Memastikan icon Pick tetap abu-abu saat belum approved dan baru berubah menjadi hijau tepat saat Picking List berstatus Approved.

## Bukti Pengujian (Evidence)
- Dokumen Uji: `SO-5ULXAGOK` | Picking List: `PL-NEFPJCQR`
- Bukti Send to Default Wave (Icon Pick abu-abu): https://drive.google.com/file/d/11BAK-vZto0KItIiG4t2IqxZDzNs0uHc1/view?usp=drive_link
- Bukti Generate Picking List (Icon Pick abu-abu): https://drive.google.com/file/d/1poytyugEjeJGDGcgOfeGHqigHf8KjUBi/view?usp=drive_link
- Bukti PL Approved (Icon Pick hijau, Check abu-abu): https://drive.google.com/file/d/1GdZLyPv6oUW-9EbtRw9aroLyMhBt5gWD/view?usp=drive_link

### Hasil Pengujian:
- **PASSED 🟢:** 
  1. Icon Pick tetap berwarna abu-abu selama dokumen PL belum disetujui (saat masuk wave dan generate PL).
  2. Icon Pick berubah menjadi warna hijau tepat saat dokumen `PL-NEFPJCQR` disetujui (*Approved*).
  3. Icon Check tetap berwarna abu-abu saat proses picking baru saja selesai.
