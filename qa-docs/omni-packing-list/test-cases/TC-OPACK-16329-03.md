# TC-OPACK-16329-03: [Packing List] - Kartu Shipping Handoff saat resi kosong, order Sales General, dan order isi bundle saja

## Konteks Pengujian (Card ETM-16143 / Ref ETM-16326)
Menguji kasus-kasus khusus (*edge cases*) dan penanganan nilai kosong (*fallback*) pada kartu **Shipping Handoff**:
1. Order tanpa resi/AWB.
2. Order non-marketplace dari menu **Sales Order General**.
3. Order yang seluruh isinya adalah produk **Bundle**.
4. Konsistensi tampilan saat kartu dibuka kembali melalui aksi *View Shipping Handoff*.

## Precondition Data
1. Login Staging OlshopERP dengan akses Packing List.
2. Tersedia 3 jenis dokumen uji:
   * **Dokumen 1:** Sales Platform belum punya AWB.
   * **Dokumen 2:** Sales Order General.
   * **Dokumen 3:** Sales Platform murni produk bundle (2 SKU bundle).

## Langkah Pengujian
1. Selesaikan packing untuk Dokumen 1, periksa kartu Shipping Handoff.
2. Selesaikan packing untuk Dokumen 2, periksa kartu Shipping Handoff.
3. Selesaikan packing untuk Dokumen 3, periksa kartu Shipping Handoff.
4. Buka datalist Packing List, cari dokumen yang sudah selesai, lalu klik **View Shipping Handoff**.

## Expected Result
* **Dokumen 1 (Tanpa AWB):** Menampilkan teks `AWB not yet assigned` dan instruksi *Get Resi di Process Summary*.
* **Dokumen 2 (Sales General):** Kurir tampil `By Internal` dan badge `General`.
* **Dokumen 3 (Pure Bundle):** Rincian item dan counter bundle tampil proporsional dengan label `Contains bundle`.
* **View Histori:** Tampilan kartu riwayat identik dengan tampilan saat awal complete.
