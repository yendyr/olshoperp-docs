# TC-OPACK-16329-02: [Packing List] - Confirm Void ditolak saat order sudah punya Sales Invoice, pesan jelas dan Packing List tidak tampil sebagai voided

## Konteks Pengujian (Card ETM-16143 / Ref ETM-16325)
Memverifikasi validasi proteksi integritas finansial: jika pesanan marketplace berstatus Cancelled tetapi sudah menerbitkan **Sales Invoice**, permintaan Void langsung dari modal Packing List harus ditolak secara tegas tanpa merusak status dokumen.

## Precondition Data
1. Login ke Staging OlshopERP dengan privilege Packing List dan Sales Platform.
2. Terdapat dokumen Packing List (Open) dari Sales Platform yang status platform-nya sudah Cancelled.
3. Order tersebut sudah dibuatkan dokumen **Sales Invoice** (faktur penjualan).

## Langkah Pengujian
1. Masuk ke **Omni › Processing › Packing List**, buka dokumen terkait.
2. Klik **Complete & Next**.
3. Sistem mendeteksi status cancel dan memunculkan pop-up konfirmasi.
4. Pilih **Void order...** $\rightarrow$ pilih **Void only** $\rightarrow$ klik **Confirm Void**.
5. Amati respon penolakan dari sistem.
6. Cek status di tabel Packing List dan Sales Platform.

## Expected Result
* **Pesan Penolakan:** Muncul error validasi yang jelas bahwa order terikat Sales Invoice.
* **Status Dokumen:** Packing List tetap **Open**, Sales Platform tetap pada status sebelumnya (bukan Void).
* **Transfer Return:** Tidak ada mutasi/transfer return palsu yang terbentuk.
