# TC-OPACK-16329-04: [Packing List] - User tanpa akses approval Sales Platform tidak bisa Void dari Packing List

## Konteks Pengujian (Card ETM-16143 / Ref ETM-16327)
Memverifikasi matriks otorisasi dan isolasi data (*role & permission guardrails*):
1. Aksi **Void Order** dari popup Packing List membutuhkan hak akses *Sales Platform Approval*. Operator packing biasa yang tidak punya izin tersebut tidak boleh bisa mengeksekusi void.
2. Segregasi multi-tenant: User dari company lain dilarang mengakses dokumen packing list lintas company.

## Precondition Data
1. Tersedia 2 akun uji:
   * **Akun Role 1:** Hanya punya hak akses operasional Packing List (tanpa permission approval Sales Platform).
   * **Akun Role 2:** User dari company berbeda.
2. Dokumen Packing List (Open) dari order yang berstatus cancel di marketplace.

## Langkah Pengujian
1. Login sebagai **Akun Role 1**, buka dokumen Packing List.
2. Klik **Complete & Next** $\rightarrow$ pilih **Void order...** $\rightarrow$ **Confirm Void**.
3. Amati pesan penolakan akses.
4. Coba klik **Continue** untuk memvalidasi alur alternatif packing tetap bisa jalan.
5. Login sebagai **Akun Role 2**, buka link dokumen tersebut langsung.

## Expected Result
* **Penolakan Void (Role 1):** Aksi void gagal dengan pesan tidak berwenang; status order tidak berubah.
* **Alur Continue (Role 1):** Operator tetap bisa menyelesaikan packing normal jika memilih Continue.
* **Isolasi Company (Role 2):** Akses ditolak saat mencoba membuka dokumen company lain.
