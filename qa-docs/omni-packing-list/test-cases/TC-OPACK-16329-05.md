# TC-OPACK-16329-05: [Packing List] - Set Location, Scan, Pause/Resume, dan Skip Processing tetap jalan tanpa popup Cancel/Void

## Konteks Pengujian (Card ETM-16143 / Ref ETM-16328)
Memverifikasi bahwa seluruh fitur eksisting (AS-IS) pada modul Packing List tetap berjalan stabil dan tidak mengalami regresi setelah dilakukan revamp UI:
1. Alur wajib **Set Location** sebelum proses.
2. Fitur **Scan Barcode / QR Code**.
3. Fitur **Pause & Resume**.
4. Alur otomatis **Skip Processing / Skip Wave**.

## Precondition Data
1. Login Staging OlshopERP dengan akses Packing List.
2. Tersedia dokumen Packing List manual (belum punya lokasi).
3. Tersedia order yang diproses melalui alur otomatis Skip Wave / Skip Processing.

## Langkah Pengujian
1. Buka Packing List manual $\rightarrow$ Set Location $\rightarrow$ Lanjut ke proses packing.
2. Lakukan packing via Scan Barcode/QR.
3. Uji tombol Pause $\rightarrow$ coba Complete saat pause $\rightarrow$ klik Resume $\rightarrow$ Complete.
4. Jalankan Skip Processing untuk order otomatis.
5. Cek pembentukan dokumen Collecting/Shipping List.

## Expected Result
* **Set Location & Scan:** Berfungsi normal dan mengupdate progres item.
* **Pause Guard:** Sistem memblokir Complete saat status Pause dan mengizinkannya setelah Resume.
* **Skip Wave Compatibility:** Alur instan selesai mulus tanpa interupsi popup manual.
