# Packing List — User Guide

Cara memakai **Packing List** untuk mengemas order setelah checking.

**Alamat:** `/omni/packing-list`

> UI process sedang di-improve (wireframe packing handoff). Langkah di bawah mengikuti perilaku + arah TO-BE.

---

## 1. Buka Packing List

1. Menu Processing › **Packing List**.  
2. Buka dokumen. Set **Location** stasiun packing jika diminta.

---

## 2. Pack barang

1. **Pack** / **Unpack** per baris.  
2. Untuk **bundle**: Pack sekali di baris bundle; lihat isi lewat **View items**.  
3. Pack hanya penanda — Anda tetap bisa **Complete** meski ada yang belum di-pack.

---

## 3. Complete

1. Klik **Complete & Next**.  
2. Jika order cancel/void dan packing manual, pilih lanjut shipping atau Void.  
3. (TO-BE) Lihat kartu handoff: **kurir / shipper**, gudang 3PL, dan **AWB**. Drop paket sesuai shipper itu.  
4. Lanjut Collecting / next order. Print Shipping Label jika perlu.

---

## 4. Tips

- Resi biasanya sudah ada di tahap ini; kalau belum, Get Resi di **Process Summary**.  
- Skip Wave / Skip Processing: tidak ada pertanyaan cancel di Complete.  
- Settlement marketplace butuh order sampai Shipped — selesaikan packing + collecting/DO.
