# Dropdown Applied Store mengikuti status store (cross-menu)

Card: [ETM-16679](https://erpintegration.atlassian.net/browse/ETM-16679) (Test Case, cross-menu) · card asal: [ETM-16666](https://erpintegration.atlassian.net/browse/ETM-16666) · improvement peringatan: [ETM-16706](https://erpintegration.atlassian.net/browse/ETM-16706)

## Retest cepat
1. Staging, company **Dev Staging (13)** → **Business Development → Price → Category Price** → Create/Edit, buka dropdown **Applied Store**: store aktif (authorized atau belum) tampil, store nonaktif tidak.
2. Buka daftar Category Price: kolom **Applied Store** CAT-CROSS, Testing, SHP-DEV, QA-TEST-ETM-16675 berisi store belum authorized yang dipakainya.
3. Buka Edit tiap kategori: field **Applied Store** menampilkan store yang sama.

## Catatan QA

### Hasil run Bugsy 21-10-2026 (WIB)
| Langkah | Hasil | |
|---|---|---|
| Dropdown: LZ-Komi Pet Store (aktif authorized) | tampil | ✅ |
| Dropdown: OMG Beauty dan 3 store nonaktif | tidak tampil | ✅ |
| Dropdown: SH Lumicharms (aktif belum authorized), lalu Save | tampil dan tersimpan | ✅ (sesuai arahan Lead QA) |
| Daftar dan Edit: kategori yang sudah memakai store belum authorized | 4 dari 4 store tampil, tanpa peringatan | ✅ |
| Nonaktifkan store di master Store | tidak bisa diuji | ⏸ |
| Store terpakai nonaktif/terhapus | tidak ada datanya; tidak teruji dengan data asli | ⏸ |

### Observasi
- Toggle Active di master Store tidak bisa diubah untuk store authorized; pada 3 store belum authorized Save All ditolak validasi yang sudah ada (COA wajib diisi atau sudah dipakai di Cash/Bank Account), sehingga status store tidak bisa diubah di staging.
- Dari kode (`PricelistCategoryController`, `HasSelect2::prependSelected`): daftar dan show tidak memfilter status; dropdown Edit hanya memuat store aktif; store yang soft-deleted tidak tampil di daftar maupun Edit. Simulasi di layar Edit (respons dropdown dibuang store terpakai) membuat field Applied Store tampil kosong. Artinya store terpakai yang nonaktif berpotensi terlihat kosong di Edit. Ditangani di ETM-16706 (Improvement peringatan); perlu diverifikasi dengan data asli.
