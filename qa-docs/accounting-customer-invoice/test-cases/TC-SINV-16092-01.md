# TC-SINV-16092-01: Export Sales Invoice Mode Without Details & With Details (Verifikasi 4 Kolom Baru & Data Integrity)

## Deskripsi Pengujian
Menguji perbaikan card **ETM-16092** pada kedua mode export utama (**Without Details** dan **With Details**) di menu Sales Invoice (`/accounting/customer-invoice`), memastikan 4 kolom baru (`Instant Settlement`, `Total Other Cost`, `Total Other Discount`, dan `Description`) tampil di Excel dengan posisi kolom, formatting angka, dan nilai data yang presisi.

---

## Checklist Verifikasi File Excel Hasil Export

### A. Mode Without Details (Kolom A s.d. Q)
- [ ] Kolom A: `Trx. Date`
- [ ] Kolom B: `Trx. Code`
- [ ] Kolom C: `Customer`
- [ ] Kolom D: `Your Ref.`
- [ ] Kolom E: `Trx. Ref.`
- [ ] **Kolom F: `Instant Settlement` (BARU ⭐)**
- [ ] Kolom G: `Platform Order`
- [ ] Kolom H: `Currency`
- [ ] Kolom I: `Exchange Rate`
- [ ] **Kolom J: `Total Other Cost` (BARU ⭐)**
- [ ] **Kolom K: `Total Other Discount` (BARU ⭐)**
- [ ] Kolom L: `Total`
- [ ] Kolom M: `Net Sales`
- [ ] Kolom N: `Trx. Status`
- [ ] **Kolom O: `Description` (BARU ⭐)**
- [ ] Kolom P: `Created By`
- [ ] Kolom Q: `Created At`
- [ ] Merge cell judul di baris 1 adalah `A1:Q1`.

### B. Mode With Details (Kolom A s.d. AD)
- [ ] Level Header (Kolom A s.d. Q) memuat 4 kolom baru pada posisi F, J, K, dan O.
- [ ] Level Detail Item (Kolom R s.d. AD) berisi rincian item barang dan tidak bergeser kolom.
- [ ] Merge cell judul di baris 1 adalah `A1:AD1`.

### C. Data Integrity & Formatting
- [ ] Format angka pada `Total Other Cost` dan `Total Other Discount` menggunakan pemisah ribuan (*comma-separated*).
- [ ] Nilai di Excel sama persis dengan yang tampil di datalist.
