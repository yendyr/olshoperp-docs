# TC-SINV-16092-02: Export With/Without Details Saat Kolom Dihide di Datalist (Fixed Backend Template Integrity)

## Deskripsi Pengujian
Menguji integritas template backend export **Without Details** dan **With Details** pada card **ETM-16092**. Skenario ini memvalidasi bahwa template export With/Without Details bersifat *fixed* dan independen dari konfigurasi tampilan layar user (Columns Show/Hide). Sekalipun user menyembunyikan kolom-kolom tersebut di tabel datalist, file Excel yang diekspor tetap harus menyajikan data lengkap ke-4 kolom tersebut.

---

## Kondisi Uji (Test Setup)
1. **Filter Tanggal Transaksi (Trx Date):**
   `01-09-2026 00:00:00` s/d `28-09-2026 23:59:59`
2. **Pengaturan Kolom di UI (Columns Show/Hide):**
   - [x] Hide `TOTAL OTHER COST`
   - [x] Hide `TOTAL OTHER DISCOUNT`
   - [x] Hide `Instant Settlement`
   - [x] Hide `Description`

---

## Checklist Verifikasi File Excel Hasil Export

### 1. File Excel Mode Without Details
- [ ] Kolom F: `Instant Settlement` **tetap tampil di Excel** (meski di-hide di UI datalist).
- [ ] Kolom J: `Total Other Cost` **tetap tampil di Excel** (meski di-hide di UI datalist).
- [ ] Kolom K: `Total Other Discount` **tetap tampil di Excel** (meski di-hide di UI datalist).
- [ ] Kolom O: `Description` **tetap tampil di Excel** (meski di-hide di UI datalist).
- [ ] Data sel tetap terisi akurat sesuai dokumen invoice.

### 2. File Excel Mode With Details
- [ ] Kolom F: `Instant Settlement` **tetap tampil pada level header**.
- [ ] Kolom J: `Total Other Cost` **tetap tampil pada level header**.
- [ ] Kolom K: `Total Other Discount` **tetap tampil pada level header**.
- [ ] Kolom O: `Description` **tetap tampil pada level header**.
- [ ] Baris detail item (SKU, Qty, Harga, Subtotal) tetap sejajar rapi dan tidak bergeser kolom.
