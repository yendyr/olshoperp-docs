# Katalog job-flow Help Center

## Apa ini

Cara membaca dokumentasi job lintas menu di Help Center: halaman **Horizon Jobs Docs** menampilkan katalog artikel + (opsional) **Visual board** HTML.

## Kapan dipakai

- Belajar alur Instant Settlement / Sales Order / Skip Wave dari sudut antrean.
- Share peta visual ke tim tanpa buka file HTML lokal.

## Cara pakai

1. Login OlshopERP → buka **/docs**.
2. Section **Horizon Jobs Docs** → **Open catalog**, atau langsung **/docs/horizon-jobs**.
3. Pilih artikel (Settlement Upload, Sales Order, Skip Wave Process, Transfer…).
4. Jika ada tab **Visual board**, buka untuk peta HTML interaktif.

## Catatan

- Aturan QA (HJ-01…08) tetap di folder `qa-docs/horizon-jobs/`.
- Visual Skip Wave Process mungkin belum ada HTML — artikel markdown tetap tersedia.

## Lihat juga

- Help Center: `/docs/horizon-jobs`
- Folder visual/repo: [`_meta/horizon-jobs`](../_meta/horizon-jobs/)
