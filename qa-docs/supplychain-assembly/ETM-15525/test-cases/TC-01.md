# [TC-01] Max Assembly Qty terhitung ulang saat unit PCS diganti ke BOX

Saat UNIT detail FG diganti ke BOX, **Max Assembly Qty** harus dihitung ulang (≈50), bukan tetap 500.

## Step

- Login `playwright@gmail.com` / `12345678`, company **DEV-STG (13)**
- Assembly → Create → isi header wajib → Save & Next (atau auto-edit)
- Assembly Detail → Select Product → `ASS-R`
- UNIT = PCS → catat **Max Assembly Qty** (harap ≈ 500)
- Ubah UNIT → **BOX**
- Catat ulang **Max Assembly Qty**

## Expected

- PCS: Max ≈ **500**
- BOX (1 BOX = 10 PCS): Max ≈ **50** (bukan 500)
- Sesuai requirement A-17 + §4.2.1 (`floor` konversi stok komponen → unit FG)
