# TC-ASMBLY-DRAFT-20260914161607

## Deskripsi Uji
Memverifikasi ketahanan penanganan *null state* (*graceful fallback*) pada tooltip kolom **Transaction Stock** ketika pengguna mengosongkan tanggal transaksi (*clear date*), di mana sistem diharapkan secara aman menampilkan `Stock as of -` tanpa menimbulkan *runtime error* atau teks *null/undefined*.
