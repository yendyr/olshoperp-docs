# TC-SRM-16113-06: Validasi Tipe Data Numerik Kolom Qty dan Total Amount pada File Excel Hasil Export

## Deskripsi Uji
Memverifikasi usability laporan export bagi tim Finance/Accounting:
Seringkali pemformatan nilai mata uang atau kuantitas dilakukan dengan menempelkan prefix teks statis (misal `"Rp "`) langsung ke dalam nilai cell atau menggunakan formatting string di backend/frontend. Hal ini membuat Excel mendeteksinya sebagai data bertipe **Text/String**, yang berakibat formula spreadsheet (seperti `SUM`, `AVERAGE`, pivot table) menghasilkan nilai `0` atau error `#VALUE!`.
Test case ini memastikan tipe data cell pada kolom Qty dan Total Amount tetap berupa **Number**.
