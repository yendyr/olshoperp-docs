# TC-SRM-16113-07: Integritas Alignment Kolom Export This Page Only Pasca Penyembunyian Kolom Datalist (Hide Column)

## Deskripsi Uji
Menguji potensi bug *column misalignment / offset*:
Fitur export **This Page Only** membaca konfigurasi kolom langsung dari frontend state. Karena di antarmuka UI kolom Qty dan Total Amount merupakan 1 kolom fisik, sedangkan di hasil export dipecah menjadi 2 kolom Excel terpisah, perubahan visibilitas kolom (menyembunyikan/menampilkan kolom lain) sangat rawan menyebabkan bug di mana indeks kolom Excel bergeser 1 kolom ke kanan/kiri (data Total Amount masuk ke kolom Status, atau data Status masuk ke Total Amount).
Test case ini memastikan integritas alignment kolom tetap terjaga sempurna.
