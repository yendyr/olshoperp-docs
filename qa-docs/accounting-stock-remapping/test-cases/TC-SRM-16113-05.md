# TC-SRM-16113-05: Akurasi Akumulasi Total Amount pada Transaksi Multi-Item dengan Variasi Unit Price Ekstrem

## Deskripsi Uji
Menguji potensi bug kalkulasi (kalkulasi agregat keliru):
Pada transaksi dengan multi-item detail yang memiliki Unit Price berbeda-beda, sistem sering kali secara keliru mengalikan `Total Qty` dengan harga baris pertama (`first line unit price`), atau menggunakan rata-rata sederhana.
Test case ini memastikan rumus di datalist dan di seluruh varian export (Without Details, With Details, This Page Only) murni mengeksekusi $\sum_{i=1}^n (\text{Qty}_i \times \text{Unit Price}_i)$.
