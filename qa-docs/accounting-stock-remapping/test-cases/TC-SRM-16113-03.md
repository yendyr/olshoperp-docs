# TC-SRM-16113-03: Export This Page Only — Pemisahan Kolom Gabungan Qty dan Total Amount

## Deskripsi Uji
Memverifikasi perbaikan konfigurasi export sisi frontend (`exportUsing`) pada kolom gabungan datalist:
- Sebelumnya, mode **This Page Only** hanya memetakan `quantity_formatted` menjadi satu header `Qty`, sehingga nilai **Total Amount** terlewat / tidak ikut ter-export.
- Dengan perbaikan ini, mode **This Page Only** wajib menghasilkan 2 header kolom terpisah (Qty dan Total Amount) dengan nilai yang identik dengan tampilan layar browser.
