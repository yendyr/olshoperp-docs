# TC-SRM-16113-04: Export Without Details — Pemisahan Kolom Total Remapping Quantity dan Total Amount

## Deskripsi Uji
Memverifikasi perbaikan export sisi backend (`StockRemappingExportAll` opsi WITHOUT_DETAILS):
- Sebelumnya, export **Without Details** hanya memuat kolom heading `Total Remapping Quantity` (Qty) dan sama sekali tidak memiliki kolom **Total Amount**.
- Perbaikan pada tiket **ETM-16113** (origin ETM-16097) memastikan backend query menyertakan kolom **Total Amount** sebagai kolom terpisah dan nilainya merefleksikan total nilai transaksi remapping.
