# Summary AR: Credit Note IDR dan USD sebagai source masuk baris Credit Note bertanda minus, terpisah dari Cash/Bank (cross-menu)

Card: [ETM-16720](https://erpintegration.atlassian.net/browse/ETM-16720) (Test Case, cross-menu) · card asal: [ETM-16644](https://erpintegration.atlassian.net/browse/ETM-16644) · TC terkait lama: ETM-16685 sampai ETM-16689

## Retest cepat

1. BAGIAN A. Buat AR: Create; Customer = PT Nusa Jaya Abadi, Transaction Currency = IDR, Exchange Rate = 1; lanjut sampai halaman Edit.
2. Available Sales Invoice → SI-69B36EA9 → Use → to be Paid Amount (IDR) = 400.000 → Save.
3. Receiving Destination → Select Credit Note → centang CN-5UME5OMY → Use → Amount = 150.000 → simpan.

## Data uji dari awal sampai akhir

Prasyarat umum:
- Akun uji QA yang punya akses menu Account Receive (Finance and Accounting → Account Receive). Login di https://staging.olshoperp.com/login.
- Company aktif harus **Dev Staging**: klik avatar profil di pojok kanan atas → Switch Company → Dev Staging → Proceed. Cara cek: daftar Account Receive memuat dokumen customer PT Nusa Jaya Abadi (mis. RC-5UNRJVO7 tanggal 06-10-2026). Kalau membuka halaman edit dokumen muncul 'You do not have access to this page', berarti company belum benar (data tes ini milik company Dev Staging).
- Perbaikan ETM-16644 sudah ada di Staging. Cek di bagian paling bawah halaman: tulisan 'Last FE build' tanggal 21-10-2026 15:09 atau lebih baru, dan 'Last API build' 21-10-2026 16:19 atau lebih baru.
- Aturan isian: kolom 'to be Paid Amount (kode mata uang)' di sub-modal 'Use this to Payment Process' selalu dalam mata uang header AR (Transaction Currency). Angka bantu di sisi kanan modal (to be Paid Amount dan to be Paid Amount (IDR)) bisa membingungkan (labelnya ganda, catatan screening ETM-16644); yang dinilai di TC ini adalah angka di tabel Detail dan di Summary.
- Customer uji: PT Nusa Jaya Abadi (kode NJA). Di AR, pilihan Customer bisa berisi customer atau store; pilih customer.
- CN-5UME5OMY (IDR 150.000, Approved, milik PT Nusa Jaya Abadi) belum dipakai AR lain: di daftar Select Credit Note, Used Status 'Prepared: IDR 0, Processed: IDR 0' dan Remaining Balance 150.000.
- Untuk Bagian B siapkan Credit Note USD (belum ada di data): Finance and Accounting → Credit Note → Create; Customer = PT Nusa Jaya Abadi, Transaction Currency = USD, Exchange Rate = 16.000, simpan sampai halaman Edit; di Receiving Destination klik Select Cash/Bank → centang 'Bank BCA USD Staging' → Use → Amount = 50,00; lalu Approve. Catat kode CN baru (CN-…) dan pastikan statusnya Approved. Kalau CN USD tidak bisa dibuat atau di-approve, tulis Bagian B sebagai Blocked.

## Langkah dan hasil yang harus terlihat

1. Login, pastikan company Dev Staging. Siapkan Credit Note USD untuk Bagian B (lihat Precondition).
2. BAGIAN A. Buat AR: Create; Customer = PT Nusa Jaya Abadi, Transaction Currency = IDR, Exchange Rate = 1; lanjut sampai halaman Edit.
3. Available Sales Invoice → SI-69B36EA9 → Use → to be Paid Amount (IDR) = 400.000 → Save.
   - Cek Summary: Piutang Rp 400.000,00; Total Rp 400.000,00 orange.
4. Receiving Destination → Select Credit Note → centang CN-5UME5OMY → Use → Amount = 150.000 → simpan.
   - Cek Summary: Credit Note Rp -150.000,00; Cash / Bank Rp 0,00; Total Rp 250.000,00 orange.
   - Kolom Credit Note Code di tabel Receiving Destination terisi CN-5UME5OMY.
5. Select Cash/Bank → centang 'Bank BCA Lumi Charms' → Use → Amount = 250.000 → simpan.
   - Cek Summary: Cash / Bank Rp -250.000,00; Total Rp 0,00 warna normal.
6. Hapus AR uji Bagian A.
7. BAGIAN B. Buat AR baru: Customer sama, Transaction Currency = USD, Exchange Rate = 16.000. Available Sales Invoice → SI-69A9447A → Use → to be Paid Amount (USD) = 100,00 → Save.
   - Cek Summary: Piutang USD 100,00.
8. Select Credit Note → centang CN USD baru → Use → Amount = 50,00; lalu Select Cash/Bank → 'Bank BCA USD Staging' → Use → Amount = 50,00.
   - Cek Summary: Credit Note USD -50,00; Cash / Bank USD -50,00; Total USD 0,00 warna normal.

## Hasil yang diharapkan

- Bagian A: Piutang Rp 400.000,00; Cash / Bank Rp -250.000,00; Credit Note Rp -150.000,00; Adj Debit Rp 0,00; Adj Credit Rp 0,00; Total Rp 0,00 normal.
- Bagian B: Piutang USD 100,00; Cash / Bank USD -50,00; Credit Note USD -50,00; Total USD 0,00 normal.
- Baris Credit Note bertanda minus untuk CN sebagai sumber dan tidak bercampur dengan baris Cash / Bank.

## Catatan QA

- Credit Note yang 'terbit dari AR' (kelebihan bayar, tanda plus di Summary) hanya terjadi lewat Import Account Receive (IDR). Itu dicakup TC lama ETM-16689 dan tidak diulang di sini.
- Setelah selesai hapus AR uji supaya CN dan SI kembali bebas.
- Dokumen ini DRAFT (belum dijalankan). Hasil run dicatat di card ETM-16720.

## Pembersihan data (akhir tes)

- Hapus dokumen AR uji yang kamu buat (daftar Account Receive → pilih dokumen → Delete) supaya Sales Invoice dan Credit Note yang tertahan (reserved) dilepas dan bisa dipakai penguji lain. Dokumen yang sudah Approved tidak dihapus.
- Credit Note baru yang kamu buat sendiri (hanya TC Credit Note bagian USD) boleh dibiarkan Approved untuk uji ulang berikutnya.
- Simpan screenshot hasil (khususnya kotak Summary) sebagai bukti sebelum dokumen dihapus.
