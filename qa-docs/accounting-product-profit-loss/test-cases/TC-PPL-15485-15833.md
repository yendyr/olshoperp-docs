# TC-PPL-15485-15833: Verifikasi Order tanpa Warehouse Process (Bypass Alur Gudang) Tidak Masuk ke Report

## 1. Objective
Memverifikasi bahwa Sales Order yang tidak memiliki `wh_process_id` (misal mode fulfillment 'Not Processed' atau tidak dialokasikan ke gudang pemroses) secara otomatis di-filter keluar dan tidak masuk ke dalam laporan Product Profit Loss (mengacu pada filter backend `whereNotNull('so.wh_process_id')`).

## 4. Evaluasi & Kesimpulan QA
1. **Kegagalan Filter (Defect):** Dokumen Sales Order bertipe non-processed / tanpa alokasi gudang pemroses (`so.wh_process_id IS NULL`) tetap tembus dan terhitung ke dalam laporan *Product Profit Loss*.
2. **Dampak:** Munculnya omzet dan pembebanan COGS fiktif di laporan laba rugi atas barang yang tidak pernah diproses ataupun keluar dari gudang fisik OlshopERP.
3. **Kesimpulan Akhir:** Test Case dinyatakan **FAILED ❌**. Perlu perbaikan query backend `generateDailyData()` agar filter `whereNotNull('so.wh_process_id')` secara konsisten menyaring transaksi non-processed keluar dari laporan.
