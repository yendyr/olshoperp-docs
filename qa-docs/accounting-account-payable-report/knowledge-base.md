# Account Payable Report — Knowledge Base

> Dokumentasi menu ini sebagian besar masih disusun. Section **Supplier tampilan** di bawah sudah mengunci kebijakan code-only.

## Ringkasan

Menu **Account Payable Report** adalah bagian dari modul **Accounting** di OlshopERP (laporan hutang supplier / outstanding AP).

## Supplier tampilan (code-only)

Di grid dan export, supplier tampil sebagai **kode** saja (semua role). Filter/search tetap bisa by nama atau kode. Nama supplier boleh muncul di **Print** (jika ada). Ini **bukan** Purchase Report.
