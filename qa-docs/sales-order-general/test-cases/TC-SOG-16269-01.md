# TC-SOG-16269-01: Akumulasi Price Before VAT pada Header Bundle yang Memiliki Komponen Variant Random

## Konteks Pengujian (Card ETM-16269)
Memastikan perbaikan bug pada Sales Order di mana baris header bundle mengakumulasikan nilai *Price Before VAT* (DPP) dari seluruh komponen penyusunnya secara lengkap, termasuk komponen varian *random* (`SKUBotolTumblr-random`).

## Precondition & Test Data
* **SKU Bundle:** `SKU-TestBundle-small`
* **Komponen:**
  1. `SKU-GAYUNG` (Retail Price: Rp 8.000, VAT Exclude 10%, Coeff: false)
  2. `SKU-EMBER` (Retail Price: Rp 15.000, VAT Exclude 10%, Coeff: false)
  3. `SKUBotolTumblr-random` (Retail Price: Rp 20.000, VAT Exclude 10%, Coeff: false)
* **Unit Price Input:** `Rp 43.000` (Exclude 10%)

## Langkah Pengujian
1. Masuk ke **Dev - Sales Order** (`/businessdevelopment/sales-order-general`), buat dokumen SO baru atau edit draft.
2. Tambahkan item bundle **`SKU-TestBundle-small`** (Qty: 1).
3. Masukkan **Unit Price**: `Rp 43.000` (VAT Exclude 10%).
4. Periksa kolom **Price Before VAT** pada baris header bundle tersebut.

## Expected Result
* Kolom **Price Before VAT** terisi utuh sebesar **`Rp 43.000`** (`8.000` + `15.000` + `20.000`).
* Sistem tidak lagi mengabaikan nilai Rp 20.000 dari komponen `SKUBotolTumblr-random`.
