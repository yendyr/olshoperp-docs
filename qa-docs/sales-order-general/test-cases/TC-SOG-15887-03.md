# TC-SOG-15887-03: Perhitungan Total Detail Lines untuk SKU Header Assembly

## Catatan Tambahan (Finding Minor)

Namun saat import berhasil, counter tidak langsung ter-update secara otomatis di UI dan harus di-refresh manual terlebih dahulu ([Bukti Session BetterBugs](https://app.betterbugs.io/session/6ab61ac59a0216b8a623af9d)).
