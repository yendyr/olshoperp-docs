# TC-SOG-16269-06: Perhitungan Price, DPP, dan VAT pada Detail Sales Order Berupa SKU Bundle Random Setelah Send to Default Waves

## Konteks Pengujian (Card ETM-16269)
Memverifikasi ketahanan data keuangan saat detail Sales Order yang memesan produk varian **Bundle Random** (`SKU-TestBundleNewest-random`) diproses melalui tahapan fulfillment **Send to Default Waves**.

## Precondition & Test Data
* **Parent Bundle:** `SKU-TestBundleNewest` (VAT 10% Exclude)
* **Varian Fisik Sibling:**
  * `SKU-TestBundleNewest-abu` (Retail Price: Rp 9.500)
  * `SKU-TestBundleNewest-biru` (Retail Price: Rp 10.000)
* **Item Diuji:** `SKU-TestBundleNewest-random` (Price di Sales Order: Rp 9.000 Exclude 10%)
* **Sample SO:** `SO-5UPZEMM9`

## Langkah Pengujian
1. Buat Sales Order `SO-5UPZEMM9` dengan item `SKU-TestBundleNewest-random` seharga Rp 9.000.
2. Lakukan **Send to Default Waves**.
3. Setelah proses wave berjalan, buka kembali detail dokumen `SO-5UPZEMM9`.
4. Amati nilai pada kolom Price, DPP (Price Before VAT), VAT Amount, dan Total Price.

## Expected Result
* Nilai Price (Rp 9.000), DPP (Rp 9.000), VAT (Rp 900), dan Total Price (Rp 9.900) tetap bertahan secara valid.
* Tidak terjadi reset angka menjadi `0` atau DPP menjadi null (`-`).

## Actual Result (Field Defect - ETM-16269)
* Kolom Price, DPP, VAT, hingga Total Price berubah menjadi `0`, dan kolom DPP tampil null (`-`) setelah order berhasil dikirim ke wave.

* Bukti Aktual Bug: [Detail Nilai Ter-reset Jadi 0/Null](https://drive.google.com/file/d/1xVwOI8_j9asyIJ5YSTqVokJK13-dlpyz/view?usp=drive_link)
