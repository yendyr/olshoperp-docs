# TC-SOG-15887-06: Pencegahan Race Condition Penambahan Produk Manual saat Import Processing dan Proteksi Backend Approval

## Evaluasi & Temuan Retest ETM-16098
* **Status:** ❌ **FAILED / NEED IMPROVEMENT**
* **Temuan:**
  1. Ketika proses import masih berstatus `processing`, antarmuka UI tidak me-disable field `Select Product`. User berhasil menambahkan produk secara manual di tengah-tengah proses import.
  2. Setelah background import selesai, seluruh baris import ikut masuk sehingga total detail lines pada dokumen Sales Order menjadi **`102/100`** (melebihi batas maksimal kapasitas dokumen).
  3. **Backend Guard:** Saat di-approve, sistem memang menolak dengan pesan error `"This transaction has more than 100 details."`.
* **Kebutuhan Perbaikan (Action Item):**
  * Diperlukan mekanisme **UI Error Prevention** berupa penguncian (*disable/read-only state*) pada field `Select Product` dan tombol penambahan item selama terdapat background job import yang berstatus `processing` pada dokumen tersebut, guna mencegah data draft korup / over-quota sejak awal.
