# TC-SOG-15887-06: Proteksi Backend Approval terhadap Race Condition Penambahan Produk saat Import Sedang Berjalan

## Hasil Eksekusi & Evaluasi Requirement
* Ketika proses import 100 baris masih berstatus `process`, sistem mengizinkan penambahan manual 1 baris sehingga total detail lines menjadi **101 baris**.
* Dokumen dapat diubah statusnya menjadi Open. Namun saat di-approve, **backend guard berhasil memblokir approval** dengan pesan error `"This transaction has more than 100 details."` baik melalui tombol Approve form maupun melalui menu Dev - Sales Order.
