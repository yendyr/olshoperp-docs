# TC-SOG-15887-09: Import Terpisah (Multi-File / Sequential Import) dalam 1 Dokumen Sales Order

## Temuan Defect
1. **Urutan 1 (Bundle 50 lines -> Single 50 lines):**
   * Import bundle 25 baris sukses (detail lines = 50).
   * Import SKU single 50 baris gagal dengan error `'This transaction have more than 100 details.'`.
   * Saat baris single dikurangi menjadi 30 baris pun tetap gagal dengan error yang sama.
2. **Urutan 2 (Single 50 lines -> Bundle 50 lines):**
   * Import Single 50 baris sukses (tercatat total success row = 1).
   * Import Bundle 25 baris gagal (total failed row = 1) dengan pesan error `'This transaction have more than 100 details (75 details and 50 bundle details).'`.
