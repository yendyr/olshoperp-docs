# TC-SOG-15887-05: Penolakan Penambahan Produk saat Kapasitas Sudah Mencapai 100 Detail Lines

## Hasil Eksekusi
* Sistem secara konsisten memblokir penambahan produk baru saat detail order sudah mencapai 100 lines dengan pesan `"This transaction has more than 100 details."`.
* **Catatan Sidebar Import:** Pada sidebar import history, informasi `total failed row` tercatat `1` padahal isi baris file import ada 100 baris.
