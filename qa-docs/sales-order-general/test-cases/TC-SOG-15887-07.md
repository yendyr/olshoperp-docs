# TC-SOG-15887-07: Import Tepat 50 Baris SKU Bundle @2 Komponen (Boundary Test Limit 100 Detail Lines)

## Temuan Defect
* **Bug:** Import 50 baris SKU bundle (total 100 detail lines) ditolak dengan error log `'This transaction have more than 100 details (50 details and 100 bundle details).'`.
* **Analisis:** Formula validasi pada background import salah menjumlahkan baris header Excel dengan komponen bundle (`50 + 100 = 150`). Seharusnya perhitungan detail lines hanya mengambil komponen bundle (`100 detail lines`), sehingga kondisi ini harusnya lolos.
* **Catatan Sidebar:** Total failed row tercatat `1` di history import.
