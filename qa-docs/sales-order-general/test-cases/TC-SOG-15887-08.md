# TC-SOG-15887-08: Import Kombinasi 25 Baris Bundle dan 50 Baris Single (Total 100 Detail Lines)

## Temuan Defect
* **Bug:** Import kombinasi 25 baris bundle (@2 komponen = 50 detail lines) + 50 baris single (50 detail lines) yang berjumlah tepat 100 detail lines ditolak oleh sistem.
* **Analisis Error Log:** Pesan error `'This transaction have more than 100 details (75 details and 50 bundle details).'` membuktikan bahwa sistem menjumlahkan:
  `75 (total product line di Excel) + 50 (komponen bundle) = 125 detail lines`.
* Formula tersebut salah karena 25 baris header bundle dihitung dua kali (sebagai baris detail dan sebagai baris bundle).
