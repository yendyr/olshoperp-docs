# TC-SOG-16269-03: Verifikasi Nilai Grand Total Header SO Bebas dari Double-Counting Komponen Random Child

## Konteks Pengujian (Card ETM-16269)
Memverifikasi perbaikan bug kalkulasi grand total header Sales Order, di mana komponen *random child* tidak boleh ikut dihitung secara terpisah ke Grand Total (perhitungan grand total hanya bergantung pada header bundle).

## Precondition & Test Data
* Sales Order memuat item `SKU-TestBundle-small` (Qty: 1, Unit Price: Rp 43.000, VAT Exclude 10%).

## Langkah Pengujian
1. Buka form Sales Order dengan data di atas.
2. Periksa tabel ringkasan total di bagian bawah.
3. Simpan dokumen dan periksa nilai akhir.

## Expected Result
* **Subtotal:** `Rp 43.000`
* **VAT (10%):** `Rp 4.300`
* **Grand Total:** `Rp 47.300`
* Komponen `SKUBotolTumblr-random` tidak menyebabkan nilai Grand Total membengkak secara ganda.

## Hasil Eksekusi Pengujian (2026-10-13)
* **Status**: **PASSED** (Dieksekusi Manual oleh QA)
* **Jira Reference**: ETM-16451 (Clones ETM-16269)
* **Data Uji**:
  * Sales Order: `SO-5UQF22NU`
  * SKU Bundle: `SKU-TestBundle-small` (Unit Price: Rp 43.000, VAT Exclude 10%)
* **Temuan / Hasil Aktual**:
  * Nilai grand total header Sales Order sudah sesuai dengan perhitungan VAT type Exclude 10%.
  * Subtotal: Rp 43.000, VAT Amount: Rp 4.300, Grand Total: Rp 47.300.
