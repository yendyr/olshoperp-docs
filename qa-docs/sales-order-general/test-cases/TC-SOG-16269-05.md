# TC-SOG-16269-05: Cascade Delete Random Child saat Baris Bundle Dihapus dari Sales Order

## Konteks Pengujian (Card ETM-16269)
Memverifikasi perbaikan bug developer di mana penghapusan baris bundle di form Sales Order sebelumnya tidak menghapus record *random child*. Setelah perbaikan, seluruh *random child* harus terhapus bersih secara cascade.

## Precondition & Test Data
* Sales Order memuat item `SKU-TestBundle-small`.

## Langkah Pengujian
1. Buka dokumen Sales Order yang memuat `SKU-TestBundle-small`.
2. Hapus baris item bundle dengan menekan ikon Delete.
3. Simpan perubahan form Sales Order.
4. Buka kembali dan amati status kalkulasi.

## Expected Result
* Baris bundle dan seluruh komponen turunannya terhapus sempurna.
* Grand Total kembali menjadi `Rp 0`.
* Record *random child* di tabel random terhapus (tidak meninggalkan data orphan).
