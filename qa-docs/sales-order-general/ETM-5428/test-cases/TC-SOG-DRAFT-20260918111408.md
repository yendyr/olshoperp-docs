# Print SO Approved tidak menampilkan watermark VOIDED

Implements: `SC-SOG-5428-02` · Origin: [ETM-5428](https://erpintegration.atlassian.net/browse/ETM-5428) · Request ID: `none`

## Step-by-Step UI Crawling

1. Login staging → company **FAT** → `goto` `/businessdevelopment/sales-order-general`.
2. Filter datalist **Trx. Status** = Approved; buka link **Trx. Code**.
3. Verifikasi status Approved di header/form. Jangan Void / Close.
4. Klik **Print**. Assert di print out, bukan di datalist.
5. Catat apakah teks **VOIDED** muncul sebagai watermark. Selector Print tidak ada di docs.

## Catatan QA

- Negative = guard lingkup: VOIDED hanya untuk VOID (implikasi card + §3), bukan penolakan save.
- Company card PT KOMI hanya catatan; default FAT.
- Print expected = `[MENUNGGU REQUIREMENT]`.
