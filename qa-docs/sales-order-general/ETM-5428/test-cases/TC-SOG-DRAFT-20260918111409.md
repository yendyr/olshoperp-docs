# Print SO Closed tidak menampilkan watermark VOIDED (Closed bukan Void)

Implements: `SC-SOG-5428-03` · Origin: [ETM-5428](https://erpintegration.atlassian.net/browse/ETM-5428) · Request ID: `none`

## Step-by-Step UI Crawling

1. Login staging → company **FAT** → `goto` `/businessdevelopment/sales-order-general`.
2. Cari **Trx. Status** = Closed, atau dari Approved klik **Close Doc** lalu konfirmasi Closed.
3. Buka link **Trx. Code**. Status harus Closed — bila Void, ganti fixture (ini bukan SC-01).
4. Klik **Print**. Cek print out untuk absennya watermark **VOIDED**.
5. Selector Print tidak ada di docs. Jangan mengarang pesan error.

## Catatan QA

- Edge karena Closed sering disamakan dengan Void di operasional; SoT §3 / §7.5 memisahkannya.
- Company card PT KOMI hanya catatan; default FAT.
- Print expected = `[MENUNGGU REQUIREMENT]`.
