## 2. Kontrak data

### Master yang harus ada (lookup, jangan dibuat ulang)

- Company sesuai tabel di atas.
- Satu Variable Price yang **sudah dipakai** Category Price, untuk kasus hapus ditolak. Probe memakai code **VarP-001**. Jangan dihapus.
- Untuk cek section Used in Category Price yang terisi: Category yang memasang VarP-001 (atau master in-use lain di company yang sama).
- Crawl master saja **tidak** butuh SKU baru.

### Data yang dibuat crawl

- Prefix wajib: `QA-AUTO-`.
- Pola code: `QA-AUTO-VP-{timestamp}`.
- Pola name: `QA-AUTO Variable Price {timestamp}`.
- Contoh yang sempat dibuat 2026-10-14: code `QA-AUTO-VP-1791990197526`, name `QA-AUTO Variable Price 1791990197526`, type by Amount, margin percentage 5.
- Jangan memakai code master bisnis yang sudah ada (termasuk `VarP-001`) sebagai data buat.

### Bersihkan setelah run

1. Di daftar Variable Price, cari code berawalan `QA-AUTO-`.
2. Hapus hanya baris yang **tidak** dipakai Category Price.
3. Jangan hapus `VarP-001` atau master in-use lain.
4. Jika toast sukses tidak muncul dan baris tetap ada, catat sebagai temuan cleanup. Jangan mengulang hapus berkali-kali.
5. Tulis code yang tertinggal di log run.

Probe 2026-10-14 tidak berhasil menghapus `QA-AUTO-VP-1791990197526` (temuan CLEAN-01). Anggap code itu mungkin masih ada. Cek dulu sebelum membuat code baru; jangan bentrok.

### c. Audit Log (standar UAT)

- Label kolom dan field terbaca manusia (Code, Name, Type, Active), bukan nama kolom database.
- Tiap ubah field punya **nilai lama** dan **nilai baru**.
- Tidak boleh menampilkan id mentah (`Variable Price Id: 15`) atau enum mentah (`amount`, `percentage`, `Is Last: 1`) sebagai teks yang dibaca user.
- Create dan edit sama-sama masuk log.
- Requirement A-13: Start/End/Margin yang kosong tampil angka atau `Unlimited`, bukan strip. Old Value terisi saat baris diubah.

Probe 2026-10-14: ada 3 baris log dan label header terlihat terbaca, tetapi baris ubah name tidak menunjukkan old ke new dengan jelas, dan baris tier masih memuat id serta enum. Ini temuan **AUD-03**, kartu [ETM-16565](https://erpintegration.atlassian.net/browse/ETM-16565).

## 4. Relasi menu dan kapan regresi diulang

```
Variable Price --[Update to Category]--> Category Price --[Update to Pricelist]--> Pricelist Product
```

Perubahan master **tidak** otomatis mengubah Category atau Pricelist. User menekan **Update to Category**. Harga jual di Pricelist baru berubah setelah Category menjalankan **Update to Pricelist**.

| Kalau yang berubah | Ulangi bagian crawl ini |
|--------------------|-------------------------|
| Form atau validasi Variable Price | Pilar a, b, d, plus baseline toast di §6 |
| Komponen Audit Log bersama | Pilar c dan kartu ETM-16518 s/d ETM-16522 |
| Category Price (pilih tier, snapshot, Save All, Update from Master) | Section Used in, kunci Type, hapus in-use, Update to Category, dan pola Save All |
| Pricelist Product (hitung margin, hover, kolom weight) | Alur silang ETM-16476. Jangan cukup cek form Variable Price. |
| Hak akses Business Development | ETM-16473 |

Menu terdampak: `businessdevelopment-category-price` (ETM-16313), `businessdevelopment-pricelist-product` (ETM-16314).

Tooltip mass Update saat ada master terpilih yang belum dipakai (requirement §3): `{Code} is not used by any Category Price yet, so there is nothing to update.`
