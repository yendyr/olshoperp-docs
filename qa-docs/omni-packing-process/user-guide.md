# Packing Process — Panduan Pengguna

**Menu:** Omni → Packing Process · **Route:** `/omni/packing-process`

## Apa itu

Approve transfer tahap **packing** setelah checking. Setelah approve, order siap masuk jalur Collecting → Delivery Order → 3PL.

**Bukan** [Packing List](../omni-packing-list/user-guide.md) — itu pack item, bundle, shipping handoff (shipper/AWB).

## Langkah singkat

1. Pastikan checking selesai.
2. Scan / approve di Packing Process.
3. Lanjut Collecting / Delivery Order.

Settlement **tidak** otomatis di packing — outbound setelah order **Shipped**.
