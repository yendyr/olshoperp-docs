Implements: `SC-SKWP-15985-02` · Origin: [ETM-15985](https://erpintegration.atlassian.net/browse/ETM-15985) · Request ID: `none`

## Step-by-Step UI Crawling

1. Buka Skip Wave Process (merdian, read-only).
2. Buka slideover Log Data → tab Import logs.
3. Amati list default ≤20 row; catat waktu tampil.
4. Assert kolom §4.3 terlihat; catat residual bila lambat.
