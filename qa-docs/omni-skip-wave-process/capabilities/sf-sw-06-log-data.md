# Log Data — Import Logs

## Apa ini

Toolbar **Log Data** membuka riwayat upload: batch, hasil screening, dan pesan error per baris bila Import gagal.

## Kapan dipakai

- Upload gagal / Import Failed.
- Perlu tahu Order No mana yang bermasalah.
- Audit siapa yang upload dan kapan.

## Cara pakai

1. Klik **Log Data** di toolbar.
2. Pilih batch / entri log terkait.
3. Baca pesan error → perbaiki file.
4. Upload ulang seluruh file (tidak ada Retry Import).

## Catatan

- Bedakan Import Failed (screening) vs gagal di Wave setelah Import sukses.
- Setelah Completed, pekerjaan latar bisa masih jalan — bukan error Log Data.
