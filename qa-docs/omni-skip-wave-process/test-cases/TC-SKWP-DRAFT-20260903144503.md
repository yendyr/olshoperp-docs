### Temuan Defect / Bug:
1. **Inkonsistensi Konteks Data:** Kolom UI di grid dan label SearchBuilder tertulis **`Processing Start & End`**.
2. **Perilaku Sistem AS-IS:** SearchBuilder hanya mengeksekusi query `MIN(scm_skip_processing_logs.created_at)` yang hanya membaca **Processing Start**.
3. **Dampak:** User tidak dapat mencari data batch berdasarkan waktu selesai proses (*Processing End*).
4. **Rekomendasi Perbaikan:**
   - **Opsi 1 (Disarankan):** Pisahkan variabel di SearchBuilder menjadi 2 field mandiri: **`Processing Start`** dan **`Processing End`**.
   - **Opsi 2:** Perbaiki nama label menjadi `Processing Start` jika memang dirancang hanya memfilter waktu mulai.
