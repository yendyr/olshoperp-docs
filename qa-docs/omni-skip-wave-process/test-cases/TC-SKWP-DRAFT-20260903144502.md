### Temuan Defect / Bug:
1. **Inkonsistensi Konteks Data:** Kolom UI di grid dan label SearchBuilder tertulis **`Wave Start & End`**.
2. **Perilaku Sistem AS-IS:** SearchBuilder hanya mengeksekusi query `MIN(omni_unassign_wave_logs.created_at)` yang hanya membaca **Wave Start**.
3. **Dampak:** User tidak dapat mencari data batch berdasarkan waktu selesai unassign (*Wave End*).
4. **Rekomendasi Perbaikan:**
   - **Opsi 1 (Disarankan):** Pisahkan variabel di SearchBuilder menjadi 2 field mandiri: **`Wave Start`** dan **`Wave End`**.
   - **Opsi 2:** Perbaiki nama label menjadi `Wave Start` jika memang dirancang hanya memfilter waktu mulai.
