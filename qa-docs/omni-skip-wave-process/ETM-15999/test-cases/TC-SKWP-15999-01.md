# Retry hanya redispatch SO gagal (bukan seluruh chunk)

Implements: `SC-SKWP-15999-01` · Origin: [ETM-15999](https://erpintegration.atlassian.net/browse/ETM-15999) · Jira TC: [ETM-16053](https://erpintegration.atlassian.net/browse/ETM-16053) · Relates: [ETM-15988](https://erpintegration.atlassian.net/browse/ETM-15988)

## Step-by-Step UI Crawling

1. Buka Skip Wave Process; identifikasi batch siap/sedang retry (few SO gagal).
2. Amati siklus retry (Horizon/log bila tersedia).
3. Bandingkan jumlah redispatch vs jumlah SO retryable.
4. Assert SO sukses tidak ikut redispatch / tidak DO ganda.

## Catatan QA

- Gap-only vs Advanced Filter TC (ETM-15719). Bug acuan: `triggerProcessingPhase` me-chunk `lockable_ids` penuh saat retry.
- Jangan spam redispatch; jangan isi `last_execution` sampai run nyata.
