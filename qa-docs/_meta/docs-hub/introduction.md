**OlshopERP** is an ERP that brings Accounting, Sales/Omnichannel, and Supply Chain together in one platform — from an order coming in through warehouse work to financial reports.

## What is OlshopERP

OlshopERP is a **multi-module** ERP used across teams, not only by one department. Finance, sales/ops, warehouse, and admins work in the same product with shared masters and consistent status flows.

It is **company / tenant based**. Each company (for example FAT, Lumielle, or TANRISE on staging) has its own data and configuration. You sign in to the web app, then open this Help Center (`/docs`) whenever you need self-service documentation.

## Who it's for

| Persona | Typical use |
|---|---|
| Finance / Accounting | Invoices, payments, journals, financial reports |
| Sales / Ops (Omnichannel) | Orders, picking/packing, marketplace platforms |
| Warehouse / Inventory (Supply Chain) | Stock, PO/PR, transfers, warehouses |
| Admin / IT (Gate) | Users, roles, and access |
| Ops / Setup (General Setting) | Company profile, currency, region, shared masters |
| Client / tenant owner (new) | Cross-module overview and where to begin |

## Key concepts

- **Company / Tenant** — the company unit whose data is isolated from others.
- **Menu** — one feature unit (for example Purchase Order or Customer Invoice).
- **Documentation layers** — Knowledge Base, Feature Map, Requirement, Technical, and User Guide. Pick a module → menu → layer in Browse by module.
- **Approval flow** — many transactions (PO, stock opname, and similar) go through approve/reject before they are final.
- **Docs icon (`?`)** — contextual help on the menu you are using. This Help Center is the full library; the `?` icon stays as a shortcut on each menu.

## How to get started

1. Sign in to OlshopERP.
2. Learn the sidebar: **module → menu**.
3. Open Help Center anytime via **Help Center** in the profile menu (`/docs`), or click the **`?`** icon on the menu you have open.
4. **If you are internal staff** — start from the module that matches your role (see the table above).
5. **If you are a new client / tenant** — start in **General Setting** (company profile and masters) before your first transactional documents.
