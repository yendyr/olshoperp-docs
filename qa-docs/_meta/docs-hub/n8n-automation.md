### Architecture & catalog

Internal map of all n8n workflows, how they call each other, and which Telegram command or webhook starts each job. Open the [n8n Automation catalog](/docs/n8n-automation).

### Olshoperp dengan enduser

Intake from Lark form or Telegram, AI preview, Jira cards, pending reminder, and release notif back to the end-user group. Start at [Feedback User Automation](/docs/n8n-automation/feedback-user).

### Test Case & Bug

Create or clone test cases, gate FAILED/PASSED results, audit bugs against Notion requirements, and sync results back to Notion. Start at [Test Case Create & Clone](/docs/n8n-automation/test-case-create-clone).

### Meeting & Weekly Report

Draft or finalize meeting notes into Jira/Lark, then build the weekly Jira recap (optionally with notulen). Start at [Notulensi Meeting](/docs/n8n-automation/notulensi-meeting).
