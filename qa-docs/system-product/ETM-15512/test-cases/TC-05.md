# [TC-05] Expand Variant Group — child zero-relation → soft delete + regenerate

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2 GAP-SP-18**  
**Tag automation:** `@TC-ETM-15512-05`

Child Default tanpa relasi transaksi boleh diganti (soft delete) saat expand group baru.

## Precondition

- Master Default ON
- Buat produk Default (ikuti TC-01): parent `ETM15512-E5-{stamp}-(PARENT)`, child `ETM15512-E5-{stamp}`
- Pastikan child **belum** dipakai di PR/PO/inbound/outbound/transfer/SO/WO/binding/BOM/bundle
- Siapkan Variant Group baru (bukan Default) + opsi, mis. Warna: `merah`, `biru` — pastikan total group ≤ 3 termasuk Default

## Step

1. Edit parent Variant
2. Tambah Variant Group baru (Warna) + opsi
3. Save All / Save & Next
4. Catat daftar child SKU + product ID (jika terlihat di UI/audit)

## Expected

- **Tidak** muncul hard-block `Cannot add variant, Product already have relations`
- Child Default lama (`ETM15512-E5-{stamp}`) yang obsolete **soft-deleted** (zero relation)
- Kombinasi baru digenerate dengan **ID produk baru**
- SKU baru **omit** segment opsi Default (lihat juga TC-07)
- Tidak ada auto-rename ke opsi pertama group baru
- Tidak ada auto stock remap
