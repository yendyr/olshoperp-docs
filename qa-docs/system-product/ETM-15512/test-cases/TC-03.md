# [TC-03] Import Single-eligible + Default ON → sama create

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.1 Import**  
**Tag automation:** `@TC-ETM-15512-03`

Import baris kandidat Single (tanpa variant eksplisit) otomatis jadi Variant Default.

## Precondition

- Master Default ON
- Template Import New System Product tersedia
- SKU belum ada: `ETM15512-IMP1-{stamp}`
- Row import: Type/path Single atau kosong variant group+option; **bukan** parent row untuk SKU lain

## Step

1. System Product → Import New
2. Isi 1 row: SKU `ETM15512-IMP1-{stamp}` + kolom wajib; **jangan** isi Variant Group/Option; jangan jadikan Parent di row lain
3. Submit import
4. Cek datalist / edit hasil

## Expected

- Import sukses (tidak blank / tidak ditolak sebagai single invalid karena Default)
- Parent = `ETM15512-IMP1-{stamp}-(PARENT)`
- Child = `ETM15512-IMP1-{stamp}`
- Sama pola create Default ON (GAP-SP-17)
