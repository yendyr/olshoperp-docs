# [TC-02] OFF Enable Variations → confirmation → Single

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.1 V-02**  
**Tag automation:** `@TC-ETM-15512-02`

User boleh membatalkan path Default Variant dan kembali ke Single lewat confirm popup.

## Precondition

- Master Default ON
- Form create baru dengan SKU `ETM15512-C2-{stamp}` (atau edit draft hasil auto-default sebelum finalize — ikuti UI staging)
- Variations sudah ON karena Default (hasil TC-01 / auto create)

## Step

1. Di form System Product (create Default ON), pastikan Enable Variations **ON**
2. Matikan toggle **Enable Variations**
3. Amati popup confirmation
4. **Skenario A:** Cancel / No → Variations tetap ON
5. Ulangi OFF → **Skenario B:** Confirm / Yes → Save

## Expected

- Saat OFF: muncul **confirmation popup** sebelum jadi Single
- Cancel: produk tetap Variant (Default path)
- Confirm + Save: produk tersimpan sebagai **Single**; parent `-(PARENT)` / child Default **tidak** terbentuk (atau dibatalkan sesuai implementasi TO-BE)
- Tidak ada error hard-crash; mengikuti existing rules Single
