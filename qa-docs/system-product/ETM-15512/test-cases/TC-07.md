# [TC-07] Naming omit Default segment + kolom Default hidden di datatable

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.1 / §6.3.2 V-07**  
**Tag automation:** `@TC-ETM-15512-07`

SKU kombinasi baru tidak menyertakan nama opsi Default; kolom Default di datatable variant disembunyikan (fase 1 UI).

## Precondition

- Hasil expand dari TC-05 atau TC-06 (produk Default-origin yang sudah punya group tambahan)
- Opsi Default master diketahui (mis. `Standard`)

## Step

1. Buka edit parent Variant → section datatable variant
2. Catat header kolom dynamic variant
3. Catat semua SKU child hasil generate setelah expand

## Expected

- Kolom dynamic untuk **Default group** `visible: false` (tidak tampil di datatable fase 1)
- SKU baru **bukan** pola `…-{DefaultOpt}-biru-…`  
  Contoh benar: `SKUPENSIL-biru-pikacu`  
  Contoh salah: `SKUPENSIL-Standard-biru-pikacu`
- Default group tetap menghitung ke **max 3** types (tidak bisa tambah group ke-4 jika Default + 2 group lain sudah ada)
