# [TC-01] Create + Default ON → parent `SKU-(PARENT)` + child = user SKU

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.1 / GAP-SP-17**  
**Tag automation:** `@TC-ETM-15512-01`

Saat Master Default ON, create System Product otomatis jadi Variant tanpa Enable Variations manual.

## Precondition

- Login + company uji (lihat README test-cases)
- Master Variant Default ON + 1 opsi (mis. `Standard`)
- SKU uji belum ada: `ETM15512-C1-{stamp}`

## Step

1. Buka **System Product** → **Create**
2. Isi SKU `ETM15512-C1-{stamp}` + field wajib lain (name, unit, COA group, dll. sesuai form)
3. **Jangan** klik Enable Variations manual
4. Save (Save & Next / Save All sesuai UI)
5. Buka datalist / halaman edit parent — catat SKU parent & child

## Expected

- Enable Variations **ON** otomatis; Default group + 1 opsi terpasang
- Parent SKU = `ETM15512-C1-{stamp}-(PARENT)` (literal suffix `-(PARENT)`)
- Child SKU = `ETM15512-C1-{stamp}` (tanpa suffix opsi Default di kode)
- Tipe parent = PARENT / Variant parent; child transactable
- Default group tetap tampil di bawah toggle (sementara, sesuai kartu)
