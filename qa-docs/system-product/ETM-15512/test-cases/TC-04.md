# [TC-04] Import skip auto-default (explicit variant / parent-used)

**Kartu:** [ETM-15512](https://erpintegration.atlassian.net/browse/ETM-15512)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.1 V-03**  
**Tag automation:** `@TC-ETM-15512-04`

Auto-default **hanya** untuk kandidat Single; row variant eksplisit atau SKU yang dipakai Parent di row lain di-skip.

## Precondition

- Master Default ON
- Siapkan file import minimal 2 skenario (boleh 2 file atau 1 file multi-row):

**Skenario A — explicit variant:**  
SKU `ETM15512-IMP2A-{stamp}` dengan Variant Group + Option terisi (bukan Default path)

**Skenario B — parent-used:**  
Row parent `ETM15512-IMP2B-{stamp}` + row child yang merefer Parent tersebut (pola import variant existing)

## Step

1. Import skenario A → cek hasil SKU
2. Import skenario B → cek hasil parent/child
3. Bandingkan: tidak boleh paksa jadi `…-(PARENT)` + child = user SKU ala Default jika sudah explicit / parent-used

## Expected

- Skenario A: **Skip** auto-default; naming mengikuti kolom variant yang diisi user
- Skenario B: **Skip** auto-default untuk SKU yang dipakai sebagai Parent
- Tidak mengubah / merusak mapping Parent–Child yang user nyatakan di file
