# Import Product Images Excel - Error Log Format & Validation Accuracy

## Deskripsi
Memverifikasi bahwa fitur **Import Product Images** menangani *Partial Success* dengan akurat dan menghasilkan pesan error log yang sesuai dengan penyebab kegagalan sebenarnya.

## Langkah Pengujian
1. Buka menu **System Product** (`/supplychain/product`).
2. Klik dropdown **Import** -> pilih **Import Product Images**.
3. Upload file Excel berisi 4 baris child SKU (`SKUCERMIN`): 2 file valid `< 1 MB`, 1 file `> 1 MB`, dan 1 file ber-ekstensi/format HTML.
4. Pantau progress import hingga selesai.
5. Periksa rincian pesan error pada **Import Log**.

## Hasil Eksekusi & Catatan QA
- Status: **FAILED** (Misleading Error Message)
- Actual Result: Pesan error untuk file HTML keliru mengutip akses publik GDrive (`The Google Drive file is not publicly accessible...`), padahal file di folder publik yang sama, hanya saja format fisiknya HTML.
