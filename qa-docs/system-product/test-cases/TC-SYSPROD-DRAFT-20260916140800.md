# [System Product] Upload Gambar pada Spesifik Varian Meng-update Varian Terpilih Tanpa Menimpa Varian Lain

## Deskripsi
Memverifikasi perbaikan issue ETM-15944, di mana sebelumnya ketika mengunggah gambar untuk satu varian child tertentu pada produk dengan default variant aktif, gambar tersebut justru meng-update dan menimpa seluruh varian child di bawah parent yang sama. Setelah perbaikan, gambar varian terisolasi khusus ke varian child yang diunggah.

## Langkah Pengujian
1. Login dan switch ke company **Dev Staging** (ID: 13).
2. Buka menu **System Product** (`/supplychain/product`).
3. Buka halaman Edit produk bervarian (atau buat produk bervarian jika belum ada).
4. Navigasi ke accordion **Product Details** -> tabel varian child.
5. Unggah file gambar pada input file baris varian child spesifik.
6. Tunggu respons API update image (`PUT /api/supplychain/product/specification/inline-update-image/{child_id}`).
7. Verifikasi bahwa gambar pada baris varian child tersebut berubah, sementara baris varian child lainnya tidak berubah.

## Kriteria Kelulusan
- Baris varian child target memiliki gambar preview yang baru.
- Baris varian child lainnya tidak berubah dan tidak ikut tertimpa.
