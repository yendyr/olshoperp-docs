# Import File Gambar 0 KB via Google Drive (Empty File Rejection)

## Deskripsi
Memverifikasi bahwa sistem menolak pengunggahan file gambar kosong (0 KB / corrupt file) dari Google Drive saat proses Import Product Images.

## Langkah Pengujian
1. Buka menu **System Product** (`/supplychain/product`).
2. Klik dropdown **Import** -> pilih **Import Product Images**.
3. Upload file Excel yang menunjuk ke file gambar 0 KB di Google Drive.
4. Selesaikan proses import dan amati respon sistem.
5. Refresh halaman produk.

## Hasil Eksekusi & Catatan QA
- Status: **FAILED** (Bug Found)
- Actual Result: Import dianggap sukses dengan message `'The data has been success updated'`, dan file 0 KB ter-persist di DB/storage setelah halaman di-refresh.
