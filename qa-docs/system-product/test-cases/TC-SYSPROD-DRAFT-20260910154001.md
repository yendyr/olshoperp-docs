# Upload Manual Foto Produk > 1 MB (Validation Error & Prevention 500)

## Deskripsi
Memverifikasi bahwa sistem menolak pengunggahan file foto produk manual yang berukuran > 1 MB secara bersih melalui validasi UI/API tanpa memasukkan gambar ke preview UI dan tanpa memicu error 500 saat Save All.

## Langkah Pengujian
1. Buka menu **System Product** (`/supplychain/product`).
2. Pilih salah satu produk aktif lalu klik **Edit**.
3. Navigasi ke accordion **Product Details** -> tab **Photos**.
4. Upload 1 file foto gambar `.jpg` dengan ukuran `> 1 MB` (contoh: 1.2 MB).
5. Amati respon UI dan notifikasi yang muncul.
6. Klik tombol **Save All**.

## Hasil Eksekusi & Catatan QA
- Status: **FAILED**
- Actual Result: Gambar ter-insert di preview UI. Saat klik Save All, memicu 2 notifikasi error di mana notif ke-2 (`Trying to access array offset on null`) menutupi notif ke-1 dan terjadi HTTP 500 Error backend.
