# [TC-06] Expand — child zero relation → soft delete + regenerate

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2 / GAP-SP-18**  
**Tag automation:** `@TC-ETM-15495-06`

Child tanpa relasi dokumen harus **soft deleted** saat expand (bukan leftover); kombinasi baru dengan product ID baru.

## Precondition

- Parent Variant baru `ETM15495-P6-{stamp}` dengan 1 group Warna (`biru`, `hijau`)
- Child `…-biru`, `…-hijau` **tanpa relasi** (no PR/PO/inbound/outbound/transfer/SO/WO/binding/BOM/bundle)
- Stok child boleh 0 (ideal) — fokus uji **zero relation**, bukan leftover
- Group kedua siap: Motif `doraemon`, `pikacu`

## Step

1. Edit parent → catat product ID child lama (jika terlihat di URL/network)
2. Tambah Variant Group **Motif** + opsi → Save All
3. Jika popup muncul → Confirm (leftover path tidak diharapkan)
4. Cek datalist child & product ID

## Expected

- Child lama **soft deleted** — tidak muncul sebagai leftover Active
- Kombinasi baru 2×2 terbentuk dengan **product ID baru**
- Tidak ada hard-block `Cannot add variant, Product already have relations`
- Fail jika: child lama tetap Active sebagai leftover padahal zero relation
