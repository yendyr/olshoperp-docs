# [TC-07] Expand — stok saja tanpa relasi dokumen → soft delete (bukan leftover)

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2** (stok bukan syarat tunggal leftover)  
**Tag automation:** `@TC-ETM-15495-07`

Memiliki stok di gudang **tanpa** relasi dokumen tidak cukup memicu leftover — child lama soft delete.

## Precondition

- Parent Variant `ETM15495-P7-{stamp}`, 1 group Warna (`biru`, `hijau`)
- Child `…-biru` punya **stok > 0** via Opening Stock / Stock Addition
- Child **zero relation** dokumen (verifikasi: tidak ada SO/PO/inbound/outbound/dll.)
- Catat gudang + qty sebelum expand

## Step

1. Edit parent → catat SKU + qty stok child `…-biru`
2. Tambah group Motif (`doraemon`, `pikacu`) → Save / Confirm jika ada popup
3. Cek apakah child `…-biru` masih Active sebagai leftover

## Expected

- Stok **bukan** syarat tunggal untuk leftover
- Tanpa relasi dokumen → child lama **soft delete**, bukan leftover
- Stok tidak auto-remap ke SKU kombinasi baru
- Fail jika: child lama tetap Active leftover hanya karena punya stok tanpa relasi dokumen

**Catatan:** Jika inbound/stock addition membuat relasi terhitung `haveRelations()`, dokumentasikan di result — setup ulang dengan stok tanpa relasi dokumen.
