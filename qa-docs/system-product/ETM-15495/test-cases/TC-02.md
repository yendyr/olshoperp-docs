# [TC-02] Confirm popup leftover — Cancel vs Confirm

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2 UX confirm**  
**Tag automation:** `@TC-ETM-15495-02`

Expand yang menghasilkan leftover wajib popup; Cancel tidak mengubah data.

## Precondition

- Produk Variant existing, child **sudah punya stok > 0** (boleh hasil TC-01 **sebelum** expand, atau parent baru `ETM15495-P2-{stamp}` + stok)
- Belum di-expand ke group kedua (masih 1 group)

## Step

1. Edit parent → tambah Variant Group baru + opsi
2. Save
3. Amati popup confirmation (leftover / SKU baru / stok tidak pindah otomatis — teks mengikuti UI)
4. **Skenario A — Cancel / No**
   - Klik Cancel
   - Cek daftar child = sama seperti sebelum save
5. Ulangi tambah group (jika form ter-reset, isi ulang)
6. **Skenario B — Confirm / Yes**
   - Confirm → commit
   - Cek leftover + SKU baru muncul

## Expected

- Popup **wajib** muncul sebelum commit leftover
- Cancel: tidak ada group baru, tidak ada SKU baru, stok child lama tidak berubah
- Confirm: expand ter-commit (lanjut cek TC-01 / TC-03)
- Fail jika: save langsung tanpa popup, atau Cancel tetap mengubah child
