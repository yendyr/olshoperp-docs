# [TC-05] Max 3 variant types tetap berlaku setelah expand

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3** max 3 types (GAP-SP-06, FE)  
**Tag automation:** `@TC-ETM-15495-05`

Unlock expand + stok **tidak** mengendurkan batas 3 Variant Group.

## Precondition

- Parent sudah punya **2** group (hasil expand TC-01: Warna + Motif) **atau** siapkan 2 group + stok di child
- Master Variant punya group ketiga (mis. Ukuran: `S`, `M`) dan group keempat (jika ada) untuk uji tolak

## Step

1. Edit parent yang sudah 2 group + leftover/stok
2. Tambah group ke-3 (Ukuran) + opsi → Save / Confirm jika leftover
3. Pastikan group ke-3 tersimpan (total 3)
4. Coba tambah group ke-4

## Expected

- Group ke-3 **boleh** (masih dalam max 3), generate kombinasi baru mengikuti aturan leftover/zero-relation
- Group ke-4 **ditolak** / kontrol UI tidak mengizinkan (max 3)
- Fail jika: bisa simpan 4 group, atau group ke-3 ditolak hanya karena “sudah punya stok”
