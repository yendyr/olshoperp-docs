# [TC-08] Regresi — hard-block lama tidak muncul saat expand dengan stok/relasi

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2** (cabut hard-block)  
**Tag automation:** `@TC-ETM-15495-08`

AS-IS menolak expand dengan pesan `Cannot add variant, Product already have relations` — TO-BE diganti confirm + leftover.

## Precondition

- Produk sama setup TC-01: child sudah punya **stok > 0** dan/atau relasi transaksi
- Belum expand ke group kedua

## Step

1. Edit parent → tambah Variant Group baru + opsi
2. Klik Save / Save All
3. Perhatikan response **sebelum** confirm (toast, modal error, HTTP error)

## Expected

- Pesan **`Cannot add variant, Product already have relations`** **tidak** muncul sebagai blocker
- Flow lanjut ke **confirmation popup** leftover (lihat TC-02) atau commit sukses setelah confirm
- Fail jika: save ditolak dengan hard-block lama tanpa opsi confirm/expand
