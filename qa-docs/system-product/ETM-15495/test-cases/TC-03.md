# [TC-03] Stok tetap di leftover — tidak auto-remap, tidak auto-rename

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` §6.3.2 · `qa-docs/accounting-stock-remapping/requirement.md`  
**Tag automation:** `@TC-ETM-15495-03`

Stok child lama tidak pindah ke SKU kombinasi baru. Operator remap manual jika perlu.

## Precondition

- Selesai expand Confirm (hasil TC-01 atau TC-02 B)
- Catat **sebelum expand**: child leftover, gudang, qty (contoh child `…-biru` qty 10)
- Menu Stock Remapping bisa dibuka untuk cek (tidak wajib remap di TC ini)

## Step

1. Dari edit System Product / datalist, buka leftover child yang tadi berstok
2. Catat qty stok leftover (kolom stock / Stock Monitoring)
3. Buka salah satu SKU **baru** hasil kombinasi (contoh `…-biru-doraemon`)
4. Catat qty stok SKU baru
5. Pastikan SKU leftover **tidak** berubah nama otomatis ke opsi group baru
6. (Opsional, bukan AC kartu) Buka **Stock Remapping** — Origin leftover, Remapped To SKU baru 1 parent: mapping **masih manual**, belum terjadi sendiri

## Expected

- Qty leftover **sama** seperti sebelum expand (stok tidak hilang / tidak pindah)
- SKU baru stok **0** / kosong (belum ada mutasi)
- Leftover tetap **Active**
- Tidak ada auto-rename leftover
- Fail jika: stok leftover jadi 0 dan pindah ke SKU baru tanpa Stock Remapping
