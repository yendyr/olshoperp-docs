# [TC-01] Expand Variant Group pada child yang sudah punya stok

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3.2 / GAP-SP-18**  
**Tag automation:** `@TC-ETM-15495-01`

Produk existing yang child-nya sudah punya stok harus bisa ditambah Variant Group baru (tidak hard-block).

## Precondition

- Login + company uji
- Buat (atau pakai) parent Variant 1 group saja, contoh:
  - Parent: `ETM15495-P1-{stamp}`
  - Group Warna opsi `biru`, `hijau`
  - Child: `ETM15495-P1-{stamp}-biru`, `ETM15495-P1-{stamp}-hijau`
- Pastikan **minimal 1 child punya stok > 0** (Opening Stock / Stock Addition / inbound — catat gudang + qty)
- Group kedua siap di Master Variant, mis. Motif: `doraemon`, `pikacu`
- Total group setelah expand = 2 (≤ 3)

## Step

1. Buka **System Product** → cari parent `ETM15495-P1-{stamp}` → **Edit**
   URL pola: `https://staging.olshoperp.com/supplychain/product/edit/{id}`
2. Catat daftar child + qty stok child yang berstok (screenshot / tulis angka)
3. Tambah **Variant Group** baru (Motif) + opsi `doraemon`, `pikacu`
4. Save All / Save & Next
5. Jika muncul confirmation leftover → **Confirm**
6. Refresh / tetap di edit parent — catat semua SKU child

## Expected

- **Tidak** muncul `Cannot add variant, Product already have relations`
- Child lama **tetap ada** (leftover), Active, parent sama
- Semua kombinasi baru terbentuk (4 SKU baru untuk 2×2)
- Fail jika: save ditolak / child lama hilang / kombinasi baru tidak lengkap
