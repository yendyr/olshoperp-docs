# [TC-04] Naming SKU baru mengikuti fungsi existing

**Kartu:** [ETM-15495](https://erpintegration.atlassian.net/browse/ETM-15495)  
**Docs:** `qa-docs/system-product/requirement.md` — **§6.3** Auto-generate SKU `{parent}-{opt1}-{opt2}`  
**Tag automation:** `@TC-ETM-15495-04`

Generate SKU setelah tambah group tetap pola existing — bukan pola acak / auto-rename leftover.

## Precondition

- Produk uji **bukan** Default-origin `-(PARENT)` (supaya pola murni existing; Default-origin = ETM-15512 TC-07)
- Parent SKU diketahui, contoh `ETM15495-P1-{stamp}`
- Group 1 Warna: `biru`, `hijau`
- Group 2 Motif: `doraemon`, `pikacu`
- Expand sudah Confirm

## Step

1. Edit parent → datatable variant / datalist child
2. Tulis semua SKU child (leftover + baru)
3. Bandingkan dengan matriks kombinasi 2×2

## Expected

Leftover (SKU lama tetap):

```
ETM15495-P1-{stamp}-biru
ETM15495-P1-{stamp}-hijau
```

SKU baru (contoh):

```
ETM15495-P1-{stamp}-biru-doraemon
ETM15495-P1-{stamp}-hijau-doraemon
ETM15495-P1-{stamp}-biru-pikacu
ETM15495-P1-{stamp}-hijau-pikacu
```

- Leftover **tidak** di-rename menjadi `…-biru-doraemon` secara otomatis
- Fail jika: leftover berubah kode, atau kombinasi baru tidak lengkap / urutan segment salah vs fungsi existing

**Catatan QA:** Produk Default-origin (`SKU-(PARENT)`) meng-omit segment opsi Default — diuji di ETM-15512, bukan AC utama kartu ini.
