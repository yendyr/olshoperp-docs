# Bill of Material — Panduan Pengguna

**Menu:** Supply Chain → Bill of Material

Menandai SKU sebagai **Header BOM** dan mengisi **komponen** untuk assembly. Satu SKU header = maksimal satu BOM (tanpa versioning).

1. Create — Refer from System Product atau Create New.
2. Isi detail komponen (SKU + qty + unit).
3. Aktifkan — baru bisa dipakai di transaksi Assembly.
4. Variant: tiap variant header punya detail sendiri.
