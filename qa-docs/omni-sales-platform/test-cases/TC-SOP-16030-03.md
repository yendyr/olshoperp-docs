# TC-SOP-16030-03: Verifikasi Order Lifecycle Slideover XL pada Order dengan Sales Return

## Deskripsi Pengujian
Memvalidasi fungsionalitas panel Order Lifecycle pada skenario order yang memiliki retur barang pasca-settlement, mencakup:
1. Ukuran panel slideover XL (900px).
2. Dampak pengurangan retur dan refund pada Strip Quantity dan Strip Money.
3. Keterisian node timeline Return dan kevalidan hyperlink menuju Sales Return (`/supplychain/sales-returns/edit/{id}`) serta Credit Note (`/accounting/credit-note/edit/{id}`).
