# TC-SOP-16030-02: Verifikasi Order Lifecycle Slideover XL pada Order dengan Failed Ship

## Deskripsi Pengujian
Memvalidasi fungsionalitas panel Order Lifecycle pada skenario order yang mengalami Failed Ship (gagal kirim), mencakup:
1. Ukuran panel slideover XL (900px).
2. Dampak pengurangan nilai Failed Ship pada Strip Quantity dan Strip Money.
3. Keterisian node timeline Failed Ship dan kevalidan hyperlink menuju dokumen Failed Ship (`/supplychain/failed-ship/edit/{id}`).
