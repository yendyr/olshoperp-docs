# TC-SOP-16030-04: Verifikasi Order Lifecycle Slideover XL pada Order Status Awal (Draft / Open)

## Deskripsi Pengujian
Memvalidasi fungsionalitas panel Order Lifecycle pada skenario order yang masih berada di status awal (Draft atau Open), mencakup:
1. Aksesibilitas slideover tanpa status gate (dapat dibuka kapan pun).
2. Ukuran panel slideover XL (900px).
3. Penanganan tampilan data intake awal dan status kosong (graceful empty handling) pada tahapan downstream tanpa error 500 / blank screen.
