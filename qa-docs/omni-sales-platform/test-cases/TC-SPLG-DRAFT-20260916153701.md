# TC-SPLG-DRAFT-20260916153701: Pembentukan Komponen Bundle & Detail Tree Saat Binding Platform Product via Single Binding

## Objective
Memvalidasi bahwa saat proses Single Binding manual dilakukan per SKU platform yang terdapat pada pesanan Sales Platform berkondisi unbinded (`product_id = null`) ke System Product bertipe BUNDLE, sistem berhasil membentuk baris pohon komponen anak pada tabel `omni_sales_order_detail_trees` dan baris detail anak pada `omni_sales_order_details`, serta melepaskan order dari status Failed Process.

## Preconditions
1. User login ke OlshopERP Staging (`staging.olshoperp.com`) dengan scope company `FAT`.
2. Terdapat pesanan Sales Platform baru (`SO-TEST-SINGLE-01`) di mana salah satu item produk platform masih berstatus *Not Binded* (`product_id = null`).
3. Status pesanan saat ini berada pada **Failed Process** dengan error flagging unbinded.
4. Terdapat System Product bertipe **BUNDLE** (`SKU-BUNDLE-SINGLE-01`) dengan master Bill of Materials (BOM) aktif (contoh: 2 unit `KOMPONEN-A` dan 1 unit `KOMPONEN-B`).

## Test Steps
1. Buka menu **Omni Channel → Product Binding** (`/omni/product-binding`).
2. Pilih Store / Channel tempat order berasal melalui dropdown filter toko.
3. Cari SKU platform yang bersangkutan (status *Not Binded*).
4. Klik tombol **Action / Bind Manual** pada baris produk tersebut.
5. Pada popup modal picker System Product, pilih `SKU-BUNDLE-SINGLE-01` lalu klik tombol **Save / Submit**.
6. Tunggu hingga notifikasi sukses binding muncul.
7. Buka menu **Omni Channel → Sales Platform** (`/omni/sales-order`).
8. Buka halaman detail pesanan `SO-TEST-SINGLE-01`.
9. Periksa struktur baris detail item pesanan dan kolom error flag.

## Expected Results
1. Nilai `omni_sales_order_details.product_id` pada baris header order ter-update dengan ID System Product Bundle `SKU-BUNDLE-SINGLE-01`.
2. Tabel `omni_sales_order_detail_trees` terisi data relasi parent-child yang menghubungkan header SO detail dengan seluruh komponen anak bundle.
3. Detail pesanan menampilkan baris-baris komponen bundle (`KOMPONEN-A` dan `KOMPONEN-B`) dengan quantity yang terhitung secara proporsional sesuai rasio BOM.
4. Error flag *"The product currently linked to the system doesn't have all its bundle details. Please fill in the product bundle details first."* dan flag `bind-error` otomatis **CLEAR / HILANG**.
5. Status order berhasil bertransisi keluar dari **Failed Process** menjadi status yang siap diproses (**Ready to Process / Open**).
