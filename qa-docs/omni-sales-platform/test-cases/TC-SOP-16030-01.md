# TC-SOP-16030-01: Verifikasi Order Lifecycle Slideover XL, Real Data Flow, dan Hyperlink Timeline Lintas 4 Skenario Profil Order

## Deskripsi Pengujian
Pengujian komprehensif pada card **ETM-16030** (`[Sales Platform] - Order Lifecycle slideover xl, data real, timeline link`) yang mencakup perbaikan ukuran slideover, dynamic currency, akurasi kalkulasi strip (Quantity & Money), serta validasi seluruh hyperlink dokumen terkait pada timeline lintas 4 profil data order.

---

| 1 | **Normal / Fulfilled & Invoiced** | *(isi nomor SO / link)* | Delivered / Closed | Qty Kept = Qty Order; Link DO, SI, AR aktif; Failed Ship & Return = 'no recorded' | [ ] PASS<br>[ ] FAIL |
| 2 | **Order dengan Failed Ship** | *(isi nomor SO / link)* | Failed Ship / Partial | Nilai Failed Ship mengurangi Qty & Invoiced; Link dokumen Failed Ship (`/supplychain/failed-ship/edit/{id}`) valid | [ ] PASS<br>[ ] FAIL |

## Checklist Detail Verifikasi Slideover (ETM-16030)

### 1. Layout & Tampilan (Slideover XL)
- [ ] Lebar slideover menggunakan ukuran `xl` (lebar layar lebih leluasa, tidak sempit seperti versi sebelumnya).
- [ ] Tombol header `Print Summary` dan `Done` tampil rapi di sudut kanan atas.
- [ ] Tombol `Done` menutup panel slideover seketika.

### 2. Strip Ringkasan (Real Data & Dynamic Currency)
- [ ] **Strip Quantity:**
  $$\text{Total Order Qty} - \text{Failed Ship} = \text{Delivered \& Invoiced} - \text{Returned} = \text{Kept by Buyer}$$
- [ ] **Strip Money:**
  $$\text{Order Amount} - \text{Failed Ship Value} = \text{Invoiced} - \text{Platform Fee} = \text{Received in Bank} - \text{Refunded} = \text{Money Kept}$$
- [ ] Simbol currency dinamis mengikuti data order (misal `Rp`), tidak ada currency hardcode `$`.

### 3. Hyperlink Dokumen Timeline & Related Transactions
- [ ] **Picking List:** link membuka `/omni/picking-list/edit/{id}`
- [ ] **Checking List:** link membuka `/omni/checking-list/edit/{id}`
- [ ] **Packing List:** link membuka `/omni/packing-list/edit/{id}`
- [ ] **Outbound / DO:** link membuka `/supplychain/mutation-outbound/edit/{id}`
- [ ] **Failed Ship:** link membuka `/supplychain/failed-ship/edit/{id}`
- [ ] **Sales Invoice (SI):** link membuka `/accounting/customer-invoice/edit/{id}`
- [ ] **Customer Payment (AR):** link membuka `/accounting/customer-payment/edit/{id}`
- [ ] **Sales Return:** link membuka `/supplychain/sales-returns/edit/{id}`
- [ ] **Credit Note:** link membuka `/accounting/credit-note/edit/{id}`
