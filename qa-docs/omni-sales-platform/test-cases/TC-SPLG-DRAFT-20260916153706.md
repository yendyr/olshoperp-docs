# TC-SPLG-DRAFT-20260916153706: Verifikasi Remediasi Data Fix untuk Order Platform Existing Terdampak di Server Merdian

## Objective
Memastikan bahwa script data fix / migration yang dijalankan di server Merdian berhasil me-restore relasi `omni_sales_order_detail_trees` dan baris anak bundle pada pesanan existing yang sebelumnya terflagging error akibat issue ini.

## Preconditions
1. Server: **Production Merdian** (`merdian.olshoperp.com`).
2. Terdapat order terdampak: `SO-5UC1AKJX` (Detail SO ID: `1609439`).
3. Produk bundle yang terhubung: `BATHBRUSH-white;bbss` (`scm_products.id = 12847`) dengan komponen BOM: `BATHBRUSH-white` dan `bbss`.
4. Order saat ini terflagging Failed Process dengan pesan:
   *"The product currently linked to the system doesn't have all its bundle details. Please fill in the product bundle details first."*

## Test Steps
1. Jalankan script remediasi / artisan data fix yang telah disiapkan developer (Achmad Alvin Ardiansyah) dan disetujui Pak Yendy / Dlomiri.
2. Jalankan query database level untuk memverifikasi tabel `omni_sales_order_detail_trees` dengan filter `parent_id = 1609439`.
3. Buka URL detail pesanan di server Merdian:
   https://merdian.olshoperp.com/omni/sales-order/edit/981967
4. Klik tombol aksi **Re-validate / Refresh Status Order**.

## Expected Results
1. Tabel `omni_sales_order_detail_trees` terisi relasi parent detail ID `1609439` dengan detail baris anak komponen `BATHBRUSH-white` dan `bbss`.
2. Baris komponen anak bundle tampil lengkap pada halaman detail pesanan.
3. Pesan error bundle hilang dari halaman detail pesanan.
4. Status pesanan `SO-5UC1AKJX` keluar dari **Failed Process** dan siap diproses ke tahap alur operasional selanjutnya.
