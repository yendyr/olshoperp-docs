# [TC-01] Code invalid — max 50 & no spaces

**Tag:** `@TC-WHSTR-VAL-01`  
**Requirement:** V-01 (`code` required, max 50, no spaces)

## Step

1. Warehouse Structure → Create
2. **Name** valid, **Type** bebas (mis. 19. Building)
3. **Kondisi A — Code >50 karakter tanpa spasi** → Save & Next
4. Pastikan save gagal, lalu lanjut kondisi B (buat ulang / ganti Code)
5. **Kondisi B — Code <50 karakter dengan spasi** → Save & Next

## Expected

- Dokumen **gagal** disimpan (tetap di create)
- **Kondisi A:** error terkait Code max 50 (V-01 `max:50`)
- **Kondisi B:** error mengandung `code cannot contain spaces` (AS-IS staging: *Failed to create or update data. Field code cannot contain spaces…*)

[CATATAN QA] Pesan spasi hanya untuk kondisi B. Kondisi A mengacu `max:50`, bukan pesan spaces.
