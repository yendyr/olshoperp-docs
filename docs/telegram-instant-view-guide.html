Telegram Bot Instant View Integration

Solusi Pencegahan Limit 4.096 Karakter & Tampilan Panduan/SOP Elegan di HP via Telegraph API

📌 Background & Tujuan

Ketika asisten bot (Antigravity CLI / LLM) menghasilkan jawaban panduan komprehensif, SOP panjang, atau modul lengkap, pesan seringkali melampaui batas native Telegram.

❌ Masalah Saat Ini

  • Limit 4.096 karakter Telegram memotong teks di tengah jalan (teks terputus).
  • Chat bubble menjadi sangat panjang dan sulit dibaca di layar HP.
  • Format tabel atau markdown kompleks sering rusak/terlipat.

✅ Solusi Instant View (Telegraph)

  • 0 limit karakter (mampu memuat panduan puluhan ribu kata).
  • Muncul tombol ⚡ INSTANT VIEW resmi di aplikasi Telegram.
  • Membuka artikel secara instan, bersih (*reader mode*), tanpa kuota eksternal.
⚡ Arsitektur Logika Pengiriman (Smart Routing)
1

Eksekusi CLI & Cek Panjang Output

Script bridge di server menerima output teks dari perintah Antigravity CLI, lalu mengecek total panjang karakter (Threshold: 800 karakter).

2

Cabang Routing

• Output Singkat (< 800 char): Langsung kirim ke Telegram seperti biasa.
• Output Panjang (≥ 800 char): Terbitkan ke Telegraph API ➔ Dapatkan link artikel.

3

Kirim Summary + Link ke Telegram

Bot hanya mengirim ringkasan eksekutif (3-5 poin) + link Telegraph. Telegram secara otomatis menyematkan tombol Instant View.

💻 Panduan Implementasi Teknis (Step-by-Step)

Langkah 1: Buat Akun Telegraph (Hanya 1x di Awal)

Jalankan perintah cURL ini di terminal server untuk mendapatkan token akses gratis:

Terminal (cURL) 
curl "https://api.telegra.ph/createAccount?short_name=OlshopERP&author_name=OlshopERP+Assistant"

Simpan nilai access_token dari JSON response ke dalam .env server (misal: TELEGRAPH_ACCESS_TOKEN=...).

Langkah 2: Buat Helper Telegraph di Server

Pilih bahasa pemrograman yang dipakai oleh runner bot kamu (Node.js atau Python):

Node.js Helper (telegraphHelper.js) 
const TELEGRAPH_TOKEN = process.env.TELEGRAPH_ACCESS_TOKEN || 'PASTE_TOKEN_KAMU_DISINI';

/**
 * Konversi teks markdown sederhana menjadi struktur DOM Nodes Telegraph
 */
function parseToTelegraphNodes(markdownText) {
  const lines = markdownText.split('\n');
  const nodes = [];

  for (const rawLine of lines) {
    const line = rawLine.trim();
    if (!line) continue;

    if (line.startsWith('# ')) {
      nodes.push({ tag: 'h3', children: [line.replace('# ', '')] });
    } else if (line.startsWith('## ') || line.startsWith('### ')) {
      nodes.push({ tag: 'h4', children: [line.replace(/#+\s*/, '')] });
    } else if (line.startsWith('- ') || line.startsWith('• ')) {
      nodes.push({ tag: 'li', children: [line.replace(/^[-•]\s*/, '')] });
    } else {
      nodes.push({ tag: 'p', children: [line] });
    }
  }
  return nodes;
}

/**
 * Terbitkan artikel ke Telegraph API
 */
async function createInstantViewPage(title, textContent) {
  const nodes = parseToTelegraphNodes(textContent);

  const res = await fetch('https://api.telegra.ph/createPage', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      access_token: TELEGRAPH_TOKEN,
      title: title || 'Panduan OlshopERP',
      author_name: 'OlshopERP Assistant',
      content: nodes,
      return_content: false
    })
  });

  const data = await res.json();
  if (data.ok) {
    return data.result.url; // Mengembalikan format: https://telegra.ph/Judul-xxx
  }
  throw new Error('Gagal create Telegraph page: ' + JSON.stringify(data));
}

module.exports = { createInstantViewPage };

Langkah 3: Pasang Handler Smart Threshold di Script Bot

Tambahkan logika berikut saat menangkap output dari Antigravity CLI sebelum dikirim ke Telegram:

Bridge Handler (botRunner.js) 
const { createInstantViewPage } = require('./telegraphHelper');

async function sendBotResponse(chatId, cliOutput, topicTitle = 'Panduan OlshopERP') {
  const THRESHOLD = 800; // Batas karakter memicu Instant View

  if (cliOutput.length > THRESHOLD) {
    try {
      // 1. Terbitkan teks lengkap ke Telegraph
      const pageUrl = await createInstantViewPage(topicTitle, cliOutput);

      // 2. Buat Executive Summary singkat untuk bubble chat
      const summary = cliOutput.split('\n\n').slice(0, 2).join('\n\n');
      const message = `${summary}\n\n📖 *Baca Dokumen Lengkap (Instant View):*\n${pageUrl}`;

      // 3. Kirim ke Telegram
      await sendTelegramMessage(chatId, message);
      return;
    } catch (err) {
      console.error('Fallback error Telegraph:', err);
      // Jika gagal, fallback kirim pesan terpotong atau chunk
    }
  }

  // Jika respon pendek, langsung kirim utuh
  await sendTelegramMessage(chatId, cliOutput);
}
