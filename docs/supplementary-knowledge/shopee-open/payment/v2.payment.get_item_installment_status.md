# v2.payment.get_item_installment_status

> **Source:** [https://open.shopee.com/documents/v2/v2.payment.get_item_installment_status?module=97&type=1](https://open.shopee.com/documents/v2/v2.payment.get_item_installment_status?module=97&type=1)
> **Module:** Payment
> **API type:** Shop

## Description

Get item installment tenures.Only for TH、TW.

## Method

`POST`

## Path

`/api/v2/payment/get_item_installment_status`

## Request Address

`https://partner.shopeemobile.com/api/v2/payment/get_item_installment_status`
