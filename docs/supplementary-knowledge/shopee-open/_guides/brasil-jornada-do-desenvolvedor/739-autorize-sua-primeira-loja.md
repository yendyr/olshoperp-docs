# Autorize sua primeira loja

> **Source:** [https://open.shopee.com/developer-guide/739](https://open.shopee.com/developer-guide/739)
> **Type:** Developer Guide / Overview
> **document_id:** `739`
> **Section:** BRASIL | Jornada do Desenvolvedor / Sua trilha começa aqui!

## Content

Objetivo 
Na Shopee, para que um App (criado no Open Platform Console) possa ter acesso aos dados de uma loja pela API, é preciso que ela dê autorização à esse App.
Para isso, crie um link de autorização seguindo as regras abaixo, forneça ele ao vendedor e oriente ele a autorizar.
O que você fará nesta etapaApenas aplicativos como tipo Seller In-House System possuem o botão "Authorize" direto no console, demais aplicativos precisam gerar a REDIRECT URL, que deve ser construída pelo desenvolvedor, seguindo os parâmetros e path da Shopee. Confira sempre a documentação de Autorização e Autenticação na íntegra, para verificar as informações de forma atualizada. (Obs: mude o console para Português para ler as documentações traduzidas).
Fluxo para APP: Seller In-House SystemO processo é inciado dentro do console, no botão Authorize. Ao clicar em Authorize aparecerá uma tela para confirmar a REDIRECT URL, que já foi cadastrada na hora da criação do app. Se atualizar a URL nesse momento e tentar a autorização, retornará erro: {"code":1,"error":"error_param","msg":"The domain of redirect_uri is not consistent with the Redirect URL Domain declared in console.","debug_message":""}
 
Portanto, a URL de autorização cadastrada dentro dos detalhes do aplicativo e a URL de autorização no campo "Redirect URL", devem ser a mesma.
 
Fluxo para APP: ERP SystemEsse tipo de aplicativo não possui o botão Authorize no console, pois ERP System funciona para aprovar lojas terceiras e não lojas próprias. Portanto, devem seguir o fluxo de autorização, com a URL já cadastrada dentro dos detalhes do aplicativo, disponibilizando essa URL numa interface, para acesso do vendedor que pretende autorizar a integração da loja com o aplicativo do parceiro.
 
Documentação a seguirem:Autorização e Autenticação: https://open.shopee.com/developer-guide/20 (https://open.shopee.com/developer-guide/20) 
(Sempre orientamos a documentação na íntegra, para verificar URL e parâmetros técnicos de forma atualizada).Antes de continuar, você deve saber- O desenvolvedor é responsável por gerar a URL de autorização.
- O vendedor é quem acessa essa URL e autoriza a aplicação.
- Se o desenvolvedor é o próprio vendedor, o processo é iniciado por dentro do console, no botão Authorize.
- O vendedor consegue autorizar o acesso do aplicativo a loja por, no máximo, 365 dias. Após 365 a conexão irá expirar e as APIs não irão funcionar. Necessário realizar o processo de autorização novamente.
