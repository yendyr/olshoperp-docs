# Crie um login

> **Source:** [https://open.shopee.com/developer-guide/384](https://open.shopee.com/developer-guide/384)
> **Type:** Developer Guide / Overview
> **document_id:** `384`
> **Section:** BRASIL | Jornada do Desenvolvedor / Sua trilha começa aqui!

## Content

Criando um login para acessar a Open PlatformObjetivoA Shopee Open Platform é o portal oficial da Shopee voltado para desenvolvedores e para utilizar essas APIs privadas é necessário possuir login e perfil de desenvolvedor aprovado. 
O que você fará nesta etapaPara ter acesso a Shopee Open Platform, primeiro é necessário criar um login (email/senha) em https://open.shopee.com/ (https://open.shopee.com/)
 
Antes de continuar, você deve saber- O login dá acesso ao console mas, sozinho, não permite criar Aplicações. Para isso, é necessário se aplicar a um dos dois tipos de perfil de desenolvedor e, ao cumprir os critérios avaliados internamente e ser aprovado, terá permissão para criar um App.
- A Open Platform fornece APIs de diferentes módulos (orders, logistics, payments, etc), que permitem conectar sistemas de: gestão, integração, logísticos, como ERPs, Hubs, TMSs, diretamente à conta dos vendedores.
- Cada API está relacionada a um tipo de app, se necessário, crie mais de um aplicativo.
- Se você é seller, o login não é obrigatoriamente o mesmo email e senha de sua loja, inclusive, sugerimos que utilize senhas diferentes para Open Platform e Central do Vendedor.
 
É importante ter lido todas as Políticas da Open Platform antes de verificar os termos de aceite:
Terms of Service: https://open.shopee.com/developer-guide/36 (https://open.shopee.com/developer-guide/36) 
Data Protection Policy (DPP): https://open.shopee.com/developer-guide/32 (https://open.shopee.com/developer-guide/32)
Platform Partner Rules: https://open.shopee.com/developer-guide/34 (https://open.shopee.com/developer-guide/34)
