# Realize testes (Sandbox)

> **Source:** [https://open.shopee.com/developer-guide/744](https://open.shopee.com/developer-guide/744)
> **Type:** Developer Guide / Overview
> **document_id:** `744`
> **Section:** BRASIL | Jornada do Desenvolvedor / Sua trilha começa aqui!

## Content

Test Account e Sandbox V2O que é o Sandbox?O Sandbox é um ambiente de testes da Shopee que permite desenvolver e validar integrações sem utilizar dados ou lojas reais.
ObjetivoValidar sua integração em um ambiente de testes antes de utilizar uma loja real.
O que você fará nesta etapaVocê criará uma loja de testes (Sandbox), autorizará essa loja para sua aplicação e poderá simular todo o fluxo de integração antes de publicar sua solução em Produção.
Fluxo de utilização- Criar uma conta de teste (Sandbox).
- Criar uma loja de teste.
- Criar uma aplicação Sandbox.
- Autorizar a loja de teste para sua aplicação.
- Criar produtos de teste.
- Criar pedidos de teste.
- Validar suas chamadas de API.
- Simular o fluxo logístico e acompanhar as mudanças de status do pedido.
Antes de continuar, você deve saber- Sandbox e Produção são ambientes totalmente independentes.
- Aplicações Sandbox funcionam apenas com contas e lojas Sandbox.
- É necessário autorizar a loja de teste utilizando o Partner ID de Sandbox.
- Algumas funcionalidades disponíveis em Produção podem não estar implementadas no Sandbox.
Próximo passoCom sua aplicação validada no Sandbox, você poderá solicitar o ambiente de Produção (Go Live) e iniciar testes com lojas reais.
📚 Leia a documentação completa: https://open.shopee.com/developer-guide/644 (https://open.shopee.com/developer-guide/644)
