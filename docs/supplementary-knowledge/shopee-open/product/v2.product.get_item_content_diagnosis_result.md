# v2.product.get_item_content_diagnosis_result

> **Source:** [https://open.shopee.com/documents/v2/v2.product.get_item_content_diagnosis_result?module=89&type=1](https://open.shopee.com/documents/v2/v2.product.get_item_content_diagnosis_result?module=89&type=1)
> **Module:** Product
> **API type:** Shop

## Description

Get the content quality details (including content quality level, content issues, and system suggestions) for specific product list.

## Method

`POST`

## Path

`/api/v2/product/get_item_content_diagnosis_result`

## Request Address

`https://partner.shopeemobile.com/api/v2/product/get_item_content_diagnosis_result`
