# v2.product.search_ssp_list

> **Source:** [https://open.shopee.com/documents/v2/v2.product.search_ssp_list?module=89&type=1](https://open.shopee.com/documents/v2/v2.product.search_ssp_list?module=89&type=1)
> **Module:** Product
> **API type:** Shop

## Description

{"content":"Search SSPs by title or by image. At most 50 results are returned.
When image_id_list is provided, the search is based on image similarity and title is ignored; otherwise title must contain at least three characters.
","raw_content":[{"name":"paragraph","children":[{"data":"Search SSPs by title or by image. ## Method

`POST`

## Path

`/api/v2/product/search_ssp_list`

## Request Address

## Request Parameters

| Name | Type | Required | Sample | Description |
| --- | --- | --- | --- | --- |
| title | string | False | wireless headphones | Title text for SSP search. Required when image_id_list is empty and must contain at least three Unicode characters. |
| image_id_list | string[] | False | ["ph-11134207-81z1k-ms9az2bpxibk04"] | Image IDs used for visually similar SSP search. When at least one image ID is supplied, title is ignored. |
