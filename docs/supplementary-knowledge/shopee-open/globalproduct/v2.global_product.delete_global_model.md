# v2.global_product.delete_global_model

> **Source:** [https://open.shopee.com/documents/v2/v2.global_product.delete_global_model?module=90&type=1](https://open.shopee.com/documents/v2/v2.global_product.delete_global_model?module=90&type=1)
> **Module:** GlobalProduct
> **API type:** Merchant

## Description

Delete global model. Only for China mainland sellers and Korean sellers.

## Method

`POST`

## Path

`/api/v2/global_product/delete_global_model`

## Request Address

`https://partner.shopeemobile.com/api/v2/global_product/delete_global_model`
