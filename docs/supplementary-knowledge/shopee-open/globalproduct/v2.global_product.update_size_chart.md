# v2.global_product.update_size_chart

> **Source:** [https://open.shopee.com/documents/v2/v2.global_product.update_size_chart?module=90&type=1](https://open.shopee.com/documents/v2/v2.global_product.update_size_chart?module=90&type=1)
> **Module:** GlobalProduct
> **API type:** Merchant

## Description

Update size chart for global item. Only for China mainland sellers and Korean sellers.

## Method

`POST`

## Path

`/api/v2/global_product/update_size_chart`

## Request Address

`https://partner.shopeemobile.com/api/v2/global_product/update_size_chart`
