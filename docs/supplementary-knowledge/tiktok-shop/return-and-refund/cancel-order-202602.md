# Cancel Order

> **Source:** [https://partner.tiktokshop.com/docv2/page/cancel-order-202602](https://partner.tiktokshop.com/docv2/page/cancel-order-202602)
> **Category:** Return and refund
> **document_path:** `cancel-order-202602`

## Description

Use this API to cancel an order on behalf of a seller. In the US and UK markets, when an item is out of stock, partial cancellation on the single item level is supported by this API.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202602/cancellations`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

| timestamp | int | N | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| order_id | string | Y | TikTok Shop order id |
| skus | []object | N | List of SKU to cancel |
| ^sku_id | string | Y | The SKU id to cancel |
| ^quantity | int | Y | The quantity of SKU to cancel |
| order_line_item_ids | []string | N | List of order line item IDs to cancel. In the US and UK markets, when an item is out of stock, partial cancellation at the individual item level is supported. To initiate a partial cancellation, specify the item's order line ID. **Note:** This is a legacy field. For new integrations, use `order_line_list` instead. Do not provide non-empty values in both `order_line_item_ids` and `order_line_list` in the same request. |
| cancel_reason | string | Y | Reason for canceling the order. To obtain a reason for this order, call `GET /return_refund/202602/orders/{order_id}/aftersale_eligibility` with the same `order_id`, `initiate_aftersale_user=SELLER`, and `request_types=CANCEL`. From the corresponding `data.sku_eligibility[].line_item_eligibility[]` result, pass an exact value from `available_reason_names` as `cancel_reason`. See "Return API Overview" for additional guidance on seller cancellation reasons. |
| order_line_list | []object | N | List of order lines or sub-order lines to cancel. In the US and UK markets, when an item is out of stock, partial cancellation at the individual item level is supported. **Note:** This field is completely backward compatible with the previous `order_line_item_ids` field. Do not provide non-empty values in both `order_line_list` and `order_line_item_ids` in the same request. |
| ^order_line_item_id | string | N | The corresponding order line ID |
| ^sub_order_line_item_id | string | N | The sub-order-line ID inside a bundle product<br>- Required for bundle products<br>- Not required for non-bundle products |
