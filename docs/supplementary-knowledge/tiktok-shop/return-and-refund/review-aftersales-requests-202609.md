# Review Aftersales Requests

> **Source:** [https://partner.tiktokshop.com/docv2/page/review-aftersales-requests-202609](https://partner.tiktokshop.com/docv2/page/review-aftersales-requests-202609)
> **Category:** Return and refund
> **document_path:** `review-aftersales-requests-202609`

## Description

API used to review (approve, reject, or offer alternatives to) a buyer's return request.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202609/aftersales/review`

## Method

`POST`
