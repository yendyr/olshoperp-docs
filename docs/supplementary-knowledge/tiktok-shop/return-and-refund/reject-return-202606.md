# Reject Return

> **Source:** [https://partner.tiktokshop.com/docv2/page/reject-return-202606](https://partner.tiktokshop.com/docv2/page/reject-return-202606)
> **Category:** Return and refund
> **document_path:** `reject-return-202606`

## Description

Use this API to reject a buyer's refund-only, return-and-refund, or replacement request, or to offer a partial refund after the package is received. The valid decision depends on the current request type and status. Before calling this API, make sure the request is still awaiting the seller action that matches the decision you send.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202606/returns/{return_id}/reject`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| decision | string | Y | Seller's decision for the request, available values:<br>- `REJECT_REFUND`: seller reject a refund-only request<br>- `REJECT_RETURN`: seller reject the initial return-and-refund request<br>- `REJECT_RECEIVED_PACKAGE`: seller reject return-and-refund request after the buyer has already shipped or handed over the item.<br>- `REJECT_REPLACEMENT`: seller reject replacement request<br>- `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`: seller offer partial refund regarding to the package item quality check |
| reject_reason | string | Y | Seller's reason for rejecting the aftersales request. For `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, first call Get Review Decision (`GET /return_refund/202606/review_decision`) for the same aftersales request: pass this request's `return_id` as `return_or_cancel_id` and set `check_decisions` to `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`. In the response, select the `data.line_items[]` entry for the affected return line item, then select its `decisions[]` entry whose `decision` is `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, and submit one of that decision's `available_reject_reasons[].name` values in this field. For other decisions, use the [Get Decision Eligibility](https://partner.tiktokshop.com/docv2/page/69844a11eeba77049695c7f6) endpoint to retrieve the currently available rejection options for the same request and submit the returned rejection reason name. **Note**: Available decisions and rejection reasons depend on the current request status, so retrieve eligibility again before calling this API. |
| comment | string | N | Seller's comment about the rejection decision. For `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, the comment must not exceed 500 characters. |
| images | []object | N | Images provided by the seller to support the decision. For `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, a maximum of 6 images is allowed. |
| ^image_id | string | Y | Image URI obtained from the [Upload Product Image](https://partner.tiktokshop.com/docv2/page/6509df95defece02be598a22) API. |
| ^mime_type | string | N | MIME type. |
| ^height | int | N | Image height<br>Units: px |
| ^width | int | N | Image width<br>Units: px |
| partial_refund_amount | object | N | Partial refund amount and currency. Required when `decision` is `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`. |
| ^partial_refund_total | string | N | Partial refund amount. When `decision` is `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, this field is required and must be a numeric string representing an amount greater than 0. |
| ^currency | string | N | Currency of the partial refund amount. When `decision` is `OFFER_PARTIAL_REFUND_AFTER_RECEIVING_PKG`, this field is required and must match the return order's currency. |
