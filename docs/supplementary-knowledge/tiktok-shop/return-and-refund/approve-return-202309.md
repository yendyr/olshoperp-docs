# Approve Return

> **Source:** [https://partner.tiktokshop.com/docv2/page/approve-return-202309](https://partner.tiktokshop.com/docv2/page/approve-return-202309)
> **Category:** Return and refund
> **document_path:** `approve-return-202309`

## Description

Use this API to approve a buyer's return request. The exact effect depends on the return type and return status. Before calling this API, make sure the return is still awaiting a seller action that matches the decision you are sending.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202309/returns/{return_id}/approve`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| decision | string | Y | Seller's decision for the return request, available values:<br>- `APPROVE_REFUND`: seller approve a refund-only request<br>- `APPROVE_RETURN`: seller approve the initial return-and-refund request<br>- `APPROVE_RECEIVED_PACKAGE`: seller approve return-and-refund request after the buyer has already shipped or handed over the item.<br>- `APPROVE_REPLACEMENT`: seller approve replacement request<br>- `ISSUE_REPLACEMENT_REFUND`: seller decline the replacement request and directly refund the buyer instead.<br>- `OFFER_PARTIAL_REFUND`: seller offers a partial refund amount to the buyer without requiring the item(s) to be returned.<br>- `DIRECT_REFUND`: seller issues a returnless refund, meaning the buyer receives a full refund and keeps the item |
| buyer_keep_item | bool | N | **Optional**. Use this field only when decision is set to `APPROVE_RETURN`. If set to `true`, the seller issues a returnless refund, which means the buyer receives a full refund and keeps the item. If set to `false` or omitted, the seller approves the return-and-refund flow and the buyer returns the item. |
| partial_refund | object | N | **Required** when `decision` is set to `OFFER_PARTIAL_REFUND`. When `partial_refund` is provided, both `amount` and `currency` are required. Omit this field for all other decisions. |
| ^currency | string | N | Refund currency must match the currency of the current return request. |
| ^amount | string | N | The partial refund amount seller would like to offer to the buyer |
