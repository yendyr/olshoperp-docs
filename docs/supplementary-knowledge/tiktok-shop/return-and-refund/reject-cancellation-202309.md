# Reject Cancellation

> **Source:** [https://partner.tiktokshop.com/docv2/page/reject-cancellation-202309](https://partner.tiktokshop.com/docv2/page/reject-cancellation-202309)
> **Category:** Return and refund
> **document_path:** `reject-cancellation-202309`

## Description

Use this API to reject a buyer's cancellation request for the specified cancel_id. Before calling this API, make sure the request is still in a state where seller rejection is currently allowed.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202309/cancellations/{cancel_id}/reject`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| reject_reason | string | Y | Seller's reason for rejecting the buyer's order cancellation request. Use the [Get Decision Eligibility](https://partner.tiktokshop.com/docv2/page/69844a11eeba77049695c7f6) endpoint to retrieve the currently available rejection reasons for the same cancellation request, and submit the returned rejection reason name in this field. |
| comment | string | N | Seller's comment on rejection decision. This is where a seller will provide more information about rejecting the request.  |
| images | []object | N | List of images provided by the seller to support seller's decision to reject the order cancellation request.  |
