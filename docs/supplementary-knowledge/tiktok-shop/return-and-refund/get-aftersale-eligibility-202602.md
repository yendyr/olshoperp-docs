# Get Aftersale Eligibility

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-aftersale-eligibility-202602](https://partner.tiktokshop.com/docv2/page/get-aftersale-eligibility-202602)
> **Category:** Return and refund
> **document_path:** `get-aftersale-eligibility-202602`

## Description

Use this API to check whether a seller or buyer can initiate refund-only, return-and-refund, or cancellation requests for an order. The response groups eligibility by SKU, order line item, and aftersale request type.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202602/orders/{order_id}/aftersale_eligibility`

## Method

`GET`
