# Search Aftersales Requests

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-aftersales-requests-202603](https://partner.tiktokshop.com/docv2/page/search-aftersales-requests-202603)
> **Category:** Return and refund
> **document_path:** `search-aftersales-requests-202603`

## Description

Searches aftersales requests for the authorized shop. You can filter by aftersales request, buyer, or main order IDs, aftersales request status, return type, and creation or update time. Use `whitelisted_data_fields` to include line items, SKU return requests, or return merchandise authorizations in each result.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202603/aftersales/search`

## Method
