# Get Return Records

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-return-records-202309](https://partner.tiktokshop.com/docv2/page/get-return-records-202309)
> **Category:** Return and refund
> **document_path:** `get-return-records-202309`

## Description

Use this API to retrieve the record entries for a specific return request. Each item in data.records represents an action or lifecycle event for the specified return_id.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202309/returns/{return_id}/records`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
