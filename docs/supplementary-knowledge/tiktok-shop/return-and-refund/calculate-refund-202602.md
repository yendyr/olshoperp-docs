# Calculate Refund

> **Source:** [https://partner.tiktokshop.com/docv2/page/calculate-refund-202602](https://partner.tiktokshop.com/docv2/page/calculate-refund-202602)
> **Category:** Return and refund
> **document_path:** `calculate-refund-202602`

## Description

Use this API to estimate the refundable amount for a cancellation, refund, or return-and-refund request. The estimate depends on the selected request_type, reason_name, and targeted items. If skus, order_line_item_ids, and order_line_list are all omitted, all order lines in the order are selected as inputs to the refund calculation. For return-and-refund scenarios, the estimate can also depend on the selected return shipping method.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202602/refunds/calculate`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| order_id | string | Y | TikTok Shop order id. |
| request_type | string | Y | Request type<br>- CANCEL<br>- REFUND<br>- RETURN_AND_REFUND<br>Note: different request types are used for different aftersales scenarios. Also, different request types might have different refund amounts, because the refund amount calculation policy is different. |
| shipment_type | string | N | How buyer ships items to seller when in a return request, could be:<br>- `PLATFORM`<br>- `BUYER_ARRANGE` |
| handover_method | string | N | Which handover method buyer chooses to use when returning goods to seller by platform<br>- `DROP_OFF`: buyer drops off the parcel in logistics service collect point.<br>- `PICKUP`: logistics service picks up the buyer package. |
| reason_name | string | Y | Seller's reason for the selected cancellation, refund, or return-and-refund request. Use the [Get Aftersale Eligibility](https://partner.tiktokshop.com/docv2/page/69c3070c66dee40493fdfe2e) endpoint to retrieve the currently available reasons, and submit the returned reason name in this field. |
| order_line_item_ids | []string | N | TikTok Shop order line item IDs to include in the refund calculation. Do not provide non-empty values in both `order_line_item_ids` and `order_line_list` in the same request. |
| skus | []object | N | skus |
| ^sku_id | string | Y | TikTok Shop SKU ID to include in the refund calculation. |
| ^quantity | int | Y | Quantity of this SKU to include in the refund calculation. |
| order_line_list | []object | N | Order lines to include in the refund calculation. Use this field when you need to identify individual sub-items in a bundle product. **Note:** This field is completely backward compatible with the previous `order_line_item_ids` field. Do not provide non-empty values in both `order_line_list` and `order_line_item_ids` in the same request. |
| ^order_line_item_id | string | N | The corresponding order line ID |
| ^sub_order_line_item_id | string | N | The sub-order-line ID inside a bundle product<br>- Required for bundle products<br>- Not required for non-bundle products |
