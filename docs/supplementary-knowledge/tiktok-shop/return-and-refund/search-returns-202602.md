# Search Returns

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-returns-202602](https://partner.tiktokshop.com/docv2/page/search-returns-202602)
> **Category:** Return and refund
> **document_path:** `search-returns-202602`

## Description

Use this API to search returns by return ID, order ID, buyer, return type, return status, arbitration status, or create/update time window. The response is paginated. To retrieve the next page, pass the previous `next_page_token` as `page_token` and keep all other filters and sorting unchanged.

## Required scope

seller.return_refund.basic

## Path

`/return_refund/202602/returns/search`

## Method

`POST`

The buyer will be refunded.<br>- `RETURN_OR_REFUND_REQUEST_CANCEL`: The request has been cancelled by the buyer or system.<br>- `RETURN_OR_REFUND_REQUEST_COMPLETE`: The return/refund was processed successfully.
