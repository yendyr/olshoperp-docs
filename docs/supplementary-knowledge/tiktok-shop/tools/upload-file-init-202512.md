# Upload File Init

> **Source:** [https://partner.tiktokshop.com/docv2/page/upload-file-init-202512](https://partner.tiktokshop.com/docv2/page/upload-file-init-202512)
> **Category:** Tools
> **document_path:** `upload-file-init-202512`

## Description

Use this API to initialize a file upload session. Then upload the file to the returned upload URL. Files of 5 MiB (5,242,880 bytes) or less must be uploaded as a single, non-chunked request with `total_chunk_count` set to `1`; larger files use a multipart upload. After the upload step returns a ResourceId, pass that ResourceId to the API for the target path.

For more details, see https://partner.tiktokshop.com/docv2/page/wfi3nz36.

## Required scope

seller.customer_service, creator.video.write

## Path

`/open/202512/file/init`

## Method

`POST`
