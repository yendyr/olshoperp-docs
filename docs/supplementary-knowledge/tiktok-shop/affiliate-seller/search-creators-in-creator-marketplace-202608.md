# Search Creators in Creator Marketplace

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-creators-in-creator-marketplace-202608](https://partner.tiktokshop.com/docv2/page/search-creators-in-creator-marketplace-202608)
> **Category:** Affiliate seller
> **document_path:** `search-creators-in-creator-marketplace-202608`

## Description

This API is used by Sellers to search for Creators in the Creator Marketplace. Sellers can search based on filters such as GMV, keywords, and Creator follower demographics. All the data returned is for the last 30 days.

## Required scope

seller.creator_marketplace.read

## Path

`/affiliate_seller/202608/marketplace_creators/search`

## Method

`POST`
