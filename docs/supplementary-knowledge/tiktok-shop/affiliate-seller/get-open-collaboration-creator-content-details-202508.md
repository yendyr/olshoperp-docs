# Get Open Collaboration Creator Content Details

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-open-collaboration-creator-content-details-202508](https://partner.tiktokshop.com/docv2/page/get-open-collaboration-creator-content-details-202508)
> **Category:** Affiliate seller
> **document_path:** `get-open-collaboration-creator-content-details-202508`

## Description

This API allows a seller to retrieve creator profiles, content counts, and promotion details for a specified product in open collaboration.

## Required scope

seller.affiliate_collaboration.read

## Path

`/affiliate_seller/202508/open_collaborations/creator_content_details`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
