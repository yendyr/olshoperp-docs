# Get Conversation List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-conversation-list-202412](https://partner.tiktokshop.com/docv2/page/get-conversation-list-202412)
> **Category:** Affiliate seller
> **document_path:** `get-conversation-list-202412`

## Description

Retrieve the seller's IM conversations.

## Required scope

seller.affiliate_messages.write

## Path

`/affiliate_seller/202412/conversations`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| page_size | int | Y | Number of conversations to return per page. Range: 1–50. |
| page_token | string | N | Pagination cursor. Omit this parameter for the first request. For subsequent pages, use the `next_page_token` returned by the previous response. |
| only_need_conversation_id | bool | N | - If `true`, only `conversation_id` in `conversation` is returned. <br>- If `false`, all fields in conversation` are returned.<br>`true` by default. |
| conversation_status | string | N | Filter the returned IM conversations by status. If omitted, the API returns conversations from all statuses.<br><br>Possible values:<br>- `ALL`: Retrieve all conversations regardless of status.<br>- `UNREAD`: Retrieve conversations with messages the seller has not read. Messages remain unread until explicitly marked as read by calling [Mark Conversation Read](6791db761882810314a991a8); replying does not change the read status.<br>- `UNREPLIED`: Retrieve conversations in which the seller is not the last message sender.<br>- `STARRED`: Retrieve conversations the seller starred.<br>- `ARCHIVED`: Retrieve conversations the seller archived. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| only_need_conversation_id | bool | N | - If `true`, only `conversation_id` in `data.conversation` is returned. <br>- If `false`, all fields in `data.conversation` are returned.<br>`true` by default. |
