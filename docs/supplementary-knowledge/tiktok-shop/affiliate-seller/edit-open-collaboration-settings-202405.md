# Edit Open Collaboration Settings

> **Source:** [https://partner.tiktokshop.com/docv2/page/edit-open-collaboration-settings-202405](https://partner.tiktokshop.com/docv2/page/edit-open-collaboration-settings-202405)
> **Category:** Affiliate seller
> **document_path:** `edit-open-collaboration-settings-202405`

## Description

This API is used to edit a Seller's open collaboration settings. It allows you to enroll your existing product catalog and all future products into an open collaboration plan. It also allows you to turn this setting off at any point. By default, this option is turned off for all Sellers.

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202405/open_collaboration_settings`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| auto_add_product | object | N | An object with properties to automatically add products to affiliate open collaboration plans. |
| ^enable | bool | Y | Set to `true` if products are automatically added to affiliate open collaboration plans. The seller can add existing non-affiliate products to open collaboration at one time, and future products are added automatically. Set to `false` if otherwise. |
| ^commission_rate | int | Y | The commission rate in hundredths of a percent. For example, `3587` is a commission rate of `35.87%`. This value must a minimum of `100` and a maximum of `8000`. Not that setting the `enable` property to `false` overrides this property.  |
