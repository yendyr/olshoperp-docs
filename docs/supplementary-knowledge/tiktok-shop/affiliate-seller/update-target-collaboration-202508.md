# Update Target Collaboration

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-target-collaboration-202508](https://partner.tiktokshop.com/docv2/page/update-target-collaboration-202508)
> **Category:** Affiliate seller
> **document_path:** `update-target-collaboration-202508`

## Description

This API is used by sellers to update a STANDARD target collaboration. A successful response can still report creators or products that were not updated. Check `data.update_failed` and `data.target_collaboration_conflicts` before treating the update as complete.

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202508/target_collaborations/{target_collaboration_id}`

## Method

`PUT`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | Y | The name of the target collaboration. |
| end_time | string | Y | The end time of the target collaboration, as a Unix timestamp in seconds. |
| products | []object | Y | The information about the products provided by the seller for target collaboration with creators in the target collaboration.<br>The maximum number of products is 100.<br>When a product is deleted from the product list, if the deleted product has been added to the showcase by the creator, it will take effect at 0:00 the next day, otherwise it will take effect immediately. |
| ^id | string | Y | The product identifier. |
| ^commission_rate | int | Y | The desired commission rate for the target collaboration. The value is measured in ten thousandths. For example, 3587 means the commission fee equals 35.87% of the original price. The range is [100, 8000].<br>Increasing product commissions will take effect immediately, while reducing product commissions will take effect at 00:00 the next day if the current product has been added to the showcase by a creator, otherwise it will take effect immediately. |
| ^target_ad_commission_rate | int | N | The commission rate applies only to orders generated from ads. If a creator’s video is used as an ad without this rate being set, the resulting orders will instead earn either:<br>- The Shop Ads commission you configured in open collaboration, or<br>- The standard commission defined in this invitation.<br>The commission rate is specified in increments of 1/10,000.<br>For example, 1000 stands for 0.1 or 10%.  |
| creator_user_open_ids | []string | Y | The list of Creators' TikTok User Open IDs invited in the target collaboration. The maximum number of creators is 50. [More details](https://partner.tiktokshop.com/docv2/page/3obfokj6) |
| seller_contact_info | object | Y | Contact information for the seller in the target collaboration. |
| ^email | string | Y | Seller's email contact information |
| ^phone_number | string | N | The phone number of the seller. |
| ^whatsapp | string | N | The phone number used by the seller to register for WhatsApp. |
| ^telegram | string | N | The  seller's Telegram username or phone number. |
| ^line | string | N | The phone number used by the seller to register for the Line app |
| free_sample_rule | object | Y | The free sample rules set by the seller in the target collaboration. |
| ^has_free_sample | bool | Y | If true, free samples are provided to creators invited to the target collaboration. |
| ^is_sample_approval_exempt | bool | Y | If true, creators invited to the target collaboration are exempt from seller review and will automatically be approved for a free sample.<br>Note that if has_free_sample=false, this field will not take effect. |
