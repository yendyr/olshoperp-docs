# Get Weekly Creator Outreach Records

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-weekly-creator-outreach-records-202608](https://partner.tiktokshop.com/docv2/page/get-weekly-creator-outreach-records-202608)
> **Category:** Affiliate seller
> **document_path:** `get-weekly-creator-outreach-records-202608`

## Description

Query weekly detailed outreach‑invitation records for a specified seller, including whether IM messages/invitations were sent to a unconnected creator, and whether the creator added products or replied to IM messages.

## Required scope

seller.affiliate_collaboration.read, seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202608/creator_outreach/records/query`

## Method

`POST`
