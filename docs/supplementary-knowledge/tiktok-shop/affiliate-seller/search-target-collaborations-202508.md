# Search Target Collaborations

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-target-collaborations-202508](https://partner.tiktokshop.com/docv2/page/search-target-collaborations-202508)
> **Category:** Affiliate seller
> **document_path:** `search-target-collaborations-202508`

## Description

This API is used by Seller to search for all existing target collaborations. Sellers can search based on filters such as Invitation name, Invitation ID, Product name, Product ID and Creator name.

## Required scope

seller.affiliate_collaboration.read

## Path

`/affiliate_seller/202508/target_collaborations/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. ## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| creator_accept_status | string | N | Filter target collaborations by the acceptance status of invited creators.<br>Allowed values:<br>- ACCEPT: The creators have added the products to their showcases.<br>- ALL: Do not filter by whether the creators have added the products to their showcases.<br>Default: ALL. |
| free_sample_setting | string | N | Filtering by target collaborations' free sample setting.<br>You can query based on:<br>- "WITH_FREE_SAMPLE"<br>- "ALL"<br>By default, the target collaborations will be searched by "ALL" setting. |
| search_param | object | N | Search criteria for target collaborations. When this object is provided, provide both keyword_type and keyword. |
| ^keyword_type | string | Y | Type of value provided in keyword.<br>Possible values:<br>- PRODUCT_ID: Search for a specific product ID.<br>- PRODUCT_NAME: Fuzzy-search by product name.<br>- TARGET_COLLABORATION_ID: Search for a specific target collaboration ID.<br>- TARGET_COLLABORATION_NAME: Fuzzy-search by target collaboration name. |
| ^keyword | string | Y | The value to search for, interpreted according to keyword_type. |
| creator_user_open_id | string | N | The creator's TikTok User Open ID. Provide this field to filter target collaborations for the specified creator. [More details](https://partner.tiktokshop.com/docv2/page/3obfokj6) |
| collaboration_status | string | Y | Filtering by target collaborations' status.<br>You can query based on:<br>- ONGOING: If you use ONGOING to search, the remaining validity period of the returned target collaborations will be greater than 7 days.<br>- EXPIRING: If you use EXPIRING to search, the remaining validity period of the returned target collaborations will be less than 7 days.<br>- VALID: If you use VALID to search, all returned target collaborations will be valid.<br>- CANCELING: If you use CANCELING to search, all returned target collaborations will be in the process of canceling.<br>- COMPLETED: If you use COMPLETED to search, all returned target collaborations will be in the state of completed, including expired and canceled. |
