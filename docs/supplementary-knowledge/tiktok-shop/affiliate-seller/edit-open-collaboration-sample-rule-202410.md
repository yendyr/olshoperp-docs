# Edit Open Collaboration Sample Rule

> **Source:** [https://partner.tiktokshop.com/docv2/page/edit-open-collaboration-sample-rule-202410](https://partner.tiktokshop.com/docv2/page/edit-open-collaboration-sample-rule-202410)
> **Category:** Affiliate seller
> **document_path:** `edit-open-collaboration-sample-rule-202410`

## Description

Use this API to manage sample rules in open collaborations, like valid time periods, or thresholds for creators to request samples. You can create, update, or deactivate rules.

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202410/open_collaborations/sample_rules`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |

| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| product_id | string | Y | The product ID to which the sample rule applies. You can only assign one sample rule for one `product_id`. Only the most recent API call will take effect. |
| sample_rule | object | N | The sample rule settings to apply to the specified product. Use `activate_status` to create, update, or deactivate the rule. |
| ^sample_quota | int | N | The total quantity of the samples provided by the seller that the creators can apply for. |
| ^is_sample_time_unlimited | bool | N | Whether the sample is always available for application:<br>- If true, the sample can be requested at any time.<br>- If false, the sample can only be requested during specified time periods. You must set start_time and end_time. |
| ^start_time | int | N | The start of the period during which a creator can apply for samples, as a Unix timestamp in seconds. You must specify `start_time` and `end_time` together. |
| ^end_time | int | N | The end of the period during which a creator can apply for samples, as a Unix timestamp in seconds. You must specify `start_time` and `end_time` together. |
| ^thresholds | object | N | The threshold criteria that a creator must meet to be eligible to apply for the sample. |
| ^^minimum_follower_count | int | N | The creator must have a follower count greater than or equal to this value to be eligible to request the sample. |
| ^^minimum_gmv | int | N | The creator must have the GMV in the past 30 days greater than this value to be eligible to request the sample. |
| ^^avg_ec_video_views | int | N | The creator must have an average number of e-commerce video views in the past 30 days greater than or equal to this value to be eligible to request the sample. |
| ^^category_ids | []string | N | A list of product first-level category IDs.<br>Use this to limit participating creators: for each creator, sort their GMV over the past 30 days by first-level product category. If the GMV of one of the categories is among the top three, the creator is eligible to participate in the event. No restriction by default.<br>For example, if a creator's top three categories are [{Cellphone_ID}, {Furniture_ID}, {Food_ID}], and the value of tehis parameter is `[{Food_ID}]`, the creator is qualified for open collaboration. |
| ^^predicted_fulfillment_rank | string | N | The creators whose predicted rate of posting a shoppable video or LIVE after receiving a sample.<br>- ALL. All creators regardless of the rate.<br>- LOW. The creators whose rate is above or equal to low.<br>- MEDIUM. The creators whose rate is above or equal to medium.<br>- HIGH. The creators whose rate is high. |
| ^activate_status | string | Y | To activate the sample rule, use `ACTIVATE`; to deactivate the sample rule, use `DEACTIVATE`.<br>When using `ACTIVATE`, you must specify the details of the rule; when using `DEACTIVATE`, you just need to specify `product_id`. |
