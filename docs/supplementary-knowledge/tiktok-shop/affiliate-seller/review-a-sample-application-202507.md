# Review a Sample Application

> **Source:** [https://partner.tiktokshop.com/docv2/page/review-a-sample-application-202507](https://partner.tiktokshop.com/docv2/page/review-a-sample-application-202507)
> **Category:** Affiliate seller
> **document_path:** `review-a-sample-application-202507`

## Description

This API allows the seller to approve or reject a creator's sample application in an open collaboration. Only applications in the PENDING status can be approved or rejected. When rejecting an application, the seller must provide a supported rejection reason.

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202507/sample_applications/{application_id}/review`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| review_result | string | Y | The review action to take on the sample application. Possible values:<br>- APPROVE: Approves the sample application.<br>- REJECT: Rejects the sample application. |
| reject_reason | string | N | The reason why a seller rejected a creator's sample application. The possible enumerated values are:<br>- NOT_MATCH: The creator does not meet the seller's collaboration requirements.<br>- OFFLINE: The product has been taken offline.<br>- OUT_OF_STOCK: The product is temporarily out of stock.<br>- OTHER: Any other reason not covered by the above categories.<br>Required if the review_result is set to REJECT<br>This field allows the seller to specify the reason for rejecting a sample application, providing clarity to the creator regarding the rejection. |
