# Query Creator Promotion Details in Target Collaboration

> **Source:** [https://partner.tiktokshop.com/docv2/page/query-creator-promotion-details-in-target-collaboration-202608](https://partner.tiktokshop.com/docv2/page/query-creator-promotion-details-in-target-collaboration-202608)
> **Category:** Affiliate seller
> **document_path:** `query-creator-promotion-details-in-target-collaboration-202608`

## Description

Query the creator commission rate, number of promotional video contents and number of live‑stream promotions for specified creator, specified invitation and specified product.

## Required scope

seller.affiliate_collaboration.read, seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202608/target_collaborations/creator_promotion_details/query`

## Method

`POST`
