# Get Latest Unread Messages

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-latest-unread-messages-202412](https://partner.tiktokshop.com/docv2/page/get-latest-unread-messages-202412)
> **Category:** Affiliate seller
> **document_path:** `get-latest-unread-messages-202412`

## Description

Get the unread messages from the last minute.
You are recommended to use the Webhook, New Message Listener, for the message notification.

## Required scope

seller.affiliate_messages.write

## Path

`/affiliate_seller/202412/conversations/messages/list/newest`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
