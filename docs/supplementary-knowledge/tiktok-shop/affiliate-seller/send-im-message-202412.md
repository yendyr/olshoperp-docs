# Send IM Message

> **Source:** [https://partner.tiktokshop.com/docv2/page/send-im-message-202412](https://partner.tiktokshop.com/docv2/page/send-im-message-202412)
> **Category:** Affiliate seller
> **document_path:** `send-im-message-202412`

## Description

Sends a message of the selected type in the specified conversation.

## Required scope

seller.affiliate_messages.write

## Path

`/affiliate_seller/202412/conversations/{conversation_id}/messages`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| msg_type | string | Y | Message type. The value determines the decoded JSON object required in `content`. Possible values:<br>- `TEXT`<br>- `PRODUCT_CARD`<br>- `TARGET_COLLABORATION_CARD`<br>- `FREE_SAMPLE_CARD`<br>- `IMAGE`<br>- `CRM_TEXT_WITH_IMAGE_CARD`<br>- `CRM_TEXT_WITH_PRODUCTS_CARD` |
| content | string | Y | Message content as a JSON-serialized string. The decoded JSON object depends on `msg_type`:<br><br>- `TEXT`: `{"content": "simple text"}`. `content` is required, must not be empty, and supports up to 2,000 Unicode characters.<br>- `PRODUCT_CARD`: `{"product_id": "12345"}`. `product_id` is required.<br>- `TARGET_COLLABORATION_CARD`: `{"target_collaboration_id": "1234"}`. `target_collaboration_id` is required and is the invitation group ID.<br>- `FREE_SAMPLE_CARD`: `{"apply_id": "1234"}`. `apply_id` is required.<br>- `IMAGE`: `{"url": "https://p16-oec-va.ibyteimg.com/tos-maliva-i-o3syd03w52-us/2ca53c34ad8443e6b39f4e0153d3aed4~tplv-o3syd03w52-origin-image.image?from=1320446476", "width": 1280, "height": 720}`. `url`, `width`, and `height` are required; `width` and `height` must be integers. You can obtain `url` by calling [Upload Messages Image](https://partner.tiktokshop.com/docv2/page/upload-message-image-v2-202608).<br>- `CRM_TEXT_WITH_PRODUCTS_CARD`: `{"product_ids": "12345,123456", "title": "abc", "content": "abc"}`. `product_ids` is required and contains one to five comma-separated positive product IDs. `content` is required, must not be empty, and supports up to 500 Unicode characters. `title` supports up to 50 Unicode characters.<br>- `CRM_TEXT_WITH_IMAGE_CARD`: `{"image_url": "https://p16-oec-va.ibyteimg.com/tos-maliva-i-o3syd03w52-us/2ca53c34ad8443e6b39f4e0153d3aed4~tplv-o3syd03w52-origin-image.image?from=1320446476", "title": "abc", "content": "abc"}`. `image_url` and `content` are required. `content` must not be empty and supports up to 500 Unicode characters. `title` supports up to 50 Unicode characters. |
