# Seller Get Sample Request Deeplink

> **Source:** [https://partner.tiktokshop.com/docv2/page/seller-get-sample-request-deeplink-202512](https://partner.tiktokshop.com/docv2/page/seller-get-sample-request-deeplink-202512)
> **Category:** Affiliate seller
> **document_path:** `seller-get-sample-request-deeplink-202512`

## Description

Use this API to get a TikTok deeplink, use this deeplink to launch the TikTok app and land the user on the sample request page.
- The seller can encode the deeplink into an QR code and send it to a creator via email.

## Required scope

seller.affiliate_collaboration.read

## Path

`/affiliate_seller/202512/sample_applications/deeplink`

## Method

`GET`
