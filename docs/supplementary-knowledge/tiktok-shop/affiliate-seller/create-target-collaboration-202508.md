# Create Target Collaboration

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-target-collaboration-202508](https://partner.tiktokshop.com/docv2/page/create-target-collaboration-202508)
> **Category:** Affiliate seller
> **document_path:** `create-target-collaboration-202508`

## Description

This API is used to create a target collaboration.
A target collaboration is a collaboration between a seller selected set of products (including a commission payout) and a set of creators the seller has added (invited) to the collaboration. Target collaborations are private and not visible in the Creator Marketplace to all creators; they are only visible to those that have been added to the collaboration.

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202508/target_collaborations`

## Method

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | Y | The name of the target collaboration. |
| message | string | N | The message sent to creators associated with the target collaboration. |
| end_time | string | Y | The date at which the target collaboration ends, in Unix epoch time. |
| products | []object | Y | A list of metadata and data for the products provided by the seller for target collaboration. Maximum length of the list is `100` products.  |
| ^id | string | Y | The product identifier. |
| ^target_commission_rate | int | Y | The desired commission rate for the target collaboration. The desired commission rate is expressed in hundredths of a percent. For example, `3587` is a commission rate of `35.87%`. This value must a minimum of `100`.  |
| ^shop_ads_commission_rate | int | N | The commission rate applies only to orders generated from ads. If a creator’s video is used as an ad without this rate being set, the resulting orders will instead earn either:<br>- The Shop Ads commission you configured in open collaboration, or<br>- The standard commission defined in this invitation.<br>The commission rate is specified in increments of 1/10,000.<br>For example, 1000 stands for 0.1 or 10%.  |
| creator_user_open_ids | []string | Y |  Maximum length of the list is `50` user open identifiers. Creator Open ID. [More details](https://partner.tiktokshop.com/docv2/page/3obfokj6) |
| seller_contact_info | object | Y | Metadata and data associated with the seller contact information. |
| ^email | string | N | The seller's email address.  |
| ^phone_number | string | N | The phone number of the seller.   |
| ^whatsapp | string | N | The phone number used by the seller to register for WhatsApp.  |
| ^telegram | string | N | The  seller's Telegram username or phone number.  |
| ^line | string | N | The phone number used by the seller to register for the Line app.  |
| free_sample_rule | object | Y | A set of properties that control the free sample behavior for the product. |
| ^has_free_sample | bool | Y | If set to `true`, free samples are provided to creators invited to the target collaboration group. If set to `false`, free samples are not provided. |
| ^is_sample_approval_exempt | bool | Y | If set to `true`, creators invited to the target collaboration are exempt from seller review and are automatically approved for a free  product sample. Note that the `has_free_sample` property overrides the free sample behavior.  |
| preferred_content_type | string | N | preferred creator content type, "LIVE" or "VIDEO" |
