# Seller Search Open Collaboration Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/seller-search-open-collaboration-products-202405](https://partner.tiktokshop.com/docv2/page/seller-search-open-collaboration-products-202405)
> **Category:** Affiliate seller
> **document_path:** `seller-search-open-collaboration-products-202405`

## Description

Searches for open-collaboration products on the TikTok Shop Affiliate Product Marketplace within the regions where the seller is registered to sell. Category, commission rate, sales price, and title keyword filters are optional. When multiple filter groups are supplied, a product must match every supplied group. When none of these filter groups is supplied, no filter from these groups is applied; results remain scoped to eligible open-collaboration products in the seller's registered regions and are returned through pagination.

## Required scope

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| title_keywords | []string | N | A list of product keywords. Product titles, or names, are loosely matched. Keywords in the list form a query and the resulting set of matching product names is based on the conjunctive operator `AND` between each keyword. For example, the keyword list `["Men", "Fashion"]` creates a query `"Men" AND "Fashion"` and the resulting set of matching product names contains the loosely matched conjuction of "Men" and "Fashion" such as "Male Fashionable". Maximum length of the list is 20 keywords. Maximum keyword string length is 255 characters. |
| sales_price_range | object | N | Restricts the products in the search results to those with prices greater than or equal to the expressed minimum price and less than the expressed maximum price |
| ^amount_ge | string | N | The product price must be greater than this value in order to be included in the search results. The value must be greater than `0`. |
| ^amount_lt | string | N | The product price must be greater than this value in order to be included in the search results. The value must be greater than `0`. No upper bound is set if this property is not included. |
| category | object | N | Restricts the products in the search results to those that are associated with the expressed product category.  |
| ^id | string | N | The category identifier. Note that only first-level categories are supported. |
| commission_rate_range | object | N | Filters products by the commission rate range specified by `rate_ge` and `rate_lt`. |
| ^rate_ge | int | N | Products with a commission rate greater than or equal to this value are included in the search results. The rate is expressed in hundredths of a percent; for example, `3587` means `35.87%`. Valid range: [100, 8000]. |
| ^rate_lt | int | N | The commission rate must be less than this value in order to be included in the search results. The commission rate is expressed in hundredths of a percent. For example, `3587` is a commission rate of `35.87%`. This value must a minimum of `100`. |
