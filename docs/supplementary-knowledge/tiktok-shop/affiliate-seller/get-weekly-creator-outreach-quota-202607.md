# Get Weekly Creator Outreach Quota

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-weekly-creator-outreach-quota-202607](https://partner.tiktokshop.com/docv2/page/get-weekly-creator-outreach-quota-202607)
> **Category:** Affiliate seller
> **document_path:** `get-weekly-creator-outreach-quota-202607`

## Description

Query the weekly outreach invitation quota for a shop. It returns the current GMV tier, maximum reachable creator follower count corresponding to the tier, consumed quota, remaining quota and other related information.

## Required scope

seller.affiliate_collaboration.read

## Path

`/affiliate_seller/202607/creator_outreach/quota`

## Method

`GET`
