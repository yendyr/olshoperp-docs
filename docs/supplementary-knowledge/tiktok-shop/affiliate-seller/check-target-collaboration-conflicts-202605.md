# Check Target Collaboration Conflicts

> **Source:** [https://partner.tiktokshop.com/docv2/page/check-target-collaboration-conflicts-202605](https://partner.tiktokshop.com/docv2/page/check-target-collaboration-conflicts-202605)
> **Category:** Affiliate seller
> **document_path:** `check-target-collaboration-conflicts-202605`

## Description

Retrieve conflicting target collaborations for the product and determine if they can be terminated

## Required scope

seller.affiliate_collaboration.write

## Path

`/affiliate_seller/202605/target_collaborations/conflicts/check`

## Method

`POST`
