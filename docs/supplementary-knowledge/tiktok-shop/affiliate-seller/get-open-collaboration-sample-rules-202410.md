# Get Open Collaboration Sample Rules

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-open-collaboration-sample-rules-202410](https://partner.tiktokshop.com/docv2/page/get-open-collaboration-sample-rules-202410)
> **Category:** Affiliate seller
> **document_path:** `get-open-collaboration-sample-rules-202410`

## Description

Use this API to get the status and the details of the sample rules for products under an open collaboration. With this API, you can efficiently review the sample distribution criteria for products within the open collaboration context.

## Required scope

seller.affiliate_collaboration.read

## Path

`/affiliate_seller/202410/open_collaborations/sample_rules`

## Method

`GET`
