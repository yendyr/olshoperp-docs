# Create Engagement Task

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-engagement-task-202412](https://partner.tiktokshop.com/docv2/page/create-engagement-task-202412)
> **Category:** Customer engagement
> **document_path:** `create-engagement-task-202412`

## Description

Create an engagement task that acts as a container for grouping messages with similar content and rules, allowing sellers to track and compare task performance across different types of content.
Note that each task has a mandatory end time, and once expired, it cannot be used to send additional messages.

## Required scope

seller.customer_engagement.write

## Path

`/customer_engagement/202412/engagement_tasks`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| template_id | string | Y | The ID of engagement message templates predefined by TikTok Shop. Retrieve the value from [Get Message Templates](67777e44223fde02fdfdc157). |
| task_name | string | Y | The name of the task. Length: 1–256 bytes. |
| end_time | int | Y | The time at which the task ends, and messages will no longer be sent. Unix timestamp (seconds). |
| channel | string | Y | The engagement channel. Only `TIKTOK_IM` is supported. |
| product_ids | []string | N | The product ID. Retrieve this value from the [Search Products API](https://partner.tiktokshop.com/docv2/page/65854ffb8f559302d8a6acda). |
| coupon_ids | []string | N | The coupon ID. Retrieve this value and other coupon-related information from the [Search Coupons API](https://partner.tiktokshop.com/docv2/page/6699dcdf115ebe02f841e4cd).<br><br>**Note**: The coupon properties must comply with the rules defined in `coupon_card_rules.coupon_type` of the [Get Message Templates API](67777e44223fde02fdfdc157). |
