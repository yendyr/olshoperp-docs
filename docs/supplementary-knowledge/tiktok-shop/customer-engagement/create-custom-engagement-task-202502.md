# Create Custom Engagement Task

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-custom-engagement-task-202502](https://partner.tiktokshop.com/docv2/page/create-custom-engagement-task-202502)
> **Category:** Customer engagement
> **document_path:** `create-custom-engagement-task-202502`

## Description

Create an engagement task that uses a self-defined custom message instead of predefined message templates from TikTok Shop. The task acts as a container for grouping messages with similar content and rules, allowing sellers to track and compare task performance across different types of content.
Note that each task has a mandatory end time, and once expired, it cannot be used to send additional messages.

## Required scope

seller.customer_engagement.write

## Path

`/customer_engagement/202502/engagement_tasks/custom`

## Method

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| task_name | string | Y | The name of the task. Length: 1–256 bytes when UTF-8 encoded. |
| end_time | int | Y | The time at which the task ends, and messages will no longer be sent. Unix timestamp (seconds). |
| channel | string | Y | The engagement channel. Only `TIKTOK_IM` is supported.<br> |
| product_ids | []string | N | The product IDs that you want to include as interactive cards in the message. Retrieve this value from the [Search Products API](https://partner.tiktokshop.com/docv2/page/65854ffb8f559302d8a6acda).<br>Max count: 4 |
| coupon_ids | []string | N | The coupon IDs that you want to include as interactive cards in the message. <br>Max count: 1<br>You can only add coupons that have one of these sets of property:<br>- `coupons.display_type=REGULAR` and `coupons.target_buyer_segment=ALL`<br>- `coupons.display_type=REGULAR` and `coupons.target_buyer_segment=REPEAT_CUSTOMERS`.<br>Find out the coupon ID and properties from the [Search Coupons API](https://partner.tiktokshop.com/docv2/page/6699dcdf115ebe02f841e4cd). |
| custom_message | object | N | The custom message to send to customers. |
| ^title | string | N | The message title.<br>- Valid format: plain text, unicode emoji (UTF-8)<br>- Valid length: 1–70 Unicode code points. |
| ^body | string | N | The message body.<br>- Valid format: plain text, unicode emoji (UTF-8)<br>- Valid length: 1–500 Unicode code points. |
