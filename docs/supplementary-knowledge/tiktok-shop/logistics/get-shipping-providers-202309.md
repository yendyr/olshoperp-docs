# Get Shipping Providers

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shipping-providers-202309](https://partner.tiktokshop.com/docv2/page/get-shipping-providers-202309)
> **Category:** Logistics
> **document_path:** `get-shipping-providers-202309`

## Description

Returns the shipping providers available for the specified delivery option. If the delivery option is fulfilled by TikTok, the request returns an error and no shipping providers are returned.

## Required scope

seller.fulfillment.basic, seller.logistics, seller.fs.order&fufillment.management

## Path

`/logistics/202309/delivery_options/{delivery_option_id}/shipping_providers`

## Method

`GET`
