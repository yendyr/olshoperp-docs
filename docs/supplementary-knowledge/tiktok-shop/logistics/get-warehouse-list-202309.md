# Get Warehouse List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-warehouse-list-202309](https://partner.tiktokshop.com/docv2/page/get-warehouse-list-202309)
> **Category:** Logistics
> **document_path:** `get-warehouse-list-202309`

## Description

Retrieves warehouses associated with the seller, including names, effective statuses, types, default designations, and available address information.

## Required scope

seller.logistics

## Path

`/logistics/202309/warehouses`

## Method

`GET`

## Request Header

| --- | --- | --- | --- |
