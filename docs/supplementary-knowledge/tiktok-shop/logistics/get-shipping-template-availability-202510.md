# Get Shipping Template Availability

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shipping-template-availability-202510](https://partner.tiktokshop.com/docv2/page/get-shipping-template-availability-202510)
> **Category:** Logistics
> **document_path:** `get-shipping-template-availability-202510`

## Description

get seller's available shipping template and return the reason  why the template is not available，this api is now only available for JP and UK market

## Required scope

seller.logistics

## Path

`/logistics/202510/seller_templates`

## Method

`GET`

## Request Header

| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |

Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
