# Delete Webhook for an Event

> **Source:** [https://partner.tiktokshop.com/docv2/page/delete-webhook-for-an-event-202309](https://partner.tiktokshop.com/docv2/page/delete-webhook-for-an-event-202309)
> **Category:** Event
> **document_path:** `delete-webhook-for-an-event-202309`

## Description

Deletes the shop's webhook URL for the specified event topic. The request succeeds even if no webhook URL is currently configured for that topic.

## Required scope

seller.authorization.info

## Path

`/event/202309/webhooks`

## Method

`DELETE`
