# Create Video Precheck Task

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-video-precheck-task-202511](https://partner.tiktokshop.com/docv2/page/create-video-precheck-task-202511)
> **Category:** Affiliate creator
> **document_path:** `create-video-precheck-task-202511`

## Description

Use this API to create a task that checks a video and its shoppable content anchor for violations. If the task is created successfully, the response returns a task ID.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202511/videos/precheck_task`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| video_info | object | Y | Video information |
| ^file_id | string | Y | Video file_id from [Upload Shoppable Video File](https://api/affiliate_creator/202505/videos/video_files) |
| product_link_info | object | Y | Product link information |
| ^product_id | string | Y | Use product_id to bind the product with the video.<br>The product_id from [Get Shop Products](https://api/affiliate_creator/202509/shop_products) or [Get Showcase Products](https://api/affiliate_creator/202405/showcases/products) |
| ^title | string | Y | The title to be shown on the product anchor. Anchor title should be shorter than 30 characters. Titles may be rejected for punctuation, emoji, or offensive language. |
