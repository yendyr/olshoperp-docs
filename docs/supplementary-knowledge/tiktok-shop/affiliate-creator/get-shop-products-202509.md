# Get Shop Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-products-202509](https://partner.tiktokshop.com/docv2/page/get-shop-products-202509)
> **Category:** Affiliate creator
> **document_path:** `get-shop-products-202509`

## Description

Searches for products in the shop bound to the authenticated creator. Optionally use `title_keyword` to filter products by title. The creator must have a bound shop before calling this API.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202509/shop_products`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| title_keyword | string | N | The title keyword of the product you wish to search by. |
| sort_field | string | N | Sort field.<br>Possible values:<br>- PRODUCT_ID<br>- PRICE<br>- SALE<br><br>If omitted or empty, defaults to PRODUCT_ID. Any other value is rejected. |
| sort_order | string | N | Sort order.<br>Possible values:<br>- DESC<br>- ASC<br><br>If omitted or empty, defaults to DESC. Any other value is rejected. |
| page_size | int | Y | Pagination count determines how many products you'll get after sending the request. 20 is a recommended number.<br>Valid Range: [1-100] |
| page_token | string | N | An opaque token used to retrieve the next page. Leave this parameter empty for the first request. For subsequent requests, pass the `next_page_token` returned by the previous response and reuse the same `title_keyword`, `sort_field`, `sort_order`, and `page_size` values. |
