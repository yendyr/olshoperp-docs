# Get Shoppable Video Precheck Result 

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shoppable-video-precheck-result-202601](https://partner.tiktokshop.com/docv2/page/get-shoppable-video-precheck-result-202601)
> **Category:** Affiliate creator
> **document_path:** `get-shoppable-video-precheck-result-202601`

## Description

Retrieve the violation and, when enabled, good-quality check results for a video precheck task. If a returned check status is `PROCESSING`, call this API again later. If a check status is `FAIL`, review its `issues` field for the detected issues and suggested improvements.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202601/videos/precheck_tasks/{task_id}`

## Method

`GET`
