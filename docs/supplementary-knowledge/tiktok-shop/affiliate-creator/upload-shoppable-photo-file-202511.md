# Upload Shoppable Photo File

> **Source:** [https://partner.tiktokshop.com/docv2/page/upload-shoppable-photo-file-202511](https://partner.tiktokshop.com/docv2/page/upload-shoppable-photo-file-202511)
> **Category:** Affiliate creator
> **document_path:** `upload-shoppable-photo-file-202511`

## Description

Use this API to upload the photos before photo posting. It returns the photo_file_uri for each uploaded image

## Required scope

creator.video.write

## Path

`/affiliate_creator/202511/photos/photo_files`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: multipart/form-data |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| data | file | Y | The local image file to upload.<br><br>Requirements:<br>- Supported formats: JPG, JPEG, PNG, WEBP, HEIC, BMP<br>- Zero-byte files are rejected.<br>- Maximum file size: 10 MiB (10,485,760 bytes).<br>- Aspect ratio: 9:16 to 16:9 |
