# Add Showcase Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/add-showcase-products-202405](https://partner.tiktokshop.com/docv2/page/add-showcase-products-202405)
> **Category:** Affiliate creator
> **document_path:** `add-showcase-products-202405`

## Description

This API adds products to the authenticated creator's showcase. Global Shop users must have at least one selected region before calling this API. A successful API response can still contain `errors` for products that were not added; when there are no product-level addition errors, `errors` is omitted.

## Required scope

creator.showcase.write, creator.video.write

## Path

`/affiliate_creator/202405/showcases/products/add`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| add_type | string | Y | Specifies how products are added to the showcase. This an enumerated type with values:<br>- PRODUCT_ID<br>- PRODUCT_LINK  |
| product_ids | []string | N | A list of product identifiers included if `add_type` is set to `PRODUCT_ID`. The products associated with the identifiers are added to the showcase. Maximum length of the list is 20 product identifiers. |
| product_link | string | N | A product URL to use when `add_type` is set to `PRODUCT_LINK`. The product associated with the URL is added to the showcase. |
