# Generate Publisher Sharing Links in Batch

> **Source:** [https://partner.tiktokshop.com/docv2/page/generate-publisher-sharing-links-in-batch-202504](https://partner.tiktokshop.com/docv2/page/generate-publisher-sharing-links-in-batch-202504)
> **Category:** Affiliate creator
> **document_path:** `generate-publisher-sharing-links-in-batch-202504`

## Description

You can use this API to generate material sharing links for a specific publisher. After that, you can share the link with the publisher. Right now, the material type must be `PRODUCT`.
Please ensure that the material is included in the campaign by using [Generate Multi Affiliate Partner Campaign Product Links](generate-multi-affiliate-partner-campaign-product-links).

## Required scope

creator.affiliate.share_link.read

## Path

`/affiliate_creator/202504/affiliate_sharing_links/publisher/{publisher_id}/generate_batch`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| material | object | Y | The entities for which the sharing links are generated. |
| ^ids | []string | Y | The list of material IDs. The maximum length is 50. When `type` is `PRODUCT`, provide 1 to 50 product IDs. |
| ^type | string | Y | The material type. Possible values:<br>- `PRODUCT`: Provide product IDs in `ids`.<br>- `CAMPAIGN`: Provide `promotion_campaign_schema`. |
| ^promotion_campaign_schema | string | N | When `type` is set to `CAMPAIGN`, this field is required. This schema is associated with the Campaign page. |
| campaign_id | string | N | If a creator adds products from a campaign, please include the campaign ID. The campaign ID can be found in the Affiliate Center or retrieved using the Get Affiliate Partner Campaign List API. |
| link_type | string | N | Controls the `sharing_link` returned when `material.type` is `PRODUCT`.<br>- Set to `TOKO` for a Tokopedia product URL. This option is for Tokopedia agencies.<br>- Omit this field for a TikTok Shop product URL. |
