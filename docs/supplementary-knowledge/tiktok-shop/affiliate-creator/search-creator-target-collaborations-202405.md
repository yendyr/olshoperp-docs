# Search Creator Target Collaborations

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-creator-target-collaborations-202405](https://partner.tiktokshop.com/docv2/page/search-creator-target-collaborations-202405)
> **Category:** Affiliate creator
> **document_path:** `search-creator-target-collaborations-202405`

## Description

Searches for the authenticated creator's target collaborations and the products within them for the TikTok Shop specified by `shop_id`.

## Required scope

creator.affiliate_collaboration.read

## Path

`/affiliate_creator/202405/target_collaborations/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| page_token | string | N | An opaque token used to retrieve the next page of a paginated result set. It is not needed for the first page. For each subsequent page, pass the previous response's `next_page_token` unchanged as `page_token` and reuse the same `page_size`, `shop_id`, `keyword`, and `keyword_type` values, including whether optional `keyword` and `keyword_type` were omitted or provided. |
| page_size | int | Y | The number of results to be returned per page. Valid range: [0-100]. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| shop_id | string | Y | The TikTok Shop identifier. |
| keyword_type | string | N | The type of value specified in `keyword`. Provide `keyword` and `keyword_type` together to filter by ID or name. Omit both fields to search without an ID or name filter. Possible values:<br>- `TARGET_COLLABORATIONS_ID`: Match by target collaboration ID and return matching collaborations in the `LIVE`, `EXPIRED`, `DELETED`, or `ENDED` state.<br>- `TARGET_COLLABORATIONS_NAME`: Match by target collaboration name and return matching collaborations in the `LIVE` state only. |
| keyword | string | N | The target collaboration ID or name to search for, as specified by `keyword_type`. For `TARGET_COLLABORATIONS_ID`, provide a base-10 integer. For `TARGET_COLLABORATIONS_NAME`, provide a value shorter than 500 bytes. |
