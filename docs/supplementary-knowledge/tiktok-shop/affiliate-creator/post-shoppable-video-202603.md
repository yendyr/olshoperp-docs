# Post Shoppable Video

> **Source:** [https://partner.tiktokshop.com/docv2/page/post-shoppable-video-202603](https://partner.tiktokshop.com/docv2/page/post-shoppable-video-202603)
> **Category:** Affiliate creator
> **document_path:** `post-shoppable-video-202603`

## Description

Use this API to submit a shoppable video for publishing. When the submission succeeds, pass the returned video ID as the `video_id` path parameter to Get Shoppable Video Status (`GET /affiliate_creator/202509/videos/{video_id}/status`) to retrieve the posting status: `PROCESSING`, `SUCCESS`, or `FAIL`. If the status is `PROCESSING`, call the status API again later to check for a terminal status.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202603/videos`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| video_info | object | Y | Video information |
| ^file_id | string | Y | The video file ID returned by Upload Shoppable Video File (`POST /affiliate_creator/202505/videos/video_files`). |
| ^title | string | Y | The video caption. <br>The maximum length is 2200 in UTF-16 runes.<br>If not specified, the ticket post will not have any captions. |
| ^cover_uri | string | N | The video cover image URI returned by Upload Shoppable Photo File (`POST /affiliate_creator/202511/photos/photo_files`). |
| ^cover_timestamp_ms | int | N | The input parameter is a timestamp, which specifies a particular moment in the video. The frame at that timestamp will be used as the video cover. If cover_uri and cover_timestamp_ms are both not provided, the cover will default to the first frame of the uploaded video. Only one of cover_uri or cover_timestamp_ms can be provided. If both parameters are passed, cover_uri will take precedence. |
| ^music_id | string | N | The music ID for the video's background music. Obtain it from Search Music (`GET /affiliate_creator/202602/music/search`). If not provided, no music will be associated with the video. |
| product_link_info | object | Y | Product link information |
| ^product_id | string | Y | The product ID to bind to the video. Obtain it from Get Shop Products (`GET /affiliate_creator/202509/shop_products`) or Get Showcase Products (`GET /affiliate_creator/202405/showcases/products`). |
| ^title | string | Y | The title to be shown on the product anchor. Anchor title should be shorter than 30 characters. Titles may be rejected for punctuation, emoji, or offensive language. |
