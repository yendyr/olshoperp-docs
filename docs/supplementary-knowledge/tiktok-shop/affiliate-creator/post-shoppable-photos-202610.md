# Post Shoppable Photos

> **Source:** [https://partner.tiktokshop.com/docv2/page/post-shoppable-photos-202610](https://partner.tiktokshop.com/docv2/page/post-shoppable-photos-202610)
> **Category:** Affiliate creator
> **document_path:** `post-shoppable-photos-202610`

## Description

Use this API to post the shoppable photos with uris and metadata.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202610/photos`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| photos_info | []object | Y | Photo Info Metadata |
| ^photo_file_uris | string | Y | Photo file uris, not a file upload. Use [Upload Shoppable Photo File] to upload the image and obtain the photo_file_uri, then pass that URI in this field |
| music_id | string | N | Music ID |
| title | string | N | Post title:The maximum length is 5000 in UTF-16 runes. If not specified, the ticket post will not have any captions.   - You can add relevant hashtags to increase discoverability. The format is simply # followed by the topic name. Multiple hashtags are supported,e.g.,#humor#BFCM |
| link_info | object | N | Photo anchor and linking metadata |
| ^post_type | string | Y | 1-LINK_TO_PRODUCT, 2-LINK_TO_SHOP, 3-LINK_TO_ONE_PIC_ONE_PRODUCT |
| ^shop_info | object | N | Shop Info |
| ^^shop_id | string | N | Shop ID |
| ^^group_type | string | N | 1 for shop_home_page, 2 for category, 3 for collection |
| ^^group_id | string | N | Category ID/Collection ID. Use [Get Shop Category And Collection] to retrieve a valid category_id or collection_id, then set it in this field |
| ^links | []object | N | Photo Anchor List |
| ^^product_id | string | N | Product ID |
| ^^link_title | string | N | Photo Anchor Title:The title to be shown on the product anchor. Anchor title should be shorter than 30 characters |
| is_ai_generated | bool | N | Field to indicate whether the content was AI generated. Marking this field as true will display a tag indicating this post as an AI generated post. |
