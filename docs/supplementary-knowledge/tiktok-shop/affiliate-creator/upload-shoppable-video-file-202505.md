# Upload Shoppable Video File

> **Source:** [https://partner.tiktokshop.com/docv2/page/upload-shoppable-video-file-202505](https://partner.tiktokshop.com/docv2/page/upload-shoppable-video-file-202505)
> **Category:** Affiliate creator
> **document_path:** `upload-shoppable-video-file-202505`

## Description

Upload a video file before posting a shoppable video to TikTok. After the upload succeeds, call `POST /affiliate_creator/202505/videos` and pass the returned `video_file.id` as `video_info.file_id`.

## Required scope

creator.video.write

## Path

`/affiliate_creator/202505/videos/video_files`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: multipart/form-data |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| data | file | Y | The local file to be uploaded.<br>Note：<br>- For files larger than 10 MB, use the [Large File Uploads](https://partner.tiktokshop.com/docv2/page/wfi3nz36).<br>- Supported formats: MP4, MOV, MKV, WMV, WEBM, AVI, 3GP, FLV, MPEG<br>- Max video size: 10 MB<br>- Video aspect ratio: 9:16 to 16:9<br>Recommendations for product videos:<br>- Resolution: 720p or higher<br>- Duration: > 30 seconds |
