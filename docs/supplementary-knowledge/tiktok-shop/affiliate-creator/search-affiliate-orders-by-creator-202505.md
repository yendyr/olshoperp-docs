# Search Affiliate Orders by Creator

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-affiliate-orders-by-creator-202505](https://partner.tiktokshop.com/docv2/page/search-affiliate-orders-by-creator-202505)
> **Category:** Affiliate creator
> **document_path:** `search-affiliate-orders-by-creator-202505`

## Description

Retrieves affiliate orders attributed to the creator represented by the current access token. Results can provide order status and timestamps, together with SKU-level product, shop, content, trace, quantity, price, and estimated or actual commission details.

## Required scope

creator.affiliate.share_link.read

## Path

`/affiliate_creator/202505/orders/trace/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| time_ge | int | Y | The inclusive start of the time range for the selected `time_type`, as a Unix timestamp in milliseconds. Orders with timestamps greater than or equal to `time_ge` and less than `time_lt` are included. |
| time_lt | int | Y | The exclusive end of the time range for the selected `time_type`, as a Unix timestamp in milliseconds. Orders with timestamps greater than or equal to `time_ge` and less than `time_lt` are included. |
| time_type | string | N | Specifies the type of timestamp to filter the orders by. The query time range (time_ge and time_lt) will be applied to the selected time type.<br>Possible values:<br>- PAY_TIME: Filter based on the order payment time.<br>- DELIVERY_TIME: Filter based on the order delivery/shipment time.<br>- SETTLE_TIME: Filter based on the order settlement time.<br>- CREATE_TIME (default): Filter based on the order creation time. |
