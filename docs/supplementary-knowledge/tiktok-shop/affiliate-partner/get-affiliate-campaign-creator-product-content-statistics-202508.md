# Get Affiliate Campaign Creator Product Content Statistics

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-affiliate-campaign-creator-product-content-statistics-202508](https://partner.tiktokshop.com/docv2/page/get-affiliate-campaign-creator-product-content-statistics-202508)
> **Category:** Affiliate partner
> **document_path:** `get-affiliate-campaign-creator-product-content-statistics-202508`

## Description

Retrieves performance statistics for a creator's video or live-room content associated with an affiliate campaign product.

## Required scope

partner.tap_campaign.read

## Path

`/affiliate_partner/202508/campaigns/{campaign_id}/products/{product_id}/creator/{creator_temp_id}/content/statistics`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |

| x-tts-access-token | string | Y | The partner access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 3.
