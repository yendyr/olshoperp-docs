# Generate Campaign Product Promotion Links in Batch

> **Source:** [https://partner.tiktokshop.com/docv2/page/generate-campaign-product-promotion-links-in-batch-202505](https://partner.tiktokshop.com/docv2/page/generate-campaign-product-promotion-links-in-batch-202505)
> **Category:** Affiliate partner
> **document_path:** `generate-campaign-product-promotion-links-in-batch-202505`

## Description

Generate promotion links for multiple products in an online campaign. For OPS or seller-initiated campaigns, use the joined campaign ID created after the partner joins the campaign, not the original campaign ID.

## Required scope

partner.tap_campaign.read

## Path

`/affiliate_partner/202505/campaigns/{campaign_id}/products/promotion_links/generate_batch`

## Method

`POST`
