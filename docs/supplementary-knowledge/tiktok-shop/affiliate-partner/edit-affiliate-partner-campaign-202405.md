# Edit Affiliate Partner Campaign

> **Source:** [https://partner.tiktokshop.com/docv2/page/edit-affiliate-partner-campaign-202405](https://partner.tiktokshop.com/docv2/page/edit-affiliate-partner-campaign-202405)
> **Category:** Affiliate partner
> **document_path:** `edit-affiliate-partner-campaign-202405`

## Description

Partially updates an Affiliate Partner campaign. Fields omitted from the request retain their current values, including omitted fields within `contact_info`. `target_seller_types` and `target_shop_codes` are mutually exclusive. To switch targeting modes, send the previously used field as an empty array and the new field with its values. Campaigns cannot be edited after they are closed.

## Required scope

partner.tap_campaign.write

## Path

`/affiliate_partner/202405/campaigns/{campaign_id}/partial_edit`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | N | The campaign name. It must contain 1 to 50 characters and must not start with a space. |
| description | string | N | The campaign description. It must contain 1 to 1000 characters and must not start with a space. |
| campaign_start_time | int | N | The scheduled campaign start time as a Unix timestamp in seconds. This field can be updated only when the campaign status is `READY` or `UPCOMING`. |
| campaign_end_time | int | N | The scheduled end time in Unix epoch time format for the campaign. Note that the end time must be less than 360 days from the start date. This field is no longer editable when the campaign status is set to `CLOSED`.  |
| registration_start_time | int | N | The scheduled start time for seller product registration, as a Unix timestamp in seconds. This field can be updated only when the campaign status is `READY` or `UPCOMING`. |
| registration_end_time | int | N | The scheduled end time for seller product registration, as a Unix timestamp in seconds. This field is no longer editable when the campaign status is `CLOSED`. |
| commission_rate | int | N | The total commission rate, in units of 0.01%, proposed by the affiliate partner for display to sellers. The value must be between 100 and 8000, inclusive. |
| contact_info | object | N | The partner's contact information. |
| ^whatsapp | string | N | The partner's phone number registered in WhatsApp, in E.164 international format. Applicable if the target market is MY, SG, GB, ID, or US. |
| ^email | string | N | The partner's email address. |
| ^phone | string | N | The partner's phone number in E.164 international format. |
| ^zalo | string | N | The partner's phone number registered in Zalo, in E.164 international format. Applicable if the target market is VN. |
| ^viber | string | N | The partner's phone number registered in Viber, in E.164 international format. Applicable if the target market is PH. |
| ^line | string | N | The partner's phone number registered in LINE, in E.164 international format. Applicable if the target market is TH. |
| target_shop_codes | []string | N | A list of TikTok Shop seller shop codes to allow to register for the campaign. The seller shop code in available in TikTok Shop Seller Central by clicking on the Seller Profile icon in the top right of the user interface. The list must be less than 100 items in length. |
| target_seller_types | []string | N | A list of eligible seller types to allow to register for the campaign. Use this field to broadly target types of sellers instead of specific sellers in the `target_shop_codes` field. This is an enumerated type with possible values:<br>- LOCAL<br>- CROSS_BORDER |
