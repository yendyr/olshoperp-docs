# Generate Affiliate Partner Campaign Product Link

> **Source:** [https://partner.tiktokshop.com/docv2/page/generate-affiliate-partner-campaign-product-link-202405](https://partner.tiktokshop.com/docv2/page/generate-affiliate-partner-campaign-product-link-202405)
> **Category:** Affiliate partner
> **document_path:** `generate-affiliate-partner-campaign-product-link-202405`

## Description

Generates a promotion link for a product in an existing online campaign. The product must be associated with the campaign and appear in the response from Get Affiliate Partner Campaign Product List with `review_status` set to `APPROVED` or `PENDING_CLOSED`.

## Required scope

partner.tap_campaign.link.write

## Path

`/affiliate_partner/202405/campaigns/{campaign_id}/products/{product_id}/promotion_link/generate`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The partner access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 3. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a3978f4c20311b8b555) to get partner access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |

| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| category_asset_cipher | string | Y | The partner identifier used in API requests. Retrieve this value by using the [Get Authorized Category Assets API](https://partner.tiktokshop.com/docv2/page/666012dd609d4402cc3be995). |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| creator_commission_rate | int | Y | The commission rate paid to a creator, in hundredths of a percent (0.01%). The value must be at least 100 (1%) and no greater than the total commission rate set by the seller. |
