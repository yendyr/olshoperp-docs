# Create Affiliate Partner Campaign

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-affiliate-partner-campaign-202405](https://partner.tiktokshop.com/docv2/page/create-affiliate-partner-campaign-202405)
> **Category:** Affiliate partner
> **document_path:** `create-affiliate-partner-campaign-202405`

## Description

Creates an affiliate partner campaign for either specific sellers identified by shop code or eligible seller types. Configure the campaign period, seller registration period, commission rate, and contact information. When the campaign is created successfully, the operation returns the new `campaign_id` synchronously. The campaign is not displayed to sellers after creation. To publish a successfully created campaign, call `POST /affiliate_partner/202405/campaigns/{campaign_id}/publish` with the returned campaign ID.

## Required scope

partner.tap_campaign.write

## Path

`/affiliate_partner/202405/campaigns`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | Y | The campaign name. Must contain 1 to 50 characters, inclusive, and must not start with a space. |
| description | string | Y | The campaign description. Must contain 1 to 1000 characters, inclusive, and must not start with a space. |
| campaign_start_time | int | Y | The scheduled campaign start time as a Unix timestamp in seconds. It must not be earlier than the current time. In subsequent edits, this value can be changed only when the campaign status is `READY` or `UPCOMING`. |
| campaign_end_time | int | Y | The scheduled campaign end time as a Unix timestamp in seconds. It must be later than `campaign_start_time`, and the campaign period must be between 1 and 360 days, inclusive. In subsequent edits, this value cannot be changed when the campaign status is `CLOSED`. |
| registration_start_time | int | Y | The scheduled start time for seller product registration as a Unix timestamp in seconds. It must be equal to `campaign_start_time`. In subsequent edits, this value can be changed only when the campaign status is `READY` or `UPCOMING`. |
| registration_end_time | int | Y | The scheduled end time for seller product registration as a Unix timestamp in seconds. It must be later than `registration_start_time`; the registration period must be at least 1 day and must not extend beyond `campaign_end_time`. In subsequent edits, this value cannot be changed when the campaign status is `CLOSED`. |
| commission_rate | int | Y | The total commission rate, in hundredths of a percent (0.01%) units, proposed by the affiliate partner for display to sellers. The value must be between 100 and 8000, inclusive. |
| contact_info | object | Y | The partner's contact information. |
| ^whatsapp | string | N | The partner's phone number registered in WhatsApp, in E.164 international format. Required if the target market is MY, SG, GB, or ID; optional if the target market is US; otherwise, not applicable. |
| ^email | string | Y | The partner's email address. |
| ^phone | string | N | The partner's phone number in E.164 international format. |
| ^zalo | string | N | The partner's phone number registered in Zalo, in E.164 international format. Required if the target market is VN; otherwise, not applicable. |
| ^viber | string | N | The partner's phone number registered in Viber, in E.164 international format. Required if the target market is PH; otherwise, not applicable. |
| ^line | string | N | The partner's phone number registered in LINE, in E.164 international format. Required if the target market is TH; otherwise, not applicable. |
| target_shop_codes | []string | N | A list of TikTok Shop seller shop codes that may register for the campaign. Find a seller's shop code in TikTok Shop Seller Central by selecting the Seller Profile icon in the top-right corner of the user interface. Specify exactly one of `target_shop_codes` and `target_seller_types`. The list must contain fewer than 100 items. |
| target_seller_types | []string | N | A list of eligible seller types that may register for the campaign. Use this field to target seller types instead of specific sellers in `target_shop_codes`. Specify exactly one of `target_seller_types` and `target_shop_codes`.<br>Possible values:<br>- `LOCAL`<br>- `CROSS_BORDER` |
