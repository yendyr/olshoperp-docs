# Get Affiliate Partner Campaign List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-affiliate-partner-campaign-list-202405](https://partner.tiktokshop.com/docv2/page/get-affiliate-partner-campaign-list-202405)
> **Category:** Affiliate partner
> **document_path:** `get-affiliate-partner-campaign-list-202405`

## Description

Lists campaigns for an affiliate partner, filtered by campaign category, participation state, and campaign status.

## Required scope

partner.tap_campaign.read

## Path

`/affiliate_partner/202405/campaigns`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The partner access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 3. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a3978f4c20311b8b555) to get partner access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| category_asset_cipher | string | Y | The partner identifier used in API requests. Retrieve this value by using the [Get Authorized Category Assets API](https://partner.tiktokshop.com/docv2/page/666012dd609d4402cc3be995).  |
| page_size | int | Y | The number of campaigns to return per page. Valid range: 1-100. |
| page_token | string | N | An opaque token used to retrieve the next page of a paginated result set. Retrieve this value from the result of the `next_page_token` from a previous response. It is not needed for the first page. Maximum page size is `100` items. |
| status | string | N | This parameter is required.<br>The campaign status. The status is an enumerated type with values:<br>- `READY`<br>- `UPCOMING`<br>- `ONGOING`<br>- `CLOSED`<br>- `UNSPECIFIED` |
| type | string | N | The campaign type. This is an enumerated type with values: <br>- MY_CAMPAIGNS<br>- GS_SELLING_CAMPAIGNS <br>- SELLER_CAMPAIGNS<br>- EXCLUSIVE_TIKTOK_SHOP  <br>Default value is MY_CAMPAIGNS. |
| query_type_filter | string | N | An additional filter whose valid values depend on `type`:<br>- `SELLER_CAMPAIGNS`: `query_type_filter` is required. Set it to `MARKETPLACE` to include campaigns that the partner has not joined, or `JOINED` to include only campaigns that the partner has joined. When using `MARKETPLACE`, set `status` to `UNSPECIFIED`.<br>- `EXCLUSIVE_TIKTOK_SHOP`: `query_type_filter` is required. Set it to `AVAILABLE` to include campaigns that the partner is permitted to join, or `JOINED` to include only campaigns that the partner has joined. For either value, set `status` to `UNSPECIFIED`.<br>- `MY_CAMPAIGNS` or `GS_SELLING_CAMPAIGNS`: omit `query_type_filter` or set it to `DEFAULT`. |
