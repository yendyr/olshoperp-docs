# Add External Order References

> **Source:** [https://partner.tiktokshop.com/docv2/page/add-external-order-references-202406](https://partner.tiktokshop.com/docv2/page/add-external-order-references-202406)
> **Category:** Orders
> **document_path:** `add-external-order-references-202406`

## Description

If you use an external order management system (OMS), its order and line item IDs may differ from the corresponding TikTok Shop IDs. Use this endpoint to attach external OMS references to up to 100 TikTok Shop orders. To update an existing reference, call the endpoint again with the same TikTok Shop order and OMS. Each order is processed independently. On a successful API response, references for orders not listed in `data.errors` are saved; use that list to identify per-order errors.

## Required scope

seller.order.ext_ref.write.custom, seller.order.ext_ref.write

## Path

`/order/202406/orders/external_orders`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| orders | []object | Y | Orders for which to add or update external OMS references. Min count: 1. Max count: 100. |
| ^id | string | Y | The unique identifier for a TikTok Shop order. |
| ^external_order | object | Y | Order information in your external order management system (OMS). |
| ^^id | string | Y | The corresponding order ID in your OMS. |
| ^^platform | string | Y | The alias of your OMS.<br>Possible values:<br>- SHOPIFY<br>- WOOCOMMERCE<br>- BIGCOMMERCE<br>- MAGENTO<br>- SALESFORCE_COMMERCE_CLOUD<br>- CHANNEL_ADVISOR<br>- AMAZON<br>- ORDER_MANAGEMENT_SYSTEM<br>- WAREHOUSE_MANAGEMENT_SYSTEM<br>- ERP_SYSTEM<br><br>Notes:<br>- To attach information from multiple OMSs to the same order in TikTok Shop, call this API multiple times, each with the same TikTok Shop order and a different OMS.<br>- To edit the attached information for a TikTok Shop order, call the API with the same OMS. |
| ^^line_items | []object | Y | Max count: 100. |
| ^^^id | string | Y | Line item ID in your OMS. |
| ^^^origin_id | string | Y | Line item ID in TikTok Shop. |
