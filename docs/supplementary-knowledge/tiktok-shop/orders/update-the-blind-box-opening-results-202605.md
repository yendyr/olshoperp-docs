# Update The Blind Box Opening Results

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-the-blind-box-opening-results-202605](https://partner.tiktokshop.com/docv2/page/update-the-blind-box-opening-results-202605)
> **Category:** Orders
> **document_path:** `update-the-blind-box-opening-results-202605`

## Description

After the merchant completes blind box opening in a live room, use this callback to send the opening results for an order back to the platform. The request supports two result shapes: `blind_box_results` contains one unboxed product per item, while `blind_batch_box_results` groups one or more unboxed products under an order line. If `blind_batch_box_results` is non-empty, the platform processes it and ignores `blind_box_results`. Buyers can then view the unboxing results in the order details.

## Required scope

seller.order.info

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| main_order_id | string | N | The unique identifier for a TikTok Shop order. |
| blind_box_results | []object | N | When using the legacy result shape, provide unboxing results for one or more blind-box line items in the specified order. |
| ^order_line_id | string | N | The TikTok Shop line item ID for the blind box in the specified order. |
| ^blind_result_product_id | string | N | The TikTok Shop product ID revealed by opening the blind box. |
| ^blind_result_sku_id | string | N | The TikTok Shop SKU ID revealed by opening the blind box. |
| ^blind_open_time | int | N | Unix timestamp in milliseconds indicating when the blind box was opened. |
| blind_batch_box_results | []object | N | Unboxing batch results for line items under orders. |
| ^order_line_id | string | N | The TikTok Shop line item ID of the blind box in the specified order to which this batch unboxing result belongs. |
| ^blind_box_order_line_list | []object | N | Unboxing results for line items under orders. on batch box version |
| ^^blind_result_product_id | string | N | The TikTok Shop product ID revealed for this item in the batch unboxing result. |
| ^^blind_result_sku_id | string | N | The TikTok Shop SKU ID revealed for this item in the batch unboxing result. |
| ^^blind_open_time | int | N | Unix timestamp in milliseconds indicating when the blind box was opened. |
| ^^product_type | string | N | Unboxing product type.<br>Possible values:<br>- `NORMAL`: A normal unboxed product.<br>- `GIFT`: A gift unboxed product. |
