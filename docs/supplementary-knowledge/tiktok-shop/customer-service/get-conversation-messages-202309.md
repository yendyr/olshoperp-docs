# Get Conversation Messages

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-conversation-messages-202309](https://partner.tiktokshop.com/docv2/page/get-conversation-messages-202309)
> **Category:** Customer service
> **document_path:** `get-conversation-messages-202309`

## Description

Use this API to retrieve a page of messages in a conversation between a buyer and a shop.
Calling this API does not mark messages as read. Call [Read Message](650a59f7c16ffe02b8e8db3f) to mark them as read.

## Required scope

seller.customer_service

## Path

`/customer_service/202309/conversations/{conversation_id}/messages`

## Method

`GET`
