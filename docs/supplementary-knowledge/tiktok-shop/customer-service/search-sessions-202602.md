# Search Sessions

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-sessions-202602](https://partner.tiktokshop.com/docv2/page/search-sessions-202602)
> **Category:** Customer service
> **document_path:** `search-sessions-202602`

## Description

Search customer service sessions by their start-time range and, optionally, the buyer's nickname.

## Required scope

seller.customer_service

## Path

`/customer_service/202602/sessions/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. ## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| begin_time_ge | int | Y | Return sessions whose begin_time is greater than or equal to this Unix timestamp, in seconds. Only data from the last 90 days is supported. |
| begin_time_lt | int | Y | Return sessions whose begin_time is less than this Unix timestamp, in seconds. The value must be greater than or equal to begin_time_ge. |
| buyer_nickname | string | N | Filter sessions by the buyer's nickname. |
