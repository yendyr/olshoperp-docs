# Get Activity

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-activity-202309](https://partner.tiktokshop.com/docv2/page/get-activity-202309)
> **Category:** Promotion
> **document_path:** `get-activity-202309`

## Description

Get the details of a promotion activity. Product information for `FIXED_PRICE`, `DIRECT_DISCOUNT`, and `FLASHSALE` activities that ended more than 180 days ago will not be returned. For coupon activities, use [Get Coupon](6699dce0de15e502ed219e37).

## Required scope

seller.promotion.info

## Path

`/promotion/202309/activities/{activity_id}`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
