# Republish Activity

> **Source:** [https://partner.tiktokshop.com/docv2/page/republish-activity-202607](https://partner.tiktokshop.com/docv2/page/republish-activity-202607)
> **Category:** Promotion
> **document_path:** `republish-activity-202607`

## Description

Use this API to republish a product discount activity or a flash deal activity that expired or was deactivated within the last 7 days. This API only supports FIXED_PRICE, FLASHSALE, and DIRECT_DISCOUNT activities. You must provide a new effective period by passing the new begin_time and end_time. Products and SKUs already associated with the activity do not need to be added again. After the activity is republished, you can edit the activity and modify its products or SKUs as usual. We recommend using this API instead of recreating the activity to reduce requests to the API for adding products.

## Required scope

seller.promotion.write

## Path

`/promotion/202607/activities/{activity_id}/republish`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| end_time | int | N | Activity end time as a Unix timestamp in seconds. It must be later than begin_time, and the effective period must be at least 10 minutes. The maximum period depends on the activity type and shop region; for FLASHSALE activities, it must not exceed 3 days. |
| begin_time | int | N | Activity start time as a Unix timestamp in seconds. The value must be later than the current time. |
