# Search Coupon List

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-coupon-list-202406](https://partner.tiktokshop.com/docv2/page/search-coupon-list-202406)
> **Category:** Promotion
> **document_path:** `search-coupon-list-202406`

## Description

Use this API to search coupons. Supported coupon creation sources include TikTok Shop Seller Center, the TikTok Seller App, and TikTok Shop CRM. Different supplied filters are combined with AND. Within status or display_type, multiple values are combined with OR. title_keyword performs phrase-prefix matching against the coupon title. For full details about a specific coupon, use the Get Coupon API.

## Required scope

seller.promotion.info, seller.customer_service

## Path

`/promotion/202406/coupons/search`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| status | []string | N | Coupon's promotion status.<br>Values:<br>- `NOT_START`: Not available to TikTok users until the coupon's configured start time.<br>- `ONGOING`: Available to TikTok users.<br>- `EXPIRED`: Not available to TikTok users because it has expired.<br>- `DEACTIVATED`: Deactivated by the seller and is not available to TikTok users. |
| title_keyword | string | N | Keywords in coupon titles to search for. The UTF-8 byte length must be from 1 to 100. Fuzzy matching is not supported. |
| display_type | []string | N | The display type of coupons.<br>Values:<br>- `REGULAR`: Regular coupons which are displayed to TikTok users across all display locations available in TTS, including PLPs, PDPs, TikTok Videos, LIVE Rooms, Creator Showcases, and may be shared via TTS Customer Support instant messages. Includes coupons which target select customer segments.<br>- `LIVE`: Coupons which are only displayed to TikTok users in LIVE Rooms.<br>- `CREATOR_EXCLUSIVE`: Coupons that can be claimed through the display channels of the specified creator, such as their LIVE Rooms, and their Creator Showcase.<br>- `CHAT`: Exclusive coupons that may be sent to customers via TTS customer support chat messages, but are not displayed in other display locations.<br>- `PROMO_CODE`: Promo codes do not have dedicated display locations on TikTok, but may be shared with customers in LIVEs, in TikTok videos, or other social media platforms. They can be claimed by customers entering a claim code at checkout or by customers that use a custom promo code landing page URL. |
