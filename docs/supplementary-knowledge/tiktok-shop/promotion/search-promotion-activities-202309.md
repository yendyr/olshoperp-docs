# Search Promotion Activities

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-promotion-activities-202309](https://partner.tiktokshop.com/docv2/page/search-promotion-activities-202309)
> **Category:** Promotion
> **document_path:** `search-promotion-activities-202309`

## Description

Search product discount, flash sale, shipping discount, Buy More Save More, Gift With Purchase, and Buy X Get Y promotion activities. For coupon activities, use [Search Coupons](https://partner.tiktokshop.com/docv2/page/6699dcdf115ebe02f841e4cd).

## Required scope

seller.promotion.info

## Path

`/promotion/202309/activities/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| status | string | N | Filter activities by status. If omitted, activities with `NOT_START`, `ONGOING`, `EXPIRED`, or `DEACTIVATED` status are returned. Possible values:<br>- `NOT_START`: The activity is not available to TikTok users until its start time.<br>- `ONGOING`: The activity is available to TikTok users.<br>- `EXPIRED`: The activity is no longer available because it has expired.<br>- `DEACTIVATED`: The activity was deactivated by the seller and is not available to TikTok users. |
| activity_title | string | N | Activity title key words. No fuzzy matching. |
| page_size | int | N | Number of activities to return per page. Range: 0 to 100. If omitted or set to 0, the effective page size is 10. |
| page_token | string | N | Specify the value for the page. Use `""` for the first page. |
| activity_type | string | N | The type of promotion activity to return. If `activity_type` is omitted, activities of all supported types are returned. Possible values:<br>- `FIXED_PRICE`: Product discount activity with a fixed price.<br>- `DIRECT_DISCOUNT`: Product discount activity with a percentage off.<br>- `FLASHSALE`: Flash sale activity.<br>- `SHIPPING_DISCOUNT`: Shipping fee discount activity.<br>- `BUY_MORE_SAVE_MORE`: Buy More Save More activity.<br>- `GIFT_WITH_PURCHASE`: Gift With Purchase activity.<br>- `BUY_X_GET_Y`: Buy X Get Y activity. |
