# Get Bestselling Creators

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-bestselling-creators-202511](https://partner.tiktokshop.com/docv2/page/get-bestselling-creators-202511)
> **Category:** Analytics
> **document_path:** `get-bestselling-creators-202511`

## Description

Returns up to 100 creators, filtered by `author_type`, ranked by GMV in the selected `currency` for the reporting period ending on `date` and defined by `time_slot`.

## Required scope

data.bestselling.public.read

## Path

`/analytics/202511/creators/bestselling`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. | currency | string | N | Currency for monetary values. Supported values are:<br>- USD — US dollars<br>- LOCAL — the local currency where the shop is registered<br>If omitted, defaults to LOCAL. |
