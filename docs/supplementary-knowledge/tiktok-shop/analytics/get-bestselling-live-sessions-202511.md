# Get Bestselling LIVE Sessions

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-bestselling-live-sessions-202511](https://partner.tiktokshop.com/docv2/page/get-bestselling-live-sessions-202511)
> **Category:** Analytics
> **document_path:** `get-bestselling-live-sessions-202511`

## Description

Get up to 100 LIVE sessions ranked by GMV for the period defined by `date` and `time_slot`.

## Required scope

data.bestselling.public.read

## Path

`/analytics/202511/lives/bestselling`

## Method

`GET`
