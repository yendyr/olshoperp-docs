# Get Shop SKU Performance List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-sku-performance-list-202509](https://partner.tiktokshop.com/docv2/page/get-shop-sku-performance-list-202509)
> **Category:** Analytics
> **document_path:** `get-shop-sku-performance-list-202509`

## Description

Returns a paginated list of performance metrics for the shop's SKUs over the requested date range.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202509/shop_skus/performance`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| start_date_ge | string | Y | Start time (ISO 8601 YYYY-MM-DD format) in shop registered timezone, inclusive. |
| end_date_lt | string | Y | End date of the performance period, exclusive, in the shop's registered time zone. Use YYYY-MM-DD format. It must be later than start_date_ge. |
| page_size | int | N | Number of records per page. If omitted, defaults to 10. Maximum: 100. |
| page_token | string | N | Token that identifies the page to retrieve. Omit it for the first page. For later pages, pass the `next_page_token` returned by the previous response and reuse the same `start_date_ge`, `end_date_lt`, `sort_field`, `sort_order`, `category_filter`, `product_status_filter`, `product_ids`, `currency`, and `page_size` values. |
| sort_field | string | N | Sort field, possible values:<br>-  gmv (default)<br>- sku_orders<br>- units_sold |
| sort_order | string | N | Sort direction, possible values:<br>- DESC (default)<br>- ASC |
| category_filter | []string | N | List of category IDs used to filter returned SKU performance records. |
| product_status_filter | string | N | Filter SKUs by product status. Possible values:<br>- LIVE<br>- INACTIVE<br>- ALL (default) |
| product_ids | []string | N | Filter SKUs by product IDs. If product_ids are provided, the API will only return SKUs for the given product IDs, otherwise it will return all SKUs for the shop |
| currency | string | N | Currency used to report GMV:<br>- USD: U.S. dollars<br>- LOCAL (default): Local currency where the shop is located |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |
