# Get Shop Videos Performance Details

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-videos-performance-details-202609](https://partner.tiktokshop.com/docv2/page/get-shop-videos-performance-details-202609)
> **Category:** Analytics
> **document_path:** `get-shop-videos-performance-details-202609`

## Description

Returns detailed performance metrics for the requested videos.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202609/shop_videos/batch_performance`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| video_ids | []int | Y | The IDs of the shop videos whose performance details are requested. |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| start_date_ge | string | Y | Start date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "ge" refers to "greater than or equal to" (inclusive)<br><br>The time range between start and end must not exceed 60 days. |
| end_date_lt | string | Y | End date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "lt" refers to "less than" (exclusive)<br><br>The time range between start and end must not exceed 60 days. |
| granularity | string | N | Granularity of the data.<br>Available values: ALL, 1D<br>Default value: ALL<br>* ALL: aggregate<br>* 1D: daily |
| currency | string | N | Currently, only local currency is supported in the response.<br><br>Available values: USD, LOCAL<br>Default value: LOCAL<br>* USD: US dollars<br>* LOCAL: local currency where the shop is located |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |
