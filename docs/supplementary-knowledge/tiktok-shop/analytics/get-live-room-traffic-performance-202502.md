# Get Live Room Traffic Performance

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-traffic-performance-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-traffic-performance-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-traffic-performance-202502`

## Description

Returns traffic performance for a live room owned by the authenticated creator, including watch counts grouped by primary traffic source and sub-source for distribution analysis.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/traffic_performances`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |

Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |
