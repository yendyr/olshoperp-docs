# Get Shop Performance Per Hour

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-performance-per-hour-202510](https://partner.tiktokshop.com/docv2/page/get-shop-performance-per-hour-202510)
> **Category:** Analytics
> **document_path:** `get-shop-performance-per-hour-202510`

## Description

Returns hourly shop performance details for the requested date. The date can be within the last 30 days, including today.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202510/shop/performance/{date}/performance_per_hour`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |

Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
