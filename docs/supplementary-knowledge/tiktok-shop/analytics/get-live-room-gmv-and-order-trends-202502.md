# Get Live Room GMV and Order Trends

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-gmv-and-order-trends-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-gmv-and-order-trends-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-gmv-and-order-trends-202502`

## Description

Returns GMV trend performance points for the specified live room, including GMV and created-order trend values.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/gmv_trend_performances`

## Method

`GET`
