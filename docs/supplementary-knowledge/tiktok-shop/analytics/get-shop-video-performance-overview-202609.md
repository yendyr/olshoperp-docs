# Get Shop Video Performance Overview

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-video-performance-overview-202609](https://partner.tiktokshop.com/docv2/page/get-shop-video-performance-overview-202609)
> **Category:** Analytics
> **document_path:** `get-shop-video-performance-overview-202609`

## Description

Returns overall performance metrics for all videos under a shop.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202609/shop_videos/overview_performance`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
