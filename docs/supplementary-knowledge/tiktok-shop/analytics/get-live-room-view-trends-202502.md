# Get Live Room View Trends

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-view-trends-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-view-trends-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-view-trends-202502`

## Description

Returns viewer count trend data points for the specified live room, grouped by online, entering, and leaving viewers.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/view_trend_performances`

## Method

`GET`
