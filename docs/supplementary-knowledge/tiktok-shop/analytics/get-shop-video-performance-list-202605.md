# Get Shop Video Performance List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-video-performance-list-202605](https://partner.tiktokshop.com/docv2/page/get-shop-video-performance-list-202605)
> **Category:** Analytics
> **document_path:** `get-shop-video-performance-list-202605`

## Description

Returns a list of videos and associated metrics for a shop.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202605/shop_videos/performance`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| start_date_ge | string | Y | Start date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "ge" refers to "greater than or equal to" (inclusive)<br><br>The time range between start and end must not exceed 60 days. |
| end_date_lt | string | Y | End date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "lt" refers to "less than" (exclusive).<br><br>The time range between start and end must not exceed 60 days.<br> |
| page_size | int | N | Number of videos per page.<br>Minimum value: 1<br>Maximum value: 100<br>Default value: 10 |
| sort_field | string | N | Field used to sort the shop video performance list.<br>Default value: gmv<br>Available values:<br>- gmv: sort by overall Gross Merchandise Value (GMV).<br>- gpm: sort by average GMV generated from 1,000 views.<br>- avg_customers: sort by daily average customers.<br>- sku_orders: sort by paid SKU orders.<br>- items_sold: sort by units sold.<br>- views: sort by video views.<br>- click_through_rate: sort by the ratio of product clicks to video views.<br>- post_time: sort by the time the video was posted. |
| sort_order | string | N | Sort direction.<br>Available values: ASC, DESC<br>Default value: DESC<br>* ASC: ascending<br>* DESC: descending |
| currency | string | N | Currently, only local currency is supported in the response.<br><br>Available values: USD, LOCAL<br>Default value: LOCAL<br>* USD: US dollars<br>* LOCAL: local currency where the shop is located |
| page_token | string | N | Page token, indicating the current position. Used for requesting next page data.<br>Leave this field empty for first time queries. |
| account_type | string | N | Types of the accounts under which videos were created.<br>Available values: ALL, OFFICIAL_ACCOUNTS, MARKETING_ACCOUNTS, AFFILIATE_ACCOUNTS<br>Default value: ALL<br>- ALL: all account types<br>- OFFICIAL_ACCOUNTS: official accounts<br>- MARKETING_ACCOUNTS: marketing accounts<br>- AFFILIATE_ACCOUNTS: affiliate accounts |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |
