# Get Shop LIVE Products Performance List

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-live-products-performance-list-202512](https://partner.tiktokshop.com/docv2/page/get-shop-live-products-performance-list-202512)
> **Category:** Analytics
> **document_path:** `get-shop-live-products-performance-list-202512`

## Description

Returns sale performance for each product in a shop-related LIVE session from the official account or marketing accounts.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202512/shop/{live_id}/products_performance`

## Method

`GET`
