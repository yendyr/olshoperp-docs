# Get Live Room Interactive Trends

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-interactive-trends-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-interactive-trends-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-interactive-trends-202502`

## Description

Returns interactive trend performance points for the specified live room, including watch, comment, and share counts.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/interactive_trend_performances`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The creator access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 1. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a362dccb8030ea6f98c) to get creator access_token. |
