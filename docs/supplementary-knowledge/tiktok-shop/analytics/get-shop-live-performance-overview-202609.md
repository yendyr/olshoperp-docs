# Get Shop LIVE Performance Overview

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-shop-live-performance-overview-202609](https://partner.tiktokshop.com/docv2/page/get-shop-live-performance-overview-202609)
> **Category:** Analytics
> **document_path:** `get-shop-live-performance-overview-202609`

## Description

Returns overall performance metrics for all LIVE stream sessions under a certain shop.

## Required scope

data.shop_analytics.public.read

## Path

`/analytics/202609/shop_lives/overview_performance`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| start_date_ge | string | Y | Start date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "ge" refers to "greater than or equal to" (inclusive) |
| end_date_lt | string | Y | End date (ISO 8601 YYYY-MM-DD format) in shop registered timezone.<br>In the parameter name, "lt" refers to "less than" (exclusive) |
| today | bool | N | If "today" is set to true, start_date_ge and end_date_lt will be overwritten.<br>The response will contain real-time metrics of today (local time) |
| granularity | string | N | Granularity of the data.<br>Available values:<br>- ALL: Aggregate data for the full requested time range.<br>- 1D: Daily data.<br>Default value: ALL |
| currency | string | N | Currently, only local currency is supported in the response.<br><br>Available values:<br>- USD: US dollars.<br>- LOCAL: Local currency where the shop is located.<br>Default value: LOCAL |
| account_type | string | N | Types of the accounts under which videos were created.<br>Available values:<br>- ALL: All account types.<br>- LINKED_ACCOUNTS: Linked accounts.<br>- AFFILIATE_ACCOUNTS: Affiliate accounts.<br>Default value: ALL |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API.
