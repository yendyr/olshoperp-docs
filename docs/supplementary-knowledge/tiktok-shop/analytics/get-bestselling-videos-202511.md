# Get Bestselling Videos

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-bestselling-videos-202511](https://partner.tiktokshop.com/docv2/page/get-bestselling-videos-202511)
> **Category:** Analytics
> **document_path:** `get-bestselling-videos-202511`

## Description

Returns up to 100 videos ranked by gross merchandise value (GMV) in descending order for the date range selected by `date` and `time_slot`.

## Required scope

data.bestselling.public.read

## Path

`/analytics/202511/videos/bestselling`

## Method

`GET`
