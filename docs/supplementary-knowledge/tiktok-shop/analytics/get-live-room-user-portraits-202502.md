# Get Live Room User Portraits

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-user-portraits-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-user-portraits-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-user-portraits-202502`

## Description

Returns user portrait indicators for the specified live room, including age, gender, fan, advertisement, and region distributions.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/user_portraits`

## Method

`GET`
