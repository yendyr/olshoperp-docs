# Get Bestselling Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-bestselling-products-202511](https://partner.tiktokshop.com/docv2/page/get-bestselling-products-202511)
> **Category:** Analytics
> **document_path:** `get-bestselling-products-202511`

## Description

Returns up to 100 products ranked by GMV for the target date range.

## Required scope

data.bestselling.public.read

## Path

`/analytics/202511/products/bestselling`

## Method

`GET`
