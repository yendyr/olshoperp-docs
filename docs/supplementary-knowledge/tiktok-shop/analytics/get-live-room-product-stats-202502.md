# Get Live Room Product Stats

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-live-room-product-stats-202502](https://partner.tiktokshop.com/docv2/page/get-live-room-product-stats-202502)
> **Category:** Analytics
> **document_path:** `get-live-room-product-stats-202502`

## Description

Returns product performance statistics for the specified live room, including product IDs, names, GMV, unit price, inventory counts, and click counts. The live room must belong to the creator associated with the access token.

## Required scope

creator.data.live.read.public

## Path

`/analytics/202502/live_rooms/{live_room_id}/product_stats`

## Method

`GET`
