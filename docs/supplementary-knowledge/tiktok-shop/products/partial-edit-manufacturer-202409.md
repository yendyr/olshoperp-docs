# Partial Edit Manufacturer

> **Source:** [https://partner.tiktokshop.com/docv2/page/partial-edit-manufacturer-202409](https://partner.tiktokshop.com/docv2/page/partial-edit-manufacturer-202409)
> **Category:** Products
> **document_path:** `partial-edit-manufacturer-202409`

## Description

Edit the details of a manufacturer in the EU languages supported by TikTok Shop. Include the locale code to edit the manufacturer's information in a particular language.
Target seller: Local sellers operating in EU countries
**Note**:
- The manufacturer name, registered trade name, email address, local phone number, and the address field must not contain Chinese characters.
- Updates are handled per top-level property, so all non-empty fields within an updated object must be supplied to prevent overwriting with blanks.
- For top-level properties (e.g. `name`, `email`) that are not nested in an object, you can update them individually. Omitting these properties in the request will leave them unchanged.
- If you need to edit any nested property within an object, you must provide values for all nested properties of that object. Any omitted nested properties will be overwritten with blanks. For an available phone number, provide `availability=AVAILABLE`, `country_code`, and `local_number` together. If `availability=UNAVAILABLE` is supported for the seller, provide `availability=UNAVAILABLE` and omit `country_code` and `local_number`; otherwise, a valid phone number is still required.

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | N | The manufacturer name.<br>Max length: 255 characters |
| registered_trade_name | string | N | The registered trade name of the manufacturer.<br>Max length: 200 characters |
| email | string | N | The manufacturer's email address. Use a valid email format such as `name@example.com`. |
| phone_number | object | N | The phone number of the manufacturer. |
| ^availability | string | N | Indicates the availability of the phone number.<br>Possible values:<br>- `AVAILABLE`: The phone number is available and required.<br>- `UNAVAILABLE`: No phone number is available.<br><br>Default: AVAILABLE |
| ^country_code | string | N | The country code of the phone number, prefixed by a plus `+` symbol. E.g. +353 for Ireland.<br>Max digits: 4<br>Required if `availability=AVAILABLE`.  |
| ^local_number | string | N | The local number.<br>Length: 7 - 20 digits<br>Required if `availability=AVAILABLE`.  |
| address | string | N | The postal address of the manufacturer.<br>Max length: 500 characters |
| locale | string | N | The BCP-47 locale code representing the language of the manufacturer information to update.<br>Possible values:<br>- de-DE<br>- en-IE<br>- es-ES<br>- fr-FR<br>- it-IT<br>Default: The locale of the seller's registered business address.<br><br>**Note**: Only the language version selected by this locale is updated; other language versions remain unchanged. Ensure the locale matches the language used in the supplied field values. |
