# Update Global Inventory

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-global-inventory-202309](https://partner.tiktokshop.com/docv2/page/update-global-inventory-202309)
> **Category:** Products
> **document_path:** `update-global-inventory-202309`

## Description

Update the inventory of a global product in `DRAFT`, `UNPUBLISHED`, or `PUBLISHED` status. You must have access to the Multi-Warehouse feature.

## Required scope

seller.global_product.write

## Path

`/product/202309/global_products/{global_product_id}/inventory/update`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| global_skus | []object | Y | A non-empty list of global SKUs whose inventory quantities you want to set. |
| ^id | string | Y | The global SKU ID in TikTok Shop. |
| ^inventory | []object | Y | The inventory quantities to set for this global SKU, with one entry for each global warehouse to update. Existing global warehouses omitted from this array retain their current quantities. |
| ^^global_warehouse_id | string | Y | The ID of the global warehouse where the SKU is stored. The warehouse must be enabled and belong to this shop or seller. Retrieve this value from [Get Global Product](6509e2b0bace3e02b7490c96) or [Get Global Seller Warehouse](650aa3f0defece02be6e5ffb). |
| ^^quantity | int | Y | The number of inventory units to set for this global SKU in the specified global warehouse. Must be 0 or greater. |
