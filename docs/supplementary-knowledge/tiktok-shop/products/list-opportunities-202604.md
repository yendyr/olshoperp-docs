# List Opportunities

> **Source:** [https://partner.tiktokshop.com/docv2/page/list-opportunities-202604](https://partner.tiktokshop.com/docv2/page/list-opportunities-202604)
> **Category:** Products
> **document_path:** `list-opportunities-202604`

## Description

Search and retrieve a paginated list of opportunity leads available to the authorized seller, with optional filters by type, status, category, etc and ordered by the algorithm ranking model.

## Required scope

seller.product.basic

## Path

`/product/202604/opportunities/query`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| page_size | int | Y | Number of results per page. Max: 100. Default: 20. |
| page_token | string | N | Pagination token from previous response. Omit for first page. |
| locale | string | N | The locale for localized category names, tags, and reward information, expressed as a BCP-47 language-country code, for example `en-US`. If omitted, the primary locale for the seller's shop region is used. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| opportunity_type | string | Y | The type of opportunity.<br>Possible values:<br>- `PRODUCT`: Product opportunity<br>- `KEYWORD`: Search keyword opportunity<br>- `CATEGORY`: Category opportunity |
| category_ids | []string | N | Filter by category IDs. Leave empty to return all leads that available to the seller. |
| create_time_ge | int | N | Filter opportunities created at or after this time. Provide a Unix timestamp in seconds (UTC). |
| create_time_lt | int | N | Filter opportunities created before this time. timestamp in seconds |
| tag_codes | []string | N | A list of tag codes used to filter the results. You can provide at most 20 values. Use lowercase tag codes. The `core_product` and `top_product` tag codes are supported only when `opportunity_type` is `PRODUCT`; their availability also depends on the seller and market configuration. |
