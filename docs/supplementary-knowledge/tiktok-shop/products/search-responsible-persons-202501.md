# Search Responsible Persons

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-responsible-persons-202501](https://partner.tiktokshop.com/docv2/page/search-responsible-persons-202501)
> **Category:** Products
> **document_path:** `search-responsible-persons-202501`

## Description

Retrieve a list of responsible persons in the EU languages supported by TikTok Shop based on their ID or keywords.
When creating a product with the [Create Product API](https://partner.tiktokshop.com/docv2/page/6502fc8da57708028b42b18a), pass a returned responsible person's `id` as an element of `responsible_person_ids`.
Target seller: Local sellers operating in EU countries

## Required scope

seller.product.basic

## Path

`/product/202501/compliance/responsible_persons/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| page_size | int | Y | The number of results to be returned per page. <br>Valid range: [1-100] |
| page_token | string | N | An opaque token used to retrieve the next page of a paginated result set. Retrieve this value from the result of the `next_page_token` from a previous response. It is not needed for the first page. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| responsible_person_ids | []string | N | Filter results by these responsible person IDs.<br>Max IDs: The value of `page_size` |
| keyword | string | N | Filter results to show those that contain this keyword.<br>Search scope: name, local_number, email<br>Max length: 200 characters<br><br>**Note**: Provide either the `responsible_person_ids` or `keyword`; if both are provided, `responsible_person_ids` will take priority. |
| locales | []string | N | The BCP-47 locale codes for displaying the responsible person information.<br>Default: The locale of the seller's registered business address.<br>Possible values:<br>- de-DE<br>- en-IE<br>- es-ES<br>- fr-FR<br>- it-IT |
