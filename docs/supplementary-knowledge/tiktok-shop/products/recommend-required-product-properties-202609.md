# Recommend Required Product Properties

> **Source:** [https://partner.tiktokshop.com/docv2/page/recommend-required-product-properties-202609](https://partner.tiktokshop.com/docv2/page/recommend-required-product-properties-202609)
> **Category:** Products
> **document_path:** `recommend-required-product-properties-202609`

## Description

Predicts the required product properties and their recommended values from the product category and content. The result is generated synchronously for one product and can be used to prepare a create or edit product request.

Do not include personal data, such as names, phone numbers, email addresses, or postal addresses, in the product title, description, or images. The response does not return the submitted product content.

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| category_id | string | Y | The ID of the leaf category selected for the product. |
| description | string | N | Product description used to improve prediction accuracy. Do not include personal data. |
| images | []object | N | Ordered product images used to improve prediction accuracy. Do not include images containing personal data. |
| ^uri | string | Y | URI of a product image previously uploaded to TikTok Shop. |
| product_title | string | Y | Product title used to predict required properties. Do not include personal data. |
| sales_properties | []object | N | Existing standard sales properties that define the product variants and provide additional prediction context. |
| ^id | string | Y | ID of the sales property. |
| ^values | []object | Y | Existing values selected for the sales property. |
| ^^id | string | Y | ID of the sales property value. |
| target_property_ids | []string | N | Optional property IDs that limit prediction to specific properties. When omitted, no property ID filter is applied. |
