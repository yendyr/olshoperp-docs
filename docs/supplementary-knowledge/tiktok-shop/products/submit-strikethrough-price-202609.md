# Submit Strikethrough Price

> **Source:** [https://partner.tiktokshop.com/docv2/page/submit-strikethrough-price-202609](https://partner.tiktokshop.com/docv2/page/submit-strikethrough-price-202609)
> **Category:** Products
> **document_path:** `submit-strikethrough-price-202609`

## Description

Submit external pricing information for a product's SKUs so that TikTok Shop can verify the product's list price for use as a strikethrough price. If the submitted information is approved, the verified list price may be displayed as the strikethrough price when a discount applies.

Submitted pricing information expires 90 days after submission and must be resubmitted to continue supporting strikethrough price display.

## Required scope

_(none listed)_

## Path

`/product/202609/products/{product_id}/strikethrough_price/submit`

## Method

`POST`

## Request Header

| --- | --- | --- | --- |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
| Content-Type | string | Y | Allowed type: application/json |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders. |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| external_product_id | string | Y | An external product identifier used on an external ecommerce platform. This value must match the `external_product_id` used when the product was created. |
| skus | []object | Y | A list of SKUs whose external pricing information is submitted for verification. All SKU IDs must belong to the product identified by `product_id`. |
| ^external_retail_price | object | Y | The SKU retail price on the external ecommerce platform. |
| ^^amount | string | Y | The retail price amount. The valid range is 0.01 to 7600. |
| ^^currency | string | Y | The ISO 4217 currency code. The supported value is `USD`. |
| ^external_sku_id | string | Y | An external SKU identifier used on an external ecommerce platform. This value must match the `external_sku_id` used when the SKU was created. |
| ^external_transaction_price | object | Y | The highest actual transaction price recorded for the SKU on the external ecommerce platform during the past 90 days. |
| ^^amount | string | Y | The transaction price amount. The valid range is 0.01 to 7600, and the value must be equal to or greater than the list price specified when the product was created or edited. |
| ^^currency | string | Y | The ISO 4217 currency code. The supported value is `USD`. |
| ^^image | object | N | A reference to a previously uploaded image resource that proves the highest transaction price, such as an order or invoice screenshot. Mask all customer information before uploading the image. |
| ^^^uri | string | Y | The image URI returned by the Upload Product Image API when the image is uploaded with the `CERTIFICATION_IMAGE` use case. |
| ^^transaction_time | string | Y | The RFC 3339 time when the highest transaction price was recorded. The time must include a timezone and be within the 90 days before the request. |
| ^id | string | Y | The SKU ID generated by TikTok Shop. |
