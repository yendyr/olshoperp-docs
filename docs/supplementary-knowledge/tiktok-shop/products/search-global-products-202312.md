# Search Global Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-global-products-202312](https://partner.tiktokshop.com/docv2/page/search-global-products-202312)
> **Category:** Products
> **document_path:** `search-global-products-202312`

## Description

Retrieve a list of global products that meet the specified conditions. Results are sorted by creation time in descending order. This API returns only key product properties. To obtain more details, pass a returned global product ID to the [Get Global Product API](https://partner.tiktokshop.com/docv2/page/6509e2b0bace3e02b7490c96).

## Required scope

seller.global_product.info

## Path

`/product/202312/global_products/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |

| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. ## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| status | string | N | Filter global products by their status.<br>Possible values:<br>- PUBLISHED<br>- UNPUBLISHED<br>- DRAFT<br>- DELETED |
| seller_skus | []string | N | A Seller SKU used to filter global products. Provide no more than one Seller SKU. The API returns global products that include the specified Seller SKU. |
| create_time_ge | int | N | Filter global products to show only those that are created on or after the specified date and time. Unix timestamp in seconds.<br><br>**Note**:<br>The "create_time_ge" and "create_time_le" together constitute the creation time filter condition.<br>- If "create_time_ge" is filled but "create_time_le" is empty, "create_time_le" will default to the current time.<br>- If "create_time_le" is filled but "create_time_ge" is empty, "create_time_ge" will default to the earliest shop time. |
| create_time_le | int | N | Filter global products to show only those that are created on or before the specified date and time. Unix timestamp in seconds.<br>Refer to notes in "create_time_ge" for more usage information. |
| update_time_ge | int | N | Filter global products to show only those that are updated on or after the specified date and time. Unix timestamp in seconds.<br><br>**Note**:<br>The fields "update_time_ge" and "update_time_le" together define the update time filter condition.<br>- If "update_time_ge" is filled but "update_time_le" is empty, "update_time_le" will default to the current time.<br>- If "update_time_le" is filled but "update_time_ge" is empty, "update_time_ge" will default to the earliest shop time. |
| update_time_le | int | N | Filter global products to show only those that are updated on or before the specified date and time. Unix timestamp in seconds.<br>Refer to notes in `update_time_ge` for more usage information. |
