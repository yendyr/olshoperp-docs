# Predict Product Package Dimensions and Weight

> **Source:** [https://partner.tiktokshop.com/docv2/page/predict-product-package-dimensions-and-weight-202609](https://partner.tiktokshop.com/docv2/page/predict-product-package-dimensions-and-weight-202609)
> **Category:** Products
> **document_path:** `predict-product-package-dimensions-and-weight-202609`

## Description

Predicts the package dimensions and weight for one candidate product based on its leaf category. The result is generated synchronously and can be used to prepare the package information in a create or edit product request. When no prediction is available, `data` is an empty object.
