# Create Manufacturer

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-manufacturer-202409](https://partner.tiktokshop.com/docv2/page/create-manufacturer-202409)
> **Category:** Products
> **document_path:** `create-manufacturer-202409`

## Description

Add a manufacturer for a seller. The provided information will be automatically translated into all EU languages supported by TikTok Shop.
- Use the [Search Manufacturers API](67066a580dcee902fa03ccf9) to obtain the translations.
- Use the [Partial Edit Manufacturer API](67066a55c55b3a03044eea29) to edit the translations, if necessary.
- When creating a product, pass the returned `manufacturer_id` to associate the product with the manufacturer.
Target seller: Local sellers operating in EU countries

## Required scope

seller.product.basic

## Path

`/product/202409/compliance/manufacturers`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| name | string | Y | The manufacturer name. Chinese characters are not supported.<br>Max length: 255 characters |
| registered_trade_name | string | N | The registered trade name of the manufacturer. Chinese characters are not supported.<br>Max length: 200 characters |
| email | string | Y | The manufacturer's email address. Use a valid email format such as `name@example.com`. Chinese characters are not supported. |
| phone_number | object | Y | The phone number of the manufacturer. |
| ^availability | string | N | Indicates the availability of the phone number.<br>Possible values:<br>- `AVAILABLE`: The phone number is available and required.<br>- `UNAVAILABLE`: No phone number is available.<br><br>Default: AVAILABLE |
| ^country_code | string | N | The country code of the phone number, prefixed by a plus `+` symbol. E.g. +353 for Ireland.<br>Max digits: 4<br>Required if `availability=AVAILABLE`. |
| ^local_number | string | N | The local number.<br>Length: 7 - 20 digits<br>Required if `availability=AVAILABLE`. |
| address | string | Y | The postal address of the manufacturer. Chinese characters are not supported.<br>Max length: 500 characters |
| locale | string | N | The BCP-47 locale code representing the language used for specifying the manufacturer information.<br>Possible values:<br>- de-DE<br>- en-IE<br>- es-ES<br>- fr-FR<br>- it-IT<br>Default: The locale of the seller's registered business address.<br><br>**Note**: The information provided will be automatically translated into all EU languages supported by TikTok Shop. Ensure the locale matches the language used in field values to avoid inaccurate translations. |
