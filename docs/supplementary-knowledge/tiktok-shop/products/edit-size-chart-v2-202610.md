# Edit Size Chart V2

> **Source:** [https://partner.tiktokshop.com/docv2/page/edit-size-chart-v2-202610](https://partner.tiktokshop.com/docv2/page/edit-size-chart-v2-202610)
> **Category:** Products
> **document_path:** `edit-size-chart-v2-202610`

## Description

Edit an existing seller-owned size chart by replacing its structured table and editable metadata. Omit `template_name` to keep the current template name. The request must identify one authorized shop using shop_cipher.

## Required scope

_(none listed)_

## Path

`/product/202610/size_charts/edit`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
| Content-Type | string | Y | Allowed type: application/json |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders. |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | The cipher identifying the authorized shop for this request. Obtain it from Get Authorized Shops and use the value for the shop whose size chart is being created or edited. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| size_chart_data | object | Y | Complete replacement size-chart data, including the structured table, measurement type, unit system, and optional descriptive metadata. |
| ^description | string | N | Size chart description. |
| ^is_one_size | bool | N | Whether this is a one-size chart. |
| ^measurement_type | string | Y | Possible values: GENERIC_MEASUREMENTS: generic measurements; BODY_MEASUREMENTS: shopper body measurements; PRODUCT_MEASUREMENTS: finished-product measurements. |
| ^size_types | []string | N | Possible values:<br>- `size_chart_common_size_type`: Common<br>- `size_chart_size_type_regular`: Regular<br>- `size_chart_size_type_juniors`: Juniors<br>- `size_chart_size_type_plus`: Plus<br>- `size_chart_size_type_big&tall`: Big & Tall<br>- `size_chart_size_type_petite`: Petite<br>Available values depend on the category. Values outside this list are not supported. |
| ^table | object | Y | Structured table containing 1–20 column definitions and 1–45 data rows. Each row must contain exactly one cell for every header, in the same order. |
| ^^headers | []object | Y | Column definitions. |
| ^^^id | string | N | Standard size-system ID or measurement key returned by Get Category Rules; omit for custom columns. |
| ^^^name | string | Y | User-visible header name, with a maximum length of 32 characters. It may be seller-defined, for example `Bust (cm)`. |
| ^^rows | []object | Y | Named data rows. |
| ^^^cells | []object | Y | Cells aligned by index with table.headers. |
| ^^^^value | string | Y | Default displayed cell value. Maximum length: 32 characters. |
| ^unit_system | string | Y | Possible values: METRIC: metric units; IMPERIAL: imperial units. |
| size_chart_id | string | Y | The ID of the seller-owned reusable size chart template to update. |
| template_name | string | N | The new name of the size chart template. If omitted, the current name remains unchanged. |
