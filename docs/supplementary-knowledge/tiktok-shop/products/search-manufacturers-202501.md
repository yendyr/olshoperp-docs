# Search Manufacturers

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-manufacturers-202501](https://partner.tiktokshop.com/docv2/page/search-manufacturers-202501)
> **Category:** Products
> **document_path:** `search-manufacturers-202501`

## Description

Retrieve a list of manufacturers in the EU languages supported by TikTok Shop based on their IDs or keyword.
When creating a product with the [Create Product API](https://partner.tiktokshop.com/docv2/page/6502fc8da57708028b42b18a), pass a returned manufacturer's `id` as an element of `manufacturer_ids`.
Target seller: Local sellers operating in EU countries

## Required scope

seller.product.basic

## Path

`/product/202501/compliance/manufacturers/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| manufacturer_ids | []string | N | Filter results by these manufacturer IDs.<br>Max IDs: The value of `page_size` |
| keyword | string | N | Filter results to show those that contain this keyword.<br>Search scope: name, registered trade name, local_number, email<br>Max length: 200 characters<br><br>**Note**: Provide either the `manufacturer_ids` or `keyword`; if both are provided, `manufacturer_ids` will take priority. |
| locales | []string | N | The BCP-47 locale codes for displaying the manufacturer information.<br>Default: The locale of the seller's registered business address.<br>Possible values:<br>- de-DE<br>- en-IE<br>- es-ES<br>- fr-FR<br>- it-IT |
