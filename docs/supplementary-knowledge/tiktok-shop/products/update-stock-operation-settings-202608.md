# Update Stock Operation Settings

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-stock-operation-settings-202608](https://partner.tiktokshop.com/docv2/page/update-stock-operation-settings-202608)
> **Category:** Products
> **document_path:** `update-stock-operation-settings-202608`

## Description

Configure auto-restock behavior for 1 to 500 SKUs in one request. For seller-fulfilled orders, this setting controls whether inventory reserved for a canceled order is returned to the SKU's available inventory.

## Required scope

seller.product.basic

## Path

`/product/202608/inventory/operation/settings`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| seller_id | string | Y | Identifies the seller whose settings are being modified. |
| sku_ids | []string | N | List of specific SKU IDs. Up to 500 SKUs in a batch.  |
| stock_operation_setting | object | N | The canceled-order auto-restock configuration to apply to the specified SKUs. |
| ^enable_auto_restock | bool | N | Controls automatic inventory replenishment after a seller-fulfilled (FBM) order is canceled. When at least one SKU is supplied, omitting `stock_operation_setting` or `enable_auto_restock` uses `false`.<br>- `true`: Enable automatic replenishment for the specified SKUs.<br>- `false`: Disable automatic replenishment for the specified SKUs. |
