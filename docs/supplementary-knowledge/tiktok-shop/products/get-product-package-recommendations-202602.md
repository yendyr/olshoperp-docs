# Get Product Package Recommendations

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-product-package-recommendations-202602](https://partner.tiktokshop.com/docv2/page/get-product-package-recommendations-202602)
> **Category:** Products
> **document_path:** `get-product-package-recommendations-202602`

## Description

Retrieve recommended weight and dimension ranges for product packages. Only available in BR and MX.

## Required scope

seller.product.basic

## Path

`/product/202602/packages/recommend`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
