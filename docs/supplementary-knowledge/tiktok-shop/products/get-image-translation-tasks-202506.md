# Get Image Translation Tasks

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-image-translation-tasks-202506](https://partner.tiktokshop.com/docv2/page/get-image-translation-tasks-202506)
> **Category:** Products
> **document_path:** `get-image-translation-tasks-202506`

## Description

Retrieves the image translation task status and translated images for one or more previously submitted images.
**Note**: Please wait 5 minutes after [task creation](684f8b2d6e0b37048b2448b4) before calling this API, and retry at intervals over 10 seconds to avoid rate limiting.
Applicable only for sellers that sell across EU.

## Required scope

serller.product.optimize

## Path

`/product/202506/images/translation_tasks`

## Method
