# Inventory Search

> **Source:** [https://partner.tiktokshop.com/docv2/page/inventory-search-202309](https://partner.tiktokshop.com/docv2/page/inventory-search-202309)
> **Category:** Products
> **document_path:** `inventory-search-202309`

## Description

Retrieve inventory information for multiple products or SKUs.
**Note**:
- If both `sku_ids` and `product_ids` are passed, `sku_ids` takes precedence and `product_ids` is ignored.
- Passing product IDs returns the inventory information of all SKUs under the specified products.
- Passing SKU IDs returns the inventory information for the specified SKUs.

## Required scope

seller.product.basic

## Path

`/product/202309/inventory/search`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| product_ids | []string | N | A list of product IDs used to search for inventory information.<br>Max IDs: 100 |
| sku_ids | []string | N | A list of SKU IDs used to search for inventory information.<br>Max IDs: 600<br><br>**Note**: If both `sku_ids` and `product_ids` are passed, `sku_ids` will take precedence. |
