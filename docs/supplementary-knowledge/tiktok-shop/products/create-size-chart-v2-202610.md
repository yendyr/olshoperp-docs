# Create Size Chart V2

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-size-chart-v2-202610](https://partner.tiktokshop.com/docv2/page/create-size-chart-v2-202610)
> **Category:** Products
> **document_path:** `create-size-chart-v2-202610`

## Description

Create one size chart from structured table data. Use `REUSABLE_TEMPLATE` to create a seller template that can be reused across products, or `PRODUCT_SCOPED` to create a chart for a single product. The response returns the created size chart ID. The request must identify one authorized shop using shop_cipher.

## Required scope

_(none listed)_

## Path

`/product/202610/size_charts`

## Method

`POST`

## Query Header

| Properties | Type | Required | Properties description |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| category_id | string | Y | The leaf category for which to create the size chart. The category must support size charts. |
| size_chart_data | object | Y | Structured size chart content. |
| ^description | string | N | Additional size chart description. |
| ^is_one_size | bool | N | Whether this is a one-size chart. |
| ^measurement_type | string | Y | Possible values: GENERIC_MEASUREMENTS: generic measurements; BODY_MEASUREMENTS: shopper body measurements; PRODUCT_MEASUREMENTS: finished-product measurements. |
| ^size_types | []string | N | Possible values: size_chart_common_size_type: Common; size_chart_size_type_regular: Regular; size_chart_size_type_juniors: Juniors; size_chart_size_type_plus: Plus; size_chart_size_type_big&tall: Big & Tall; size_chart_size_type_petite: Petite. Available values depend on the category. |
| ^table | object | Y | Table containing headers and rows. |
| ^^headers | []object | Y | Ordered header definitions. Provide 1 to 20 headers. |
| ^^^id | string | N | Standard size-system or measurement ID.<br>For standard measurement columns, call Get Category Rules for the corresponding category and use the ID from measurement_and_options[].options[].id under the applicable measurement_type.<br>For size-system columns, use the following predefined IDs:<br>- Size: size_chart_size_system_size<br>- US: size_chart_size_system_us<br>- UK: size_chart_size_system_uk<br>- EU: size_chart_size_system_eu<br>- JP: size_chart_size_system_jp<br>- MX: size_chart_size_system_mx<br>Omit this field for custom columns. |
| ^^^name | string | Y | Header display name. Maximum length: 32 characters. |
| ^^rows | []object | Y | Rows of the size chart. Provide 1 to 45 rows. |
| ^^^cells | []object | Y | Cells aligned by index with `table.headers`. Each row must contain exactly one cell for every header. |
| ^^^^value | string | Y | Cell value. Maximum length: 32 characters. |
| ^unit_system | string | Y | Possible values: METRIC: metric units; IMPERIAL: imperial units. |
| size_chart_mode | string | Y | Possible values:<br>REUSABLE_TEMPLATE: A size chart template that can be reused across multiple products.<br>PRODUCT_SCOPED: A size chart created for and used by a single product. |
| template_name | string | N | Template name. Required when size_chart_mode is REUSABLE_TEMPLATE.<br>When size_chart_mode is PRODUCT_SCOPED, any value provided for this field is discarded and is not stored. |
