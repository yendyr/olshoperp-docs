# Update Inventory

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-inventory-202309](https://partner.tiktokshop.com/docv2/page/update-inventory-202309)
> **Category:** Products
> **document_path:** `update-inventory-202309`

## Description

Update the inventory quantity of SKUs belonging to a product. The product must be in `DRAFT`, `PENDING`, `FAILED`, `ACTIVATE`, or `SELLER_DEACTIVATED` status.

## Required scope

seller.product.write

## Path

`/product/202309/products/{product_id}/inventory/update`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| skus | []object | Y | A list of Stock Keeping Units (SKUs) used to identify distinct variants of the product. |
| ^id | string | Y | The SKU ID generated by TikTok Shop. One product can contain multiple SKU IDs.<br><br>**Note**: <br>- The SKU ID must belong to a product that is not in `FREEZE` or `DELETED` status.<br>- If you are updating multiple SKUs, all the SKU IDs must belong to the same product. |
| ^inventory | []object | Y | SKU inventory information.<br>**Note**: You must include all warehouse IDs assigned to this SKU, along with the respective quantity. Do not omit any or add unrelated warehouses. |
| ^^warehouse_id | string | N | The ID of the warehouse where the SKU is stored. Retrieve this value from the [Get Product API](https://partner.tiktokshop.com/docv2/page/6509d85b4a0bb702c057fdda).<br><br>**Note**: Optional if there is only 1 warehouse. Otherwise, please provide this ID. |
| ^^quantity | int | Y | The total SKU quantity available in the warehouse.<br>Valid range: [1, 99,999]<br><br>Note: This quantity specifically refers to the in-stock inventory that can be shipped immediately. |
| ^^backorder_quantity | int | N | The `backorder_quantity` is automatically converted to `quantity` when in-stock inventory is sold out. Its fulfillment follows the specified `handling_time`.<br><br>**Note**:<br>- Provide `backorder_quantity` and `handling_time` together.<br>- If `backorder_quantity` is omitted, the existing backorder quantity remains unchanged. |
| ^^handling_time | int | N | The estimated number of working days needed for a backorder to be shipped. Provide `handling_time` and `backorder_quantity` together. All warehouses for the same SKU must use the same `handling_time`. |
