# Search Size Charts

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-size-charts-202407](https://partner.tiktokshop.com/docv2/page/search-size-charts-202407)
> **Category:** Products
> **document_path:** `search-size-charts-202407`

## Description

Retrieve size charts that a seller has created.

## Required scope

seller.product.basic

## Path

`/product/202407/sizecharts/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| page_size | int | Y | The number of results to be returned per page. <br>Valid range: [1-100] |
| page_token | string | N | An opaque token used to retrieve the next page of a paginated result set. Retrieve this value from the result of the `next_page_token` from a previous response. It is not needed for the first page. |
| locales | []string | N | The BCP-47 locale codes for displaying the size charts.<br>Default: The default locale of your shop.<br>Possible values:<br>- de-DE<br>- en-GB<br>- en-IE<br>- en-US<br>- es-ES<br>- es-MX<br>- fr-FR<br>- id-ID<br>- it-IT<br>- ja-JP<br>- ms-MY<br>- pt-BR<br>- th-TH<br>- vi-VN<br>- zh-CN |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| ids | []string | N | Filter size charts by size chart template IDs. <br>Max: 50 IDs |
| keyword | string | N | Filter size charts by size chart template name or by key words in the template name.<br>Keyword searches do not return PRODUCT_SCOPED size charts because they do not have a template name.<br>If both ids and keyword are provided, ids takes priority.<br> |
| size_chart_mode | string | N | Filter size charts by usage mode. Possible values: REUSABLE_TEMPLATE: A size chart template that can be reused across multiple products. PRODUCT_SCOPED: A size chart created for and used by a single product. If omitted, the existing search behavior is preserved. |
