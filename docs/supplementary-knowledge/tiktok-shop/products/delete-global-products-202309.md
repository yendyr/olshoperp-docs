# Delete Global Products

> **Source:** [https://partner.tiktokshop.com/docv2/page/delete-global-products-202309](https://partner.tiktokshop.com/docv2/page/delete-global-products-202309)
> **Category:** Products
> **document_path:** `delete-global-products-202309`

## Description

Delete global products that you no longer need.

## Required scope

seller.global_product.delete

## Path

`/product/202309/global_products`

## Method

`DELETE`
