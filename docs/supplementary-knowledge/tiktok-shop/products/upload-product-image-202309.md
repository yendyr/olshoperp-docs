# Upload Product Image

> **Source:** [https://partner.tiktokshop.com/docv2/page/upload-product-image-202309](https://partner.tiktokshop.com/docv2/page/upload-product-image-202309)
> **Category:** Products
> **document_path:** `upload-product-image-202309`

## Description

Upload a local image to TikTok Shop for use as a product image, variant image, size chart, certification image, or another supported image use case.

**Note**:
- All images used in TikTok Shop products must be uploaded through this API. You cannot use image URLs that are not hosted by TikTok Shop.
- Store `data.uri` to associate the uploaded image with a product when creating or editing it. Store `data.url` when you need to display the image in a product description by using an HTML `<img>` tag.

## Required scope

seller.product.basic

## Path

`/product/202309/images/upload`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| data | file | Y | The local image file to be uploaded.<br><br>**Note**:<br>- Supported formats: JPG, JPEG, PNG, WEBP, HEIC, BMP<br>- Zero-byte files are rejected.<br>- Max size: 10MB<br>- Dimensions: [100x100 px, 20000x20000 px]<br>- For `use_case=MAIN_IMAGE`, the dimensions must be between 300x300 px and 4000x4000 px.<br>- For `use_case=SIZE_CHART_IMAGE`, the dimension must be at least 1024 px on the shorter side. |
| use_case | string | N | The usage scenario of the image.<br>Possible values:<br>- MAIN_IMAGE: An image displayed in the product image gallery.<br>- ATTRIBUTE_IMAGE: An image that represents a product variant (e.g. color).<br>- DESCRIPTION_IMAGE: An image used within the product description.<br>- CERTIFICATION_IMAGE: An image to provide supporting information to meet TikTok Shop requirements for listing restricted products (e.g., images of certifications, product packaging, labeling).<br>- SIZE_CHART_IMAGE: An image that displays the product's measurement details.<br>- CUSTOMIZATION_IMAGE: Images used for POD product customization, such as background images, mask images, or default images configured for customizable areas. These images are used to render or preview consumer-customizable product content.<br><br>**Note**: Images for use cases `MAIN_IMAGE` and `ATTRIBUTE_IMAGE` that do not fit within the 3:4 to 4:3 aspect ratio range will be automatically converted to 1:1. |
