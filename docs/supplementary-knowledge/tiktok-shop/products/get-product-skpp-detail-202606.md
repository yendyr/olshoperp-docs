# Get Product SKPP Detail

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-product-skpp-detail-202606](https://partner.tiktokshop.com/docv2/page/get-product-skpp-detail-202606)
> **Category:** Products
> **document_path:** `get-product-skpp-detail-202606`

## Description

Return the SKPP qualification status, current and target scores, task progress and suggested actions, reward eligibility and status, and offline snapshot time for one product. This API is available only to sellers authorized for SKPP in the US market.

## Required scope

seller.product.basic

## Path

`/product/202606/skpps/{product_id}`

## Method

`GET`
