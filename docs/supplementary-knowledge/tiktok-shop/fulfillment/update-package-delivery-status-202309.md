# Update Package Delivery Status

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-package-delivery-status-202309](https://partner.tiktokshop.com/docv2/page/update-package-delivery-status-202309)
> **Category:** Fulfillment
> **document_path:** `update-package-delivery-status-202309`

## Description

Use this API to report delivery outcomes for SOF (Seller Own Fleet) packages or confirm O2O (Store Pickup) package delivery. For SOF, use `DELIVERY_SUCCESS`, `DELIVERY_FAILED`, or `UPDATE_POD`. For O2O, use `DELIVERY_SUCCESS` and provide the pickup verification code. Only sellers using SOF or O2O can use this API. This API is available only in the SEA region.

## Required scope

seller.delivery.status.write

## Path

`/fulfillment/202309/packages/deliver`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| packages | []object | Y | The packages to update. Provide at least one package. |
| ^id | string | Y | The package ID. |
| ^delivery_type | string | Y | Delivery status of the package.<br>Possible values for in-store pick up:<br>- `DELIVERY_SUCCESS`: The package has been successfully delivered. <br>Possible values for SOF (Seller Own Fleet):<br> - `DELIVERY_SUCCESS`: The package has been successfully delivered. <br> - `DELIVERY_FAILED`: The package could not be delivered successfully. <br> - `UPDATE_POD`: Updates the attachment for a package that has already been delivered. |
| ^fail_delivery_reason | string | N | Delivery failure reasons.<br><br>When `delivery_type = DELIVERY_FAILED`, this field is required. For other delivery types, this field is not required.<br><br>Possible values:<br>- `INVALID_ADDRESS`: The buyer shipping address is invalid.<br>- `UNABLE_RECEIVE`: The buyer is currently unable to receive the delivery.<br>- `UNABLE_CONTACT_BUYER`: Unable to contact the buyer.<br>- `BUYER_REFUSED`: The buyer has refused to receive the product.<br>- `DELAY_DELIVERY`: Delay in delivery.<br>- `PACKAGE_LOST`: The package is lost.<br>- `PACKAGE_DAMAGE`: The package is damaged.<br>- `FORCE_MAJEURE`: An unforeseeable event of force majeure has occurred.<br>- `OTHER`: Other reason.<br> |
| ^file_type | string | N | Attachment type:<br>- `IMG`<br>- `PDF` |
| ^file_url | string | N | Attachment URL.<br>The seller can use the [Upload Delivery File](https://partner.tiktokshop.com/docv2/page/650aa6e04a0bb702c06dcd34?external_id=650aa6e04a0bb702c06dcd34#Back%20To%20Top) and [Upload Delivery Image](https://partner.tiktokshop.com/docv2/page/650aa70d0fcef602bf32772f?external_id=650aa70d0fcef602bf32772f) APIs to generate the URL. The attachment will be used by TikTok Shop to verify the package delivery. |
| ^verification_code | string | N | The verification code required for order pickup. |
