# Get Order Customs Requirements

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-order-customs-requirements-202607](https://partner.tiktokshop.com/docv2/page/get-order-customs-requirements-202607)
> **Category:** Fulfillment
> **document_path:** `get-order-customs-requirements-202607`

## Description

This API is used to query whether an order requires extra customs clearance information, whether such information has been submitted, and the list of submitted customs clearance information.
If extra customs clearance information is required but not yet provided, the merchant must complete and submit it before shipment can proceed.

## Required scope

seller.fulfillment.basic

## Path

`/fulfillment/202607/orders/customs_info/query`

## Method

`POST`

| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. ## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| order_ids | []string | Y | TikTok Shop order IDs to query. When providing a request body, include 1 to 50 order IDs. |
