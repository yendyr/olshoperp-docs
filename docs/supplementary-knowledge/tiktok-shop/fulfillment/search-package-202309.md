# Search Package

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-package-202309](https://partner.tiktokshop.com/docv2/page/search-package-202309)
> **Category:** Fulfillment
> **document_path:** `search-package-202309`

## Description

Retrieve packages, optionally filtered by creation time, update time, or package status.

## Required scope

seller.fulfillment.basic

## Path

`/fulfillment/202309/packages/search`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

| page_token | string | N | An opaque token used to retrieve the next page of a paginated result set. Retrieve this value from the result of the `next_page_token` from a previous response. It is not needed for the first page. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| create_time_ge | int | N | Filter packages to those created at or after the specified time. Unix timestamp, in seconds. |
| create_time_lt | int | N | Filter packages to those created before the specified time. Unix timestamp, in seconds. |
| update_time_ge | int | N | Filter packages to those updated at or after the specified time. Unix timestamp, in seconds. |
| update_time_lt | int | N | Filter packages to those updated before the specified time. Unix timestamp, in seconds. |
| package_status | string | N | Possible values:<br>- `TO_FULFILL`<br>- `PROCESSING`: Package has been arranged by seller. Waiting for carrier to collect the parcel.<br>- `FULFILLING`: Package has been collected by carrier and in transit.<br>- `COMPLETED`: Package has been delivered.<br>- `CANCELLED`: Package has been canceled. Normally, the package is canceled due to the package being lost or damaged. |
