# Update Package Shipping Info

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-package-shipping-info-202610](https://partner.tiktokshop.com/docv2/page/update-package-shipping-info-202610)
> **Category:** Fulfillment
> **document_path:** `update-package-shipping-info-202610`

## Description

If the seller entered an incorrect tracking number, this API allows the seller to update the tracking number and shipping provider for a package that has already been shipped. Attention: This API is only applicable to orders (or packages) shipped by the seller.  It is only used to update the tracking number and shipping provider for packages that have already been shipped.

## Required scope

seller.fulfillment.basic, seller.fs.order&fufillment.management

## Path

`/fulfillment/202610/packages/{package_id}/shipping_info/update`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| shipping_info_list | []object | Y | "Only supports uploading multiple tracking numbers for split-shipment in 3PL single item scenarios (non-virtual bundle) (This function is only support for whitelist sellers； If you are not on the allowlist, it is recommended to contact AM to apply)<br>For other scenarios, only one tracking number can be uploaded at a time." |
| ^tracking_number | string | N | Tracking number.​ |
| ^shipping_provider_id | string | N | Use Get Shipping Provider API to retrieve the shipping_provider_id for shipping providers.​ |
| ^note | string | N | "Only available for a part of white list merchants.This applies to scenarios where a large single item needs to be shipped in multiple packages.Merchants not on the whitelist who upload this field will have it automatically ignored by the platform.<br>For example, where Package 1 is marked with ""headboard"" and Package 2 is marked with ""bed frame"".<br>This field will be displayed to buyers, so please fill it in carefully." |
