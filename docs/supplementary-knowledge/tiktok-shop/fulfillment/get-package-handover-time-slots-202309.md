# Get Package Handover Time Slots

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-package-handover-time-slots-202309](https://partner.tiktokshop.com/docv2/page/get-package-handover-time-slots-202309)
> **Category:** Fulfillment
> **document_path:** `get-package-handover-time-slots-202309`

## Description

Use this API to retrieve a specified package's door-to-door pickup time slots and handover availability for pickup, drop-off, and, in the UK, van collection. When available, the response also provides a URL for finding drop-off locations.

## Required scope

seller.fulfillment.package.write

## Path

`/fulfillment/202309/packages/{package_id}/handover_time_slots`

## Method

`GET`
