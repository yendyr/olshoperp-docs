# Create Packages

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-packages-202512](https://partner.tiktokshop.com/docv2/page/create-packages-202512)
> **Category:** Fulfillment
> **document_path:** `create-packages-202512`

## Description

Use this API to ship orders (purchase labels). This API is available in the US, UK, EMEA, and JP regions. The shipping fee and delivery time is an estimate only and is based on the package dimensions and weight you provided.

## Required scope

seller.fulfillment.basic, seller.fs.order&fufillment.management

## Path

`/fulfillment/202512/packages`

## Method

`POST`

## Request Header

Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| ship_type | string | Y |   1:All the products in one order are shipped in one package with one tracking number<br>  2:Partical products in one parent order are shipped in multiple packages with multiple tracking numbers<br>  3:All the products in multiple orders are shipped in one package with one tracking number. |
| order_id | string | N | The TikTok Shop order ID. Required when `ship_type` is `1` or `2`; not used when `ship_type` is `3`. |
| warehouse_id | string | N | Only use for US local-to-local orders.<br>If you need to modify the shipping warehouse, you can edit warehouse ID; The address associated with this ID will be used to generate shipping labels, and it has no impact on inventory.<br>Note: We only support warehouse IDs in the enabled status. Passing in repository IDs with other statuses will result in shipment failure. |
| order_line_item | []object | N | List of order line item IDs.<br>If ship_type=2,This is a required field;If ship_type=1&3,we will not use this field |
| ^order_line_id | string | N | The TikTok Shop order line item ID. |
| ^sub_item_id | string | N | Only for virtual bundle items,list of sub item ids.<br>If ship_type=2,This is a required field;If ship_type=1&3,we will not use this field |
| order_list_ids | []string | N | The TikTok Shop order IDs to combine into one package. Required when `ship_type` is `3`; provide at least two order IDs. |
| dimension | object | N | Package dimensions. For `ship_type` `1` and `2`, each dimension must be between 0.01 and 999999 and have no more than two decimal places. |
| ^length | string | Y | Package length.<br><br>The length, width, and height must be passed together. |
| ^width | string | Y | Package width.<br><br>The length, width, and height must be passed together. |
| ^height | string | Y | Package height.<br><br>The length, width, and height must be passed together. |
| ^unit | string | Y | The unit of measurement for the package dimensions. For packages in the US, use `INCH`.<br><br>Available values:<br>- `CM`<br>- `INCH` |
| shipping_service_id | string | N | Specify the shipping service used. <br>If not specified, use the default service obtained from [Get Eligible Shipping Service](https://partner.tiktokshop.com/docv2/page/650aa6b2bace3e02b75dda4e). |
| weight | object | N | Package weight. For `ship_type` `1` and `2`, the value must be between 0.01 and 999999 and have no more than two decimal places. |
| ^value | string | Y | The numerical value of the package weight. |
| ^unit | string | Y | The unit of measurement for the package weight.<br><br>Available values:<br>- `GRAM`<br>- `POUND` |
