# Submit Customs Clearance Information

> **Source:** [https://partner.tiktokshop.com/docv2/page/submit-customs-clearance-information-202607](https://partner.tiktokshop.com/docv2/page/submit-customs-clearance-information-202607)
> **Category:** Fulfillment
> **document_path:** `submit-customs-clearance-information-202607`

## Description

This API is used to submit extra customs clearance information for discrepancies between declared information and physical goods.

## Required scope

seller.fulfillment.basic

## Path

`/fulfillment/202607/orders/customs_info/submit`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| order_list | []object | N | List of orders for which to submit customs clearance information. Maximum: 100 orders per request. |
| ^order_id | string | Y | TikTok Shop order ID |
| ^item_list | []object | N | List of customs clearance entries for order lines. Within the same order, explicit order_line_id values must be unique. |
| ^^order_line_id | string | N | Sub order ID; order_line_id and sku_id should not be both empty. |
| ^^sku_id | string | N | SKU ID; order_line_id and sku_id should not be both empty. |
| ^^item_detail | []object | N | List of SKU-level customs clearance details for the order line. |
| ^^^sku_id | string | Y | The SKU ID for this customs clearance detail. |
| ^^^qty | int | Y | Quantity of this SKU in the customs clearance detail. Must be greater than 0. |
| ^^^price_percent | int | Y | Percentage assigned to this SKU within the order line. Each value must be non-negative, and the price_percent values in item_detail must total 100. For example, 10 means 10%. |
