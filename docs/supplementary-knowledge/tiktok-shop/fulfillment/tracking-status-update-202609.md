# Tracking status update

> **Source:** [https://partner.tiktokshop.com/docv2/page/tracking-status-update-202609](https://partner.tiktokshop.com/docv2/page/tracking-status-update-202609)
> **Category:** Fulfillment
> **document_path:** `tracking-status-update-202609`

## Description

**This API is currently exclusive to the following markets: US, BR.**
This API is suitable for merchants to deliver and carry orders by themselves, without shipping orders through third-party service providers, that is, without shipping packages through 3PL, but orders sent by merchants. Merchants are allowed to use this API to return such orders and update the order track. The Action Code and Failed Reason in the input parameter are enumerated, as detailed in the document: https://partner.tiktokshop.com/docv2/page/1cjht3qx

## Required scope

seller.fulfillment.basic

## Path

`/fulfillment/202609/order/sof/track/update`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| country | string | Y | Order Country. |
| order_id | string | Y | TikTok Shop order ID. |
| external_tracking_url | string | N | Service provider's track URL / official website link. |
| tracks | []object | Y | Trajectory node array; maximum number of entries per single request [50], processing results are returned one by one within the array. That is, in the interface, a maximum of 50 tracks can be postbacked per order at a time. |
| ^action_code | int | Y | The standard trajectory node code must belong to the allowlist. See the below action code. The action code is limited, for the list of available enumerations, please refer to the documentation: https://partner.tiktokshop.com/docv2/page/1cjht3qx |
| ^occur_time | int | Y | Actual Trajectory Occurrence Time. Unix timestamp GMT (UTC+00:00). The unit is milliseconds. |
| ^description | string | Y | The original trajectory description of the caller. |
| ^failed_reason | string | N | Exception causes, details are listed below. See the below reason code. The reason code is limited, for the list of available enumerations, please refer to the documentation: https://partner.tiktokshop.com/docv2/page/1cjht3qx |
| ^proof_url | string | N | Third-party tracking proof links or credentials. |
| ^location | object | N | Location fields such as city, state, province, country, latitude and longitude; |
| ^^country | string | N | country. |
| ^^state | string | N | state. |
| ^^city | string | N | city. |
| ^^zip_code | string | N | zip code/post code. |
| ^tracking_no | string | Y | The waybill number used when placing an order. If there is no tracking code, fill in the invoice id instead. And it may change in split shipment, it may change in different track in this scene.  |
| provider_id | string | Y | The logistics provider ID, which is the one filled in when placing an order or uploading a tracking number, must be consistent with it. |
