# Get Order Split Attributes

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-order-split-attributes-202309](https://partner.tiktokshop.com/docv2/page/get-order-split-attributes-202309)
> **Category:** Fulfillment
> **document_path:** `get-order-split-attributes-202309`

## Description

Checks whether one or more TikTok Shop orders can be split into multiple packages. For each evaluated order, the response indicates whether it can be split and may include a reason when splitting is not allowed and mandatory package-splitting limits when applicable.

## Required scope

seller.fulfillment.package.write, seller.fs.order&fufillment.management

## Path

`/fulfillment/202309/orders/split_attributes`

## Method

`GET`
