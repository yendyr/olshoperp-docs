# Confirm Inbound Method

> **Source:** [https://partner.tiktokshop.com/docv2/page/confirm-inbound-method-202603](https://partner.tiktokshop.com/docv2/page/confirm-inbound-method-202603)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `confirm-inbound-method-202603`

## Description

Confirm a currently available warehouse placement option for an FBT inbound plan. First call the List Available Inbound Methods API and select an `inbound_method` with one exact `estimate_arrival_time` window. Then call the Get Inbound Method Detail API with that selection and choose a returned `placement_option_id`. Confirm using the `placement_option_id`, `inbound_method`, and `estimate_arrival_time` from the same selection. If the option has expired, repeat both prerequisite calls to obtain a current selection and a new `placement_option_id`, then retry. The response contains the child inbound order IDs generated for the plan.

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| plan_id | string | Y | Identifier of the FBT inbound plan whose warehouse placement option is being confirmed. |
| placement_option_id | string | Y | Placement option id. A placement option represents the shipment splits and destinations. |
| inbound_method | string | Y | **Possible values:**<br>* `D2FC` (Direct to fulfillment center, may be split into multiple shipments)<br>* `ONE_HUB` (Single destination, includes fee) |
| estimate_arrival_time | object | Y | Estimated arrival time. Value should be retrieved from the `available_time_window_list` from `ListAvailableInboundMethod` API response |
| ^start_timestamp | string | Y | Start of the estimated arrival time window as a Unix timestamp in seconds. For example, `1774162800` corresponds to Sunday, 2026-03-22 at 00:00 PDT (`2026-03-22T07:00:00Z`). Use the exact `start_timestamp` returned in `available_time_window_list` by the `ListAvailableInboundMethod` API. |
| ^end_timestamp | string | Y | End of the estimated arrival time window as a Unix timestamp in seconds. For example, `1774767600` corresponds to Sunday, 2026-03-29 at 00:00 PDT (`2026-03-29T07:00:00Z`). Use the exact `end_timestamp` returned in `available_time_window_list` by the `ListAvailableInboundMethod` API. |
