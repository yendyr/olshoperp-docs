# List Available Inbound Methods

> **Source:** [https://partner.tiktokshop.com/docv2/page/list-available-inbound-methods-202602](https://partner.tiktokshop.com/docv2/page/list-available-inbound-methods-202602)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `list-available-inbound-methods-202602`

## Description

Retrieves valid inbound shipping methods and arrival time windows for a specific plan. After selecting an `inbound_method` and one complete arrival time window, call **Get Inbound Method Detail** (`POST /fbt/202602/inbound_method_detail`) using the same `plan_id`, the selected `inbound_method`, and that window's exact `start_timestamp` and `end_timestamp` pair as `estimate_arrival_time`.

## Required scope

seller.fbt.info

## Path

`/fbt/202602/list_available_inbound_method`

## Method
