# Get FBT MCF Order Status

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-fbt-mcf-order-status-202601](https://partner.tiktokshop.com/docv2/page/get-fbt-mcf-order-status-202601)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `get-fbt-mcf-order-status-202601`

## Description

Use this API to retrieve an MCF order and the current status and fulfillment details of its consign orders. If the order requires multiple packages because of carrier restrictions or package-size limits, the FBT system splits it for fulfillment and returns one entry in `consign_orders` for each package.

## Required scope

seller.fbt.info

## Path

`/fbt/202601/mcf_outbound_orders`

## Method

`GET`
