# Get Inbound Method Detail

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-inbound-method-detail-202602](https://partner.tiktokshop.com/docv2/page/get-inbound-method-detail-202602)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `get-inbound-method-detail-202602`

## Description

Retrieves placement details for an inbound plan. First call the List Available Inbound Methods API for the plan, then use the `inbound_method` and estimated arrival window from the same returned option. The response reports the placement task status and, when available, placement options with shipment allocations; `ONE_HUB` options can also include an estimated placement fee.

## Required scope

seller.fbt.info

## Path

`/fbt/202602/inbound_method_detail`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| plan_id | string | Y | Inbound plan identifier |
| inbound_method | string | Y | **Possible values:**<br>* `D2FC` (Direct to fulfillment center, may be split into multiple shipments)<br>* `ONE_HUB` (Single destination; can include an estimated placement fee) |
| estimate_arrival_time | object | Y | Estimated arrival window for the selected `inbound_method`. Use the `start_timestamp` and `end_timestamp` from the same entry in the `available_time_window_list` returned by the List Available Inbound Methods API for this plan. |
| ^start_timestamp | string | Y | Unix timestamp in seconds for the start of the estimated arrival window, which is Sunday at 00:00 PDT. For example, `1774162800` corresponds to `2026-03-22T07:00:00Z`.<br><br>**This value must exactly match the `start_timestamp` from the selected List Available Inbound Methods time window.** |
| ^end_timestamp | string | Y | Unix timestamp in seconds for the end of the estimated arrival window, which is Sunday at 00:00 PDT. For example, `1774767600` corresponds to `2026-03-29T07:00:00Z`.<br><br>**This value must exactly match the `end_timestamp` from the selected List Available Inbound Methods time window.** |
