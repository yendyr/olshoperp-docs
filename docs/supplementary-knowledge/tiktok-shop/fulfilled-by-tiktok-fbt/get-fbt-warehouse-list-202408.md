# Get FBT Warehouse List 

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-fbt-warehouse-list-202408](https://partner.tiktokshop.com/docv2/page/get-fbt-warehouse-list-202408)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `get-fbt-warehouse-list-202408`

## Description

This API is used to retrieve all Fulfilled by TikTok warehouse information including the warehouse name, warehouse address information, etc. The IDs of subscribed warehouses can be used to query inventory-related information.

## Required scope

seller.fbt.info

## Path

`/fbt/202408/warehouses`

## Method

`GET`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
