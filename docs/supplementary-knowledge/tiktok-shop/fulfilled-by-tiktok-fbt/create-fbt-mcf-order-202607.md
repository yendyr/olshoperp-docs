# Create FBT MCF Order

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-fbt-mcf-order-202607](https://partner.tiktokshop.com/docv2/page/create-fbt-mcf-order-202607)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `create-fbt-mcf-order-202607`

## Description

For orders created on other sales channels that require fulfillment via FBT, this API enables you to create corresponding orders (hereinafter referred to as MCF Orders). Once MCF Orders are successfully created, they will be automatically submitted to the FBT system for fulfillment.

## Required scope

seller.fbt.info

## Path

`/fbt/202607/mcf_outbound_orders`

## Method

`POST`

## Request Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |

## Query Header

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| app_key | string | Y | Every single app will have a unique key. Please use the specific key assigned to your app. |
| sign | string | Y | Signature generated by gen algorithm. When you send API requests to TTS, you must sign them so that TTS can identify the senders.  |
| timestamp | int | Y | Unix timestamp GMT (UTC+00:00). This timestamp is used across all API requests. Developers can use this convert to local time. |
| shop_cipher | string | Y | Use this property to pass shop information in requesting the API. Failure in passing the correct value when requesting the API for cross-border shops will return incorrect response. <br>Get by API [Get Authorization Shop](https://partner.tiktokshop.com/docv2/page/6507ead7b99d5302be949ba9?external_id=6507ead7b99d5302be949ba9) |

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| external_order_id | string | Y | The corresponding order ID in your OMS. Maximum UTF-8 length: 127 bytes. It must be unique among active MCF orders for the same merchant. Reusing an `external_order_id` from an active order is rejected as a duplicate and is not an idempotent retry. |
| goods | []object | Y | The item IDs and quantities included in the order. The array must contain at least one item, and each item must be managed in the FBT system. The sum of `quantity` across all entries in `goods` must not exceed 50. |
| ^id | string | Y | The goods ID generated by the Fulfilled by TikTok system. The value must be a positive base-10 integer string. |
| ^quantity | int | Y | The quantity of this item. Must be greater than 0. |
| consignee | object | Y | The consignee contact info |
| ^name | string | Y | The consignee name. Must not exceed 128 UTF-8 bytes. |
| ^phone_number | string | Y | The phone number of consignee |
| ^email | string | Y | The email of consignee |
| ^address | object | Y | The consignee address must be a valid address; if the address verification fails, no order will be created. |
| ^^country_code | string | Y | The consignee address country code in two-character ISO 3166-1 alpha-2 format. Only `US` is accepted. |
| ^^state_or_region | string | Y | Consignee address state or region |
| ^^district_or_county | string | N | Consignee address district or county |
| ^^city | string | Y | Consignee address city |
| ^^address_line_1 | string | Y | The detail address line 1 |
| ^^address_line_2 | string | N | The detail address line 2 |
| ^^postal_code | string | N | The 5-digit US ZIP code for the consignee address. |
