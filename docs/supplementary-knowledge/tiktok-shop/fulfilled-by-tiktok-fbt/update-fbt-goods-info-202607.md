# Update FBT Goods Info

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-fbt-goods-info-202607](https://partner.tiktokshop.com/docv2/page/update-fbt-goods-info-202607)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `update-fbt-goods-info-202607`

## Description

Update FBT goods information, including goods name, image URL, dimensions, hazmat details, shelf-life attributes, and return address information.

## Required scope

seller.fbt.info

## Path

`/fbt/202607/goods/update_goods_info`

## Method

`POST`

| --- | --- | --- | --- |
| content-type | string | Y | Allowed type: application/json |
| x-tts-access-token | string | Y | The seller access_token value from [Get Access Token](https://partner.tiktokshop.com/docv2/page/678e3a3292b0f40314a92d75#Get%20Access%20Token%20API), when user_type = 0. Follow this [guide](https://partner.tiktokshop.com/docv2/page/678e3a344ddec3030b238fa0) to get seller access_token. |
