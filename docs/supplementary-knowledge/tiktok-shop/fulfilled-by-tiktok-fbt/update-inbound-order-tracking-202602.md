# Update Inbound Order Tracking

> **Source:** [https://partner.tiktokshop.com/docv2/page/update-inbound-order-tracking-202602](https://partner.tiktokshop.com/docv2/page/update-inbound-order-tracking-202602)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `update-inbound-order-tracking-202602`

## Description

Updates carton-level tracking information for an inbound order after shipment and before the order is marked as `Delivered` or `Received`. When updating tracking, send the complete desired `parcel_tracking_info` list; entries omitted from a non-empty submission are not retained, so this is not a partial patch. The first tracking value for a carton does not count as an edit, and resubmitting the same normalized value does not consume another edit. Changing an existing carton's tracking number consumes one of the five allowed edits for that carton; a sixth change is rejected before the local update. The submitted carton updates are applied atomically to the stored tracking list: either the complete local replacement is saved or none of it is. Warehouse synchronization and logistics tracking registration occur outside this atomic update; warehouse synchronization failures are not returned, and tracking registration runs asynchronously.

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| order_id | string | Y | The numeric identifier of the inbound order to update tracking information for.  <br>**Note:** Provide the numeric sequence only; do not include the "IBR" prefix (e.g., use `123456` instead of `IBR123456`). |
| parcel_tracking_info | []object | N | Carton-level parcel tracking information for the inbound order, including carton number, logistics provider name, and tracking number. |
| ^provider_name | string | Y | The `provider_name` field must contain exactly one of the following strings.<br><br>* `FEDEX` (Federal Express)<br>* `UPS` (United Parcel Service)<br>* `DHL` (DHL Express)<br>* `USPS` (United States Postal Service)<br>* `OTHER` (All other logistics providers)<br><br>**Note:** Input must match the uppercase string exactly (e.g., `"provider_name": "FEDEX"`). |
| ^tracking_number | string | Y | The tracking number to associate with this carton. It must not be empty or contain only whitespace, and it may contain only ASCII letters, digits, spaces, and hyphens. After spaces and hyphens are removed, 8 to 40 letters or digits must remain. |
| ^carton_number | string | Y | The carton number of an existing carton in this inbound order. After leading and trailing whitespace is removed, this value is matched to the carton whose tracking information is created or replaced. |
