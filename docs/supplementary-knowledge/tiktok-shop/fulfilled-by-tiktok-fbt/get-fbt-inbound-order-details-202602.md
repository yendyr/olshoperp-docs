# Get FBT Inbound Order Details

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-fbt-inbound-order-details-202602](https://partner.tiktokshop.com/docv2/page/get-fbt-inbound-order-details-202602)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `get-fbt-inbound-order-details-202602`

## Description

Retrieves details for the specified FBT inbound orders, including planned and actual receiving information and status history. Set `include_carton_details` to `true` to request carton dimensions and item quantities.

## Required scope

seller.fbt.info

## Path

`/fbt/202602/inbound_orders`

## Method

`GET`
