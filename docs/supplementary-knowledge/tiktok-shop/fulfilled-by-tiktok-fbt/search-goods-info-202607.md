# Search Goods Info

> **Source:** [https://partner.tiktokshop.com/docv2/page/search-goods-info-202607](https://partner.tiktokshop.com/docv2/page/search-goods-info-202607)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `search-goods-info-202607`

## Description

Retrieves goods belonging to the merchant that match the specified filters and returns their IDs, names, goods-SKU relationships, merchant-declared measurements, warehouse-confirmed measurements, and other attributes. When more than one of `goods_ids`, `product_ids`, `reference_codes`, and `sku_ids` is provided, the API returns only goods that match all provided filter fields. If all four filters are empty or omitted, the API returns the merchant's goods in descending creation-time order, limited by `page_size`.

## Required scope

seller.fbt.info

## Path

`/fbt/202607/goods/search`

## Method

`POST`

## Request Body

| Properties | Type | Required | Properties description |
| --- | --- | --- | --- |
| goods_ids | []string | N | Fulfilled by TikTok goods IDs used to filter the results. Each ID must be a positive decimal string. Maximum: 100 IDs per request. |
| product_ids | []string | N | TikTok Shop product IDs used to filter the results. Each ID must be a positive decimal string. Maximum: 100 IDs per request. |
| reference_codes | []string | N | Merchant-defined goods reference codes used to filter the results. Maximum: 100 codes per request. |
| sku_ids | []string | N | TikTok Shop SKU IDs used to filter the results. Each ID must be a positive decimal string. Maximum: 100 IDs per request. |
