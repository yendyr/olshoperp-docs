# Get FBT Merchant MCF Status

> **Source:** [https://partner.tiktokshop.com/docv2/page/get-fbt-merchant-mcf-status-202601](https://partner.tiktokshop.com/docv2/page/get-fbt-merchant-mcf-status-202601)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `get-fbt-merchant-mcf-status-202601`

## Description

Checks whether a seller is onboarded to Fulfillment by TikTok (FBT) and enrolled in Multi-Channel Fulfillment (MCF). This API currently supports only sellers in the US. If both conditions are met, `mcf_status.is_mcf` is `1` (active).

## Required scope

seller.fbt.info

## Path

`/fbt/202601/merchants/mcf_status`

## Method

`GET`
