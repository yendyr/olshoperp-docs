# Ship Inbound Order

> **Source:** [https://partner.tiktokshop.com/docv2/page/ship-inbound-order-202603](https://partner.tiktokshop.com/docv2/page/ship-inbound-order-202603)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `ship-inbound-order-202603`

## Description

Finalizes carton and shipping details for an inbound order that is ready to ship. For an order that has not already been shipped, a successful response means the details were saved and the order moved to the receiving stage. Repeating the request after the order has already been shipped returns success without applying the supplied details again.

## Required scope

seller.fbt.info

## Path

`/fbt/202603/ship_inbound_order`

## Method

| ^^goods_id | string | Y | Identifier of the goods item in the carton. |

Obtain this value from `data.goods[].lot_expiration_info.inbound_cutoff_days` in Search Goods Info (`POST /fbt/202607/goods/search`). Either omit `carton_nums` from every carton to have carton numbers generated automatically, or provide it for every carton.
