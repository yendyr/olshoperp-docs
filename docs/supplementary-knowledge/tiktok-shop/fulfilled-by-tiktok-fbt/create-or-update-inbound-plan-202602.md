# Create or Update Inbound Plan

> **Source:** [https://partner.tiktokshop.com/docv2/page/create-or-update-inbound-plan-202602](https://partner.tiktokshop.com/docv2/page/create-or-update-inbound-plan-202602)
> **Category:** Fulfilled by TikTok (FBT)
> **document_path:** `create-or-update-inbound-plan-202602`

## Description

Creates a new inbound plan or fully replaces the contents of an existing inbound plan by using a goods item list or carton configurations with dimensions. Omit `plan_id` to create a plan; provide it to update one. Provide exactly one non-empty array: `goods_items` or `cartons`; do not provide both.

For an update, submit the complete desired goods or carton contents; previously stored goods or cartons omitted from the request are not retained. Using `goods_items` clears existing carton and lot/expiration data. Using `cartons` rebuilds the carton and item data.

| ^^lot_code | string | N | Lot code for this goods item. Required when lot-code management is enabled for the goods. Every occurrence of the same `goods_id` in `cartons` must use the same `lot_code` and `expiration_timestamp` values. |

It must be no earlier than the current time plus the goods-specific `inbound_cutoff_days`.
